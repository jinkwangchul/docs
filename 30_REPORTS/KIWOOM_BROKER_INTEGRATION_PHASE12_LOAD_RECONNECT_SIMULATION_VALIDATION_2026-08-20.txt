  an explicit current-process operation start registers participants.

[SIMULATION_VERIFIED] Same-process reconnect and market-data reset

  TR_PRIMARY_SHADOWING.
- Old operation request ownership and pending reconciliation state are cleared.
- Existing Phase 1 login tests verify disconnect invalidation and new reconnect
  session identity.
- Existing Recovery/startup tests verify fail-close before current Recovery.

  not reuse prior eligibility or primary authority.

  once; repaired canonical data returns to TR_PRIMARY_SHADOWING.

  before REALTIME_PRIMARY promotion, including the no-gap case.

  save or BAR_COMMITTED publication.

  operation evaluation.

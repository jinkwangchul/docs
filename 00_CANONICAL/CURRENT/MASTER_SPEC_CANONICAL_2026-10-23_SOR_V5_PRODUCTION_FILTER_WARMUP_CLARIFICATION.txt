1. 사용자가 바로잡은 기본 개념
-----------------------------
- 실매매 필터값 계산에 필요한 기준봉 이력은 300봉을 기본 확보 목표로 한다.
  300봉은 조사 후보가 아니라 이번 실매매 이력 요청 구현 기준이다.
- 차트검증 V5의 5,000봉 과거 탐색/차트 UI 로딩은 실매매 필터
  준비용 캐시 300봉과 다른 목적이며, 실매매로 5,000봉 요구를 전파하지 않는다.
- MA600은 현재 확인한 지표추종매매 기본 필터 구성에 없다.
  활성 MA600을 가정하거나 600이평을 근거로 웜업·캐시 크기를 늘리지 않는다.
  확인된 기본 moving_averages는 [5, 20, 60]이며 이 숫자는
  모든 미래 루틴 설정에 강제되는 값이 아니라 조사 시점의 기본 구성이다.
- 과거 V4 테스트의 'MA600'은 시험 입력용 가상 사례이지
  사용자 승인 필터/실매매 운영 설정의 증거가 아니다.
- 소스에 있던 분봉 900·일봉 600·주봉 300 등의 history target은
  기준봉 이력 보유 정책값이며 MA900/MA600 같은 이동평균 기간이 아니다.
  이 값 자체로 실매매 필터 웜업 수요를 정당화하지 않는다.

2. 실매매 요청 구조 — 서로 다른 3가지 양을 혼동 금지
----------------------------------------------------
A. 필터 최소 웜업(warmup_bars):
   루틴의 실제 활성 필터, 파라미터, 봉 오프셋, 논리식 및 신호 지연을
   기준으로 산정하는 필터 판정 최소 준비량이다.
B. 실매매 지표 계산용 이력 목표(history_target_bars):
   지표추종매매 루틴의 요청값은 기본 300 기준봉으로 둔다.
   단, 실제 활성 조건의 최소 웜업이 300봉을 초과하면 해당 필요량을
   유지한다. 무작정 300으로 잘라 신호의 의미를 바꾸지 않는다.
C. 거래당일 SOR M1/틱 원천 수집량:
   장 시작부터의 당일 원천 M1, 현재 형성봉, 세션 전환,
   중도 종목 등록 복구를 위한 별도 입력이다.
   이 원천 수집량과 A/B의 선택 기준봉 이력 수를 동일시하지 않는다.

3. 공통 필터·캔들 엔진
----------------------
- V5 실시간 감시·모의검증·실매매는 SOR의 동일 기준봉과 틱을
  공통 캔들 형성/지표/필터 엔진에 투입한다.
- RSI/MACD의 초기 계산은 선택 설정에 필요한 유한 이력과
  기존 엔진의 계산/상태 갱신 규칙으로 처리한다. MACD·RSI라는
  이름만으로 과거 원천봉 무한 누적이나 5,000봉 선로딩을 요구하지 않는다.
- 별도 실매매 지표 엔진, 별도 상시 수집기는 금지. 과거 및 이미 완성된
  모든 상위 기준봉은 수량과 무관하게 직접 수신한 SOR(_AL)만 사용하며
  M1 집계·재구성·대체·fallback·검증은 영구 금지한다. 원천이 없으면 차단한다.
  거래당일 현재 진행 중인 봉만 유효한 실시간 SOR M1/틱으로 형성한다.
- 과거 SOR 확정 기준봉은 보존하고, 거래당일 현재봉만 규정대로 갱신한다.
- 동일 종목·원천·설정·평가시점의 RSI/MACD/OCR, 유효 필터,
  BUY/SELL 결과 일치를 목표로 한다. 확인 없는 동일값 PASS 선언 금지.

[2026-10-26 재확정 — 확보량과 M1 요구 범위]
- 분봉 V5의 기본 직접 선택 기준봉 확보량은 약 5,900봉(표시·탐색 5,000봉 + 준비 이력 900봉)이다. 전체 동시 화면 표시량을 뜻하지 않는다.

[2026-10-27 최신 우선 정정 — 당일 M3 이상 선택 기준봉]

- NXT 장전 _NX, SOR _AL, KRX 전용 원천과 세션 경계를 보존한다. V5/PRODUCTION/MINI/MOCK은 동일 원천·캔들·필터·신호 의미를 공유한다. MINI의 실제 체결 전체 사이클 일자 범위, MOCK의 실매매 동등 모의 흐름, 장중 CURRENT와 다음 거래일 최종봉의 차이 가능성은 2026-10-21 문서의 2026-10-27 절을 따른다.

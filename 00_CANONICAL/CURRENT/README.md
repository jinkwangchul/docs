# CURRENT Directory Policy

- Official Source of Truth is the latest Canonical in `00_CANONICAL/CURRENT`, as guided by `00_CANONICAL/REFERENCE/00_REFERENCE_INDEX.md`.
- Reference Index is a navigation and reference guide, not the Canonical itself.
- Do not decide latest status by filename date alone.
- Latest Canonical: `00_CANONICAL/CURRENT/MASTER_SPEC_CANONICAL_2026-07-14_SELL_RUNTIME_COMMIT_PIPELINE.txt`
- Latest WORK_RESUME: `00_CANONICAL/CURRENT/WORK_RESUME_LATEST_2026-07-14.txt`
- Older CURRENT documents must not be deleted or moved without explicit user approval.
- Archive moves require separate user approval.
- If documents conflict, decide in this order:
  1. Latest official Canonical
  2. Latest WORK_RESUME
  3. AGENT_WORKFLOW_REFERENCE
  4. CHANGELOG
  5. Legacy Reference PART

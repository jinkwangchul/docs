# CURRENT Directory Policy

- 공식 Source of Truth는 `00_REFERENCE_INDEX.md` 자체가 아니라, Index가 안내하는 `00_CANONICAL/CURRENT`의 최신 Canonical이다.
- Reference Index는 탐색 및 참조 안내 문서이다.
- 파일명 날짜만으로 최신본을 결정하지 않는다.
- 최신 Canonical: `00_CANONICAL/CURRENT/MASTER_SPEC_CANONICAL_2026-07-13_SELL_PREVIEW_CHAIN_AND_WORKFLOW_V2.txt`
- 최신 WORK_RESUME: `00_CANONICAL/CURRENT/WORK_RESUME_LATEST_2026-07-13.txt`
- 과거 CURRENT 문서는 사용자 승인 없이 삭제하거나 이동하지 않는다.
- Archive 이동은 별도 사용자 승인 후 수행한다.
- 문서 충돌 시 다음 순서로 판단한다.
  1. 최신 공식 Canonical
  2. 최신 WORK_RESUME
  3. AGENT_WORKFLOW_REFERENCE
  4. CHANGELOG
  5. Legacy Reference PART

2. Git Workflow v2 공식 승격

kiwoom_auto 저장소의 공식 Git 운영은 Workflow v2를 따른다.

공식 흐름:
- master 최신화
- Feature Branch 생성
- 구현
- 테스트
- Commit
- Push
- Pull Request 생성
- Review
- Merge
- Feature Branch 삭제
- master 최신화

운영 원칙:
- master 직접 Commit 금지
- master 직접 Push 금지
- Feature 하나 = Branch 하나
- Feature 하나 = Pull Request 하나
- Merge 후 master와 origin/master 일치 확인
- 긴급 Hotfix만 예외로 별도 승인 후 처리

docs 저장소는 Canonical 운영 저장소이며 PR 의무 없이 main에 Commit/Push할 수 있다.

7. MARKET 정책

SELL MARKET 후보는 price=None을 유지한다.

현재 공통 Validator 계약은 price > 0을 요구하는 구간이 있어 MARKET 계약과 충돌한다.

정책:
- price=None 우회 금지
- current_price 임의 대입 금지
- 공통 Validator 계약 검토 전 MARKET은 BLOCKED 유지
- price_required=False 의미 보존

8. PENDING 정책

PENDING은 일반 SELL Order 경로와 분리한다.

정책:
- Cancel Path 유지
- 일반 METHOD / COMPLETION SELL 주문 후보와 병합 금지
- 실제 CancelOrder 호출 금지
- Queue / Runtime / SendOrder 연결 금지

9. 다중 후보 정책

METHOD, COMPLETION, PENDING 후보가 동시에 READY 또는 eligible일 수 있다.

정책:
- 후보 모두 유지
- 우선순위 결정 금지
- 자동 선택 금지
- 실행 대상 결정은 별도 승인/Guard/Queue 단계로 분리

2. ROLLING PRICE BOX CONTRACT

Configured period means an exact rolling Candle window.
Default period is 24.

For evaluation index i, once at least period Candles exist:

window_i = CLOSE[i - period + 1 : i + 1]
A_i = arithmetic mean(window_i)
deviation_j = CLOSE_j - A_i for each CLOSE_j inside window_i

Positive deviations are the values > 0 inside that same window.
Negative deviations are the values < 0 inside that same window.

Upper_i = A_i + mean(positive deviations)
                + 2 * population_stdev(positive deviations)

Lower_i = A_i + mean(negative deviations)
                - 2 * population_stdev(negative deviations)

If the corresponding positive or negative group is empty, that band is None.
If the exact rolling window contains a missing value, that index remains None.

The project population-variance convention remains unchanged.
No new claim is made about an officially exposed N versus N-1 Kiwoom divisor.
3. ROLLING / CAUSAL BEHAVIOR

Price Box does not accumulate every historical Candle indefinitely.

When a new Candle enters a full period window:
- the newest Candle enters the calculation;
- the oldest Candle outside the period is evicted;
- the calculation again uses exactly period Candles.

Therefore:
- period=24 means only the latest 24 eligible Candles participate at each point;
- appending future Candles cannot alter already-computed earlier Price Box points;
- historical evaluation is causal without rebuilding deviation statistics from
  the entire growing prefix.

Before period Candles are available, Lower / Middle / Upper remain None.

At the canonical build_indicator_series boundary, invalid or non-positive
configured Price Box period falls back to the default 24.

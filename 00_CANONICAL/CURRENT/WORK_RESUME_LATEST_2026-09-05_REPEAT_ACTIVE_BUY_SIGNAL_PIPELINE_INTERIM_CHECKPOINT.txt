3. Repeat ACTIVE_BUY Production implementation

- Q = canonical current Position quantity.
- A = canonical current Position average_price.
- R = stable Signal/generation reference_price.
- P = actionable fresh acquisition price.
- U = R * (1 + n/100), L = R * (1 - n/100).
- Minimum quantity is solved from x = Q*(A-T)/(T-P), rounded to a whole-share
  candidate and verified against the actual comparator.
- READY creates an exact required-quantity plan; NO_BUY and WAIT create no
  order/round advancement; INVALID fails closed.
- P/Q/A changes do not mutate approved quantity in place. An undispatched stale
  generation is BLOCKED / ACTIVE_BUY_PLAN_SUPERSEDED and generation+1 re-enters
  Candidate, Approval, Operation Policy, and the normal execution path.
- Confirmed partial fills update Position before Q/A/P are re-read.
- Open remainder greater than new required quantity is canceled and waits for
  effect confirmation; open remainder less than or equal to required remains an
  unresolved obligation without duplicate dispatch.
- SEND_UNCERTAIN permits no blind retry, blind supersede, or new generation.
- ACTIVE_BUY has no independent budget SoT and does not trim the required
  quantity; existing Main cash/limit/safety gates decide admission.
- SINGLE, MULTI_HOGA, MULTI_TIME, and MULTI_RATIO planners are supported.

The 851-share and 56-share cases are regression examples only, not constants.

Automatic signal connection
---------------------------

Production automatic signal generation is connected:

  explicit operation start
  -> realtime target registration and tick stream
  -> RealtimeShadowBarBuilder
  -> completed one-minute canonical candle commit
  -> verified BAR_COMMITTED
  -> MarketDataHost canonical queue/signal
  -> AutoTradeOperationHost bar-trigger queue
  -> probe_execution_stock_for_committed_bar(...)
  -> completed_timeframe_candles(...)
  -> routine evaluate(context)
  -> BUY/SELL enqueue_routine_signal(...)
  -> _process_pending_signal_pipeline(...)
  -> normal Production approval/execution boundary

The AutoTradeOperationHost 10,000 ms QTimer is operation lifecycle/pending work
coordination, not the market signal calculation cadence. A forming minute bar is
not signal authority. The trigger is a committed/read-back-verified canonical
one-minute bar, while the Routine evaluator receives completed candles projected
to the instance's configured timeframe.

2. HISTORICAL POOL AND CHART VIEW CONTRACT
======================================================================

- Actual committed Signal Validation Historical base pool default is 5,000 candles.
- Earlier explicit operator direction requested 10,000-candle preload. This Freeze records the committed implementation state only; it does not treat 5,000 as approval of, or a supersession of, that 10,000 direction. The 5,000 vs 10,000 difference remains an unresolved recovery item requiring user decision before any implementation change.
- Required indicator warmup may increase the broker fetch count above that base.
- After the loaded pool is installed, the initial visible viewport is the latest 100 candles.
- There is no operator candle-count input in the V2 chart.
- Wheel zoom and pan inside the loaded pool are local chart operations and must not issue additional Historical/TR requests.
- Same-process stock + timeframe pool reuse is permitted and must not change first-load semantics.
- Settings re-application for the current chart does not reset the operator's chosen time/price viewport.
- Moving or zooming the time axis does not implicitly replace the current price-axis range after initial chart scale initialization.
- Price-axis zoom/pan and time-axis zoom/pan remain independent controls.
- Validation range selection remains explicit point selection and survives history prepend by candle identity/time where applicable.

======================================================================
4. V2 AVERAGING-MANAGEMENT CONTRACT
======================================================================

- Fresh V2 averaging management defaults to OFF.
- OFF means each valid BUY contributes exactly one virtual share and repeat management detail values are ignored.
- ON preserves the configured Validation repeat policy and weighted virtual position accounting.
- V2 execution controls remain Validation-local and are not a Production order-execution permission.
- Completed-cycle profit calculation uses total proceeds/cost.
- When averaging management is ON, the additional operator summary includes invested amount, profit amount, weighted average buy price, and weighted per-share estimated sell price.

======================================================================
5. MARKER / EVIDENCE / LEGEND CONTRACT
======================================================================

- BUY/SELL marker painting is clipped to the same price-plot rectangle as price candles.
- A marker outside that price plot is not hover/hit-testable.
- Visible marker Y semantics remain BUY below low and SELL above high.
- Marker hover/pin evidence remains cached; hover does not rebuild evidence.
- Filter captions are compact operator-facing labels.
- Any displayed line swatch is derived from the actual series rendering pen.
- Caption color/style follows ACTIVE/NORMAL/INACTIVE/UNSUPPORTED/ERROR rendering state rather than a duplicate color map.
- OCR histogram itself is not represented as a line swatch.
======================================================================
6. VALIDATION-OWNED PERSISTENT HISTORY CACHE
======================================================================

- Cache root: runtime/signal_validation_v2_history_cache/
- Cache identity: stock code + timeframe_minutes + requested_count.
- Payload contains normalized Validation candles, not broker raw rows.
- Cache reads validate schema, identity, and candle shape; invalid/corrupt data is treated as a cache miss.
- Writes use same-directory temporary file + flush/fsync + atomic replace, followed by read-back validation.
- On process restart, a valid cache may be loaded and refreshed using a bounded incremental overlap request, then merged by candle time.
- If incremental refresh cannot produce sufficient valid history, the flow falls back to the existing full read-only Historical request.
- A failed refresh does not destroy the last valid cache.
- Same-process in-memory/shared-pool reuse still takes precedence.
- This cache must not read or mutate Production stocks/<stock>/candles.json, MarketDataHost mutable state, operation candle writers, order/runtime production state, or Mock state.

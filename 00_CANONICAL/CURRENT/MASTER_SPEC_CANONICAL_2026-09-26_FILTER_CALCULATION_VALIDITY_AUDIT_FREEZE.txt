Final input contract
--------------------

Indicator Input SoT is the candle series of the selected timeframe.
All candle-derived indicators in one evaluation consume that same timeframe
candle set. Per-indicator alternate price sources are forbidden.

For minute timeframes, Production may derive target candles from canonical
one-minute candles. Validation may acquire read-only target-timeframe rows.
Complete target-timeframe OHLCV remains the shared semantic authority.
Filter verdicts
---------------

1. Moving Average / MA arrangement
Status: VERIFIED, NO NEW IMPLEMENTATION REQUIRED.

- MA values use the common timeframe CLOSE series.
- Explicit MA period identities remain distinct.
- MA comparison and arrangement conditions consume the configured periods.
- Production, Replay, Batch, and chart visualization share the same candle
  identity and period semantics.

2. Bollinger Band
Status: VERIFIED, NO NEW IMPLEMENTATION REQUIRED.

- Middle/upper/lower bands are derived from the same timeframe CLOSE series.
- Configured period and standard-deviation multiplier are preserved.
- Selected upper/lower band and signed-percent comparison are evaluated from
  the canonical band series.
- Production and Validation share the same Bollinger calculation functions.

3. Price Box
Status: NORMALIZED AND VERIFIED.

Checkpoint:
a9552b8 fix: normalize rolling Price Box calculation

- configured period is the exact rolling CLOSE window;
- default period is 24;
- a new candle evicts the oldest candle outside the rolling window;
- Production/Visualization/Replay/Batch consume the canonical rolling series;
- future candles cannot rewrite past Price Box values.
4. Price Comparison
Status: NORMALIZED AND VERIFIED.

Checkpoint:
ba91fed fix: normalize live price comparison semantics

- CURRENT_PRICE is an evaluation-time live/fresh strategy axis in Production;
- Validation CURRENT_PRICE is the CLOSE of the candle being evaluated;
- AVG_PRICE is the confirmed average at the evaluation point;
- delayed signal indexes must not push CURRENT_PRICE/AVG_PRICE back to stale
  historical values;
- legacy CLOSE<->AVG_PRICE strategy rules are normalized inside the Routine,
  not by changing common indicator CLOSE semantics.

5. RSI
Status: NORMALIZED AND VERIFIED.

Checkpoints:
8b60ea0 fix: honor configured RSI periods across evaluation
86cc172 fix: harden RSI runtime series binding

- BUY and SELL use the configured RSI period;
- SELL condition period no longer falls back silently to global RSI period;
- Production/Replay/Batch/Visualization use the same condition-period RSI;
- warmup uses period + 1 close observations;
- runtime private-series binding is derived from canonical fields and cannot
  be trusted from persisted private override data;
- current project RSI uses Wilder initial average plus recursive smoothing.

6. MACD / Signal
Status: VERIFIED, NO NEW IMPLEMENTATION REQUIRED.

- MACD = fast EMA - slow EMA;
- Signal = EMA(MACD, signal period);
- configured fast/slow/signal periods are shared by Production and Validation;
- MACD and Signal remain distinct selectable evaluation lines.
7. OCR / OSC
Status: NORMALIZED AND VERIFIED.

Checkpoint:
8877b12 fix: anchor OCR thresholds to turning points

- OSC = MACD - Signal;
- TURN_UP is prev2 > prev < current;
- TURN_DOWN is prev2 < prev > current;
- current confirms the transition;
- prev is the actual turning point;
- when OCR transition and numeric threshold belong to the same OCR row, the
  numeric threshold is evaluated at the turning point (bar_offset=1);
- 0/1/2 bars remain post-confirmation signal delay semantics;
- legacy rules without explicit threshold bar_offset receive the same runtime
  turning-point interpretation without mutating persisted rules.

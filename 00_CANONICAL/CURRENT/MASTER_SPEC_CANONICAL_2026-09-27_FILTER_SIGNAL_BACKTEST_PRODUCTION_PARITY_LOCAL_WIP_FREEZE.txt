2. PRODUCTION CALCULATION SOURCE CONTRACT

uses the production session contract and one-minute source history as the
calculation basis when that contract is available.

The calculation path is identified as:
PRODUCTION_M1_SESSION_AGGREGATION

Target-timeframe calculation candles are derived from the one-minute source
through the production session aggregation contract.

The display option such as regular-market-only is a display projection.
It must not change the calculation candle set or the resulting signal decision.

Calculation/cache identity must distinguish materially different:
- source identity;
- timeframe identity;
- production session contract;
- retained source range.

A persisted signal cache must not be relabeled as current merely because a
new production session contract is available.

Insufficient one-minute source coverage is retried within the approved bounded
source ceiling. If required production projection coverage cannot be proven,
the filter-signal backtest path fails closed instead of silently authorizing.

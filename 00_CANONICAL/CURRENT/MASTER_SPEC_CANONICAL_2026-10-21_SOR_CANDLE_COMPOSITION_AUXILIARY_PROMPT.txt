[새창 시작 시 필독 — 최우선 기술 계약]
차트검증 V5·모의검증·실매매는 키움 SOR를 공통 원천으로 하여
동일한 실시간 캔들 형성 엔진과 동일한 필터 판단 엔진을 사용한다.
차트검증 V5는 실매매와 동일한 실시간 캔들·필터값·BUY/SELL 신호를
수신 시점마다 추적하는 실시간 감시기 역할도 수행한다.
과거 특정 시점 재현과 실시간 감시는 같은 엔진의 사용 방식이며
별도의 차트검증 전용 형성 엔진을 만들지 않는다.
새창에서는 이 단일 엔진 계약을 우선하며 다시 묻지 않는다.
최신 명시적 사용자 지시가 본 문서보다 우선한다.

1. 단일 엔진 / 단일 원천
------------------------
1) 차트검증 V5, 모의검증, 실매매는 동일한 SOR 캔들 구성·실시간
   형성 규칙 및 동일한 기존 필터 계산식으로 BUY/SELL을 판단한다.
2) 거래당일 공통 원천은 키움 SOR의 확정 M1과 실시간 체결/틱이다.
   동일 계산 시점과 동일 원천 입력이면 OHLCV·RSI·MACD·OCR 및
   매수/매도 논리식의 결과가 일치해야 한다.
3) 실시간 틱으로 진행 중인 현재 기준봉의 OHLCV 형성, 필터 변화,
   BUY/SELL 판단을 차트검증 V5에서도 실시간으로 감시·표시한다.
   실매매와 동일한 계산 시점·원천을 사용하고 주문 전송은 분리한다.
4) 기존 evaluate_signal_selection()과 매수/매도 A/B/C, NOT, RSI,
   MACD, OCR 필터를 재사용하며 V5 전용 필터 엔진을 만들지 않는다.
5) SOR 출처와 거래세션 신원·시간을 검증한다. 키움 _AL TR 표지만
   근거로 KRX/NXT 개별 틱을 완전 병합·중복 제거했다고 주장하지 않는다.
   확인되지 않은 KRX 입력으로 SOR 값을 몰래 대체하지 않는다.

2. 과거 확정봉은 키움 SOR 선택 기준봉 그대로 보존
-------------------------------------------------
1) 전일 이전의 역사 캔들은 직접 수신한 키움 SOR(_AL) 해당
   선택 기준봉을 사용한다. 5,000봉 전체를 M1으로 재구성하지 않는다.
2) 그 시점까지의 필터값은 그 시점에 이용 가능한 동일한 기준봉
   입력으로 계산한다. 미래 가격·거래량을 과거 계산에 소급 적용 금지.
3) 과거에 이미 끝난 주·월·년 기간의 완성 기준봉은 원본을 유지한다.
4) 거래일 D가 속한 주·월·년은 D-1에 기간이 끝나지 않았을 수 있다.
   이때 해당 기간의 'D-1 마감 시점 누적 OHLCV 스냅샷'을
   키움과 같은 방식으로 구성해 전일까지의 계산 입력으로 사용한다.
   이를 최종 기간 완성봉과 혼동하지 않는다.
5) V5·실매매는 동일한 D-1 컷오프에서 동일한 과거 스냅샷과
   동일한 필터값을 재현해야 한다.

3. 거래당일 M1 + 실시간 틱으로 '현재 기준봉' 갱신
--------------------------------------------------
1) 당일 세션 시작부터 확보한 키움 SOR 확정 M1을 시간 순서대로
   축적하고, 현재 진행 중인 M1 및 상위 기준봉에는 유효한
   SOR 실시간 체결/틱을 반영한다.
2) 종목이 거래당일 중간에 매매에 참가해도 당일 첫 유효 거래
   세션부터 필요한 M1 이력을 재확보·구성한다. 등록 전 신호를
   소급 주문하지 않는다.
3) M1/M3/M5/M10/M15/M30/M60/M120/M240 및 D1의 현재
   기준봉은 키움 SOR 실제 세션·앵커 경계에 맞춰 당일 M1/틱으로
   형성·갱신한다. 과거 다른 거래일 확정 기준봉은 건드리지 않는다.
4) W1/MO1/Y1은 같은 주·월·년에 속한 경우 D-1까지의
   누적 기간봉에 당일 M1·실시간 변화분을 연결한다:
     시가   = 해당 주·월·년 최초 거래 시가(이전 누적 시가 유지)
     고가   = max(전일 누적 고가, 오늘의 최신 고가)
     저가   = min(전일 누적 저가, 오늘의 최신 저가)
     종가   = 동일 시점의 최신 유효 SOR 가격
     거래량 = 전일 누적 거래량 + 오늘의 누적 체결량
   새로운 주·월·년 첫 거래일에는 새 기간봉으로 시작한다.
   누적 거래량 중복 더하기와 미확인 중복 틱 반영을 금지한다.
5) 프리장·정규장·장후, 휴장·기간 경계·부분 기간봉,
   시간 앵커는 실제 키움 SOR 생성 방식에 맞게 확인한다.
   임의의 고정 시각·세션 규칙으로 과거 봉을 재작성하지 않는다.

4. V5 실시간 형성 및 과거 시점 재현의 차이
----------------------------------------
1) '실시간 V5'와 '실매매'는 서로 다른 형성 정책이 아니다.
   같은 SOR M1+실시간 체결/틱을 같은 공통 엔진에 전달하여
   현재 형성 중인 기준봉을 갱신하고 같은 필터값을 사용한다.
2) V5에서 과거 특정 시점을 선택해 재현할 때만 해당 시점까지
   입수된 정보로 공통 엔진 상태를 재현·고정한다. 미래 데이터는
   사용하지 않는다. 역사 재현의 컷오프 제약은 V5 실시간 형성을
   금지하는 근거가 아니다.
3) 동일 종목·설정·원천·시점에서는 캔들 성분과 필터 결과,
   BUY/SELL 지점이 같아야 한다. 차이는 입력 컷오프와
   데이터 수신 지연이 증명될 때만 설명한다.
4) 실주문 전송은 별도 명시적인 사용자 승인 전까지 금지한다.
   V5에서 계산·표시했다고 주문 경로에 연결하지 않는다.

4-A. 차트검증 V5의 실시간 감시기 역할 — 구현 필수 계약
----------------------------------------------------
목적:
- V5는 과거 BUY/SELL 지점을 연구·재현하는 차트이면서 동시에
  선택 종목의 현재 기준봉·지표·매수/매도 조건을 계속 관찰하는
  '실시간 감시기'다. 두 기능은 별도 캔들 엔진이 아니라
  동일한 SOR 공통 실시간 형성·필터 엔진의 다른 사용 방식이다.
- 실시간 감시는 주문 허가나 실매매 참여 등록을 뜻하지 않는다.

실시간 입력 및 감시 대상:
1) V5에서 사용자가 선택한 종목과 기준봉, 현재 적용된 매수/매도
   설정값을 감시 대상으로 사용한다. 기존에 허가된 키움 SOR
   수신/구독 경로를 재사용하고 중복 TR·별도 수집기를 만들지 않는다.
2) 공통 엔진으로 들어오는 유효 SOR 확정 M1·실시간 체결/틱에
   따라 현재 형성 중인 M1과 해당 상위 기준봉의 OHLCV를 갱신한다.
   직접 수신한 전일 이전 SOR 기준봉은 그대로 두고, W1/MO1/Y1은
   전일 누적 성분을 승계한 뒤 당일 변화분을 반영한다.
3) 동일 입력 시점에 실제 매매 엔진과 같은 RSI·MACD·OCR·기존
   필터 A/B/C·NOT·BUY/SELL 평가 함수를 적용한다. V5만 다른
   연산 결과를 만들거나 별도의 실시간 필터 식을 사용하지 않는다.
4) 화면에는 기준봉 형성, 가격·거래량 변화, 관련 지표선/값,
   유효 필터의 상태 및 BUY/SELL 판단 변화를 기존 표시 규약에
   따라 실시간 반영한다. 기존 마커·범례·유효·NOT 의미는 유지한다.

과거 재현·차트 조작과의 관계:
5) 과거 시점 선택·기간선택·마킹은 그 시점의 유효 원천과 계산
   상태를 공통 엔진으로 재현한다. 실시간 후속 입력으로 이미 고정한
   과거 결과를 소급 수정하거나 선택/마킹 상태를 무단 초기화하지 않는다.
   기존 수평 이동·스케일 변경에 따른 마킹 해제 계약은 보존한다.
6) 실시간 갱신과 과거 검증은 데이터 시점/표시 상태를 명확히
   구분하되, 형성 엔진·지표 엔진·신호 판단 엔진은 공유한다.
   역사 재현이 실시간 감시 기능을 제거하는 이유가 될 수 없다.
7) 현재 봉 변화로 차트를 새로 5,000봉 전량 로딩하거나 과거
   기준봉 전체를 M1으로 재구성하지 않는다. 기존 5,000봉
   초기 로딩, 3,500봉 표시 한도, 스크롤/드래그/줌 및
   GUI 반응성을 보존하고 당일 현재봉만 필요한 만큼 갱신한다.

오류·안전 경계:
8) 원천 신원, 로그인 세션, 거래 시각, 틱 순서, 확정 M1 중복,
   거래량 중복, 누락 또는 데이터 지연이 확인되면 해당 갱신/판단을
   안전하게 제한하고 상태를 구분한다. 오래된 캔들을 최신값처럼
   표시하거나 KRX 단독 데이터로 묵시적으로 대체하지 않는다.
9) V5의 BUY/SELL은 실시간 감시·검증 신호이며 주문 지시가
   아니다. 실주문·주문 큐·계좌·보유수량·운영 포지션 변경은
   이 화면의 실시간 감시 기능에 연결하지 않는다. Telegram이나
   별도 알림 서비스도 이 계약만으로 자동 생성하지 않는다.

최소 필수 검증 및 완료 기준:
10) 실제 V5 진입점에서 같은 종목·설정·SOR 입력·평가 시점의
    OHLCV, RSI/MACD/OCR, 유효 필터, BUY/SELL 결과가 실매매
    판단 경로와 일치하는지 실시간 변화 중 확인한다.
11) 현재 M1의 진행, M1 확정 및 다음 분 전환, 상위 기준봉
    전환, 주·월·년 전일 누적 승계와 새 기간 첫 거래일을
    포함해 확인한다. 중도 종목 선택/참여도 당일 선행 M1
    이력을 사용하되 과거 시점의 신호를 소급 주문하지 않는다.
12) 마킹·기간선택·유효/NOT 표시, 5,000봉 성능,
    장전/정규/장후 세션 및 실주문 0건을 필수 회귀로 확인한다.
    합성 테스트만으로 실시간 감시·실창 동작 완료를 선언하지 않는다.

4-B. 간이차트의 자동매매 운영기간·기록·필터값 표시 계약 (2026-10-23 보강)
-------------------------------------------------------------------
적용 및 단일 엔진:
1) 간이차트는 종목별 실제 자동매매 활동의 시작·진행·종료와
   당시 가격·매수/매도 기록을 보여주는 운영 이력 화면이다.
   차트검증 V5·모의검증·실매매와 동일한 키움 SOR 원천,
   캔들 형성·필터 판단 엔진을 사용하며 별도 엔진을 만들지 않는다.
2) 간이차트의 표시 범위·운영 종료 판정·필터 계산·실제 체결 기록은
   서로 다른 개념이다. 표시 끝시각이나 마지막 매매시각으로
   실제 자동매매 종료를 추정하지 않는다.

시간축과 실제 운영기간:
3) 시작은 해당 종목의 실제 승인·성공한 Operation Start 기록으로
   정한다. 단순 등록, 화면 열기 또는 시각 도래를 시작으로 보지 않는다.
4) 차트는 최소 해당 거래일 1일의 08:00~20:00를 표시한다.
   하루를 넘는 자동매매 활동은 실제 시작일에서 실제 종료일까지
   해당 거래일별 08:00~20:00 구간을 연결하여 보여준다.
   예: 첫날 10:00 시작, 익일 14:00 실제 종료이면
   첫날 08:00~20:00와 익일 08:00~20:00를 표시한다.
   시작·종료 마커는 각 실제 이벤트 시각에 별도로 표시한다.
5) 종료가 아직 확정되지 않은 활동은 '진행 중'으로 취급한다.
   과거 날짜와 현재 날짜의 차트 표시가 이어지더라도 일자 변경,
   ATS 장 종료·비거래 간격만으로 자동매매를 종료 처리하지 않는다.
   비거래 시각에 존재하지 않는 봉·틱을 만들어 채우지 않는다.

현재일과 과거일의 필터값 계산:
6) 현재 거래일은 당일 세션 시작부터 필요한 SOR 확정 M1과
   실시간 체결/틱으로 선택한 현재 기준봉(M1~M240, D1 등)을
   형성하며 공통 엔진에서 실시간 RSI/MACD/OCR, 매수·매도
   A/B/C·NOT 조건과 BUY/SELL 신호를 평가한다.
   예를 들어 M120 기준봉은 당일 M1·틱 성분으로 갱신한다.
7) 다음 거래일로 넘어오면 앞선 거래일의 필터값은 키움 SOR의
   해당 선택 기준봉 과거 확정 데이터(예: 완성 M120)를 이용해
   기존 역사 계산 계약대로 표시한다. 지난 날짜의 전체 M1을
   다시 합성해 과거 M120 필터 입력으로 대체하지 않는다.
8) 주·월·년 기준봉도 기존 키움 과거일자 방식에 따른다.
   끝난 기간은 직접 수신한 확정 기간봉, D-1에 아직 끝나지 않은
   기간은 그 시점의 누적 OHLCV 스냅샷을 사용한다.
   미래 시점의 최종 종가·고가·거래량을 과거 판단에 주입하지 않는다.
9) 이전 거래일의 M1 이력이 간이차트 가격선과 실제 매매 지점
   시각화에 필요하면 해당 표시 날짜의 자료만 사용한다.
   이는 역사 필터값의 M1 재구성 허가가 아니다.
   V5 5,000봉 표시 이력과 실매매 약 300개 선택 기준봉의
   필터 준비 이력은 목적이 다르며 간이차트 때문에
   실매매에 5,000개 M1이나 별도 검증용 700봉을 강제하지 않는다.
   실제 필터 준비량은 2026-10-23 SOR 웜업 명확화 계약을 따른다.

실제 매수·매도 기록의 불변성:
10) 실제 매수·매도 시점, 가격, 수량 및 체결·운영 사이클은
    원본 주문/체결·운영 이력 증거를 기준으로 표시·보존한다.
    신호 계산 지점과 실제 체결 지점을 혼동하지 않는다.
11) 날짜가 지난 뒤 완성된 기준봉으로 계산한 필터값이
    당시 실시간 형성봉의 값과 달라도 기존 실제 체결 시각과
    가격·매수/매도 마커를 이동·삭제·소급 재계산하지 않는다.
    과거 필터값은 이력 분석 표시이지 주문 이력 수정 근거가 아니다.

실제 종료와 검토관리 장기보유 ON/OFF:
12) 종료시각과 상태는 기존 Operation 종료·청산·주문 정리,
    Recovery/Review 판정·기록 확인 및 참가자 퇴역 절차의
    공식 결과를 따른다. 간이차트 자체 종료 판정기를 만들지 않는다.
13) review_policy.long_term_holding_enabled(기본 OFF)는
    검토관리 분류 정책이다. ON이면서 증명된 정상 이월·장기보유
    경로와 잔여 보유수량이 있으면 기존 계약대로 정상 장기보유로
    취급하고 단순 일자 경계에서 종료나 Review를 강제하지 않는다.
    OFF 상태의 잔여 보유는 기존 Review 계약을 따른다.
14) 시장가/현재가 청산 후 잔여 보유, 미해결 주문·복구·큐·브로커
    오류, 강제·비정상 종료의 Review 판정은 ON/OFF와 관계없이
    기존 계약을 우선한다. 정당한 종료 경계에서 보유수량이 0이고
    미해결 실행 상태가 없을 때만 기존 정상 완료 절차를 따른다.
    장기보유 ON 자체가 익일 자동매매를 재시작하거나 새 Operation을
    승인한 것으로 해석하지 않는다.
15) 판단 근거가 부족하면 실제 종료/체결을 추정하지 않고
    확인되지 않은 상태로 유지한다. 간이차트 표시는 실주문 실행,
    임의 청산, 검토관리 상태 변경의 권한을 부여하지 않는다.

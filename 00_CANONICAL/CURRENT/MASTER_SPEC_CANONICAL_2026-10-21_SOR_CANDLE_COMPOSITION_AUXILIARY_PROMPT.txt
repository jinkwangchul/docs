[새창 오케스트레이터 필독]
SOR 통합시세 기준 차트검증 V5·모의검증·실매매의 캔들과 필터
정합성 구현을 시작·재개하면 반드시 먼저 이 문서를 적용할 것.
이 내용은 사용자가 반복해서 정정하고 재확인한 계약이다.
최신 명시적 사용자 지시가 본 문서보다 우선한다.

1. 최상위 계약
-------------
1) 과거 전체 기준봉(예: 차트검증 V5의 5,000봉)을 M1으로 재구성하지 않는다.
2) 거래당일 이전까지의 봉과 필터 계산은 키움 SOR 통합시세(_AL)의
   해당 선택 기준봉 이력 및 전일 기준 확정 입력으로 산출한다.
3) 거래당일에는 키움 SOR M1을 원천으로 필요한 당일 기준봉을
   구성·갱신해 기존 필터 엔진으로 매수·매도를 판단한다.
4) 당일 중간에 종목을 매매에 등록하더라도 해당일 첫 거래 세션부터
   필요한 M1 이력을 확보해 당일 캔들 성분을 일관되게 구성한다.
5) 과거 확정봉을 보존한다. 새 필터 엔진과 과거 전체 M1 재생성은 금지.

2. 전일 기준봉·필터값과 주·월·년 마지막 봉
-------------------------------------------
- 거래일 D의 과거 입력은 D-1일까지의 키움 SOR 직접 기준봉으로 구성한다.
  이미 종료된 기간의 일·주·월·년 확정봉은 직접 원천 그대로 유지한다.
- 단, D가 속한 현재 주·월·년은 아직 달력 기간상 미완성일 수 있다.
  D-1 마감 시점에 키움과 동일 방식으로 누적된 해당 주봉/월봉/년봉
  OHLCV를 '전일 기준 고정 스냅샷'으로 사용한다.
- 전일 고정 스냅샷은 계산 시점에서 확정된 데이터이지,
  달력상 최종 완성봉이라고 잘못 표기해서는 안 된다.
- 차트검증과 실매매의 D-1 이전 필터값은 같은 종목·설정·데이터
  컷오프에서 동일해야 한다. D의 시세를 과거 필터값에 소급 반영 금지.

3. 당일 M1 기반 성분 조성
-------------------------
- D 당일 확정 M1을 바탕으로 그날 필요한 분봉·일봉 및 현재 기준봉을
  조성한다. 이는 당일 M1 처리이지 과거 5,000봉 전 구간 재구성이 아니다.
- M3/M5/M10/M15/M30/M60/M120/M240 등 분봉은 키움 SOR의 실제
  거래 세션과 기준봉 앵커에 따라 당일 M1을 묶는다.
- 일봉은 D의 당일 M1로 성분을 구성한다.
- 주·월·년봉은 D가 전일과 같은 기간에 속할 경우 전일 누적
  OHLCV에 D의 M1 기반 당일 누적 성분만 반영한다.
  시가   = 기간 첫 거래의 시가(전일 누적 시가 승계)
  고가   = max(전일 누적 고가, 당일 고가)
  저가   = min(전일 누적 저가, 당일 저가)
  종가   = 당일 해당 계산 시점의 최신 유효 종가/가격
  거래량 = 전일 누적 거래량 + 당일 누적 거래량
- 새 주·월·년 첫 거래일에는 이전 기간의 누적 성분을 승계하지 않고
  새 기준봉으로 시작한다. 당일 누적량의 중복합산·역산 금지.
- 주간 시작, 일·주·월·연 경계, 휴장, 장전/정규/장후, 기간
  앵커와 누적 집계는 실제 키움 SOR 방식과 일치시켜야 한다.
  미확인 관행을 임의 상수로 가정하지 않는다.

4. 차트검증·실매매 계산 시점
---------------------------
- 두 경로 모두 동일한 SOR 구성 규칙과 기존 필터 엔진을 사용한다.
- 차트검증: 평가 시점 마지막 형성 중 M1은 계산 입력에서 제외한다.
  남은 확정 M1으로 해당 시점의 현재 기준봉 계산용 스냅샷을 만든다.
  계산용 스냅샷과 달력 기간의 영구 완성봉은 다르다.
- 실매매 계산: 확정 M1 및 장중 수신한 유효 정보를 현재 기준봉에
  적용한다. _AL TR 스냅샷을 검증된 KRX/NXT 독립 통합틱으로 주장 금지.
- 전일까지의 입력 OHLCV와 필터값은 동일, 당일 차이는 실제
  확정범위·수신·계산 시점 차이로만 설명되어야 한다.
- 기존 RSI, MACD, OCR, NOT, 매수/매도 A/B/C 연산식과
  evaluate_signal_selection()을 변경·복제하지 않는다.
- 실주문 전송은 별도 명시적 사용자 승인 전까지 금지한다.

5. 엄격 금지 — 반복하지 말 것
-----------------------------
X 과거 확정 기준봉 5,000개를 M1으로 전부 재구성하기
X 차트검증 계산 뷰의 과거 봉 전체를 M1 배열로 일괄 대체하기
X 직접 SOR 과거 확정봉을 당일 M1 결과로 덮어쓰기
X 현재 주·월·년의 전일 누적 성분을 버리고 당일 M1만 사용하기
X 중복 거래량 합산, 무단 KRX 대체, 근거 없는 시간 경계 가정
X V5의 5,000봉 로딩·스크롤·마킹·기간선택·유효/NOT·성능 변질
X 불필요한 새 수집기·새 스케줄러·새 필터 엔진 구축

------------------------

- 원본 이력은 불변, 당일 M1만 추가해 대상 기준봉 갱신.

- 필수 검증: D-1 필터 정합성, 주·월·년 누적/기간 첫날,
  중도 종목등록과 당일 첫 세션, 거래량 중복 방지,
  마지막 미완성 M1 제외, 소스/결측 차단, V5 기능·성능 보존.

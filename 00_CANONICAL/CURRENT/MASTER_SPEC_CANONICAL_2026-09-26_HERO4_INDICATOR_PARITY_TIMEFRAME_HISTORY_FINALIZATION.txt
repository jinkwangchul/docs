2. HERO4 EAVG / MACD CONTRACT

For ordinary numeric vectors, the current shared EMA behavior is:
- recursive EMA state starts from the first numeric value;
- multiplier = 2 / (period + 1);
- when fewer than period values exist, the exposed EAVG-compatible vector is zero;
- once period values exist, the first period output slots are backfilled with the
  EMA value at the period-th observation;
- subsequent values continue recursively.

The sparse/None path retains its prior behavior because Hero4 missing-value
semantics were not proven by this task.

MACD / Signal / OSC remain:
- MACD = fast EAVG - slow EAVG;
- Signal = EAVG(MACD, signal period);
- OSC = MACD - Signal.

The causal-history wrapper preserves prefix causality so the warmed Hero4-style
prefix cannot leak future observations into earlier historical evaluations.

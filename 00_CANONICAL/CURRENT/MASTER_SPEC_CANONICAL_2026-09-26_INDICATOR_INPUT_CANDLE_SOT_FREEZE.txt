Canonical contract
------------------

1. Indicator Input SoT is the candle series of the selected chart timeframe.
2. All indicators evaluated at one point consume that same timeframe candle set.
3. No RSI/MACD/OSC/MA/Bollinger/Price Box path may silently source a separate
   price series for the same evaluation.
4. Minute-timeframe examples:
   - 1-minute RSI14 uses the selected 1-minute candle closes.
   - 30-minute RSI14 uses the closes of the selected 30-minute candles.
   - Production 30-minute candles are projected from canonical one-minute
     candles using the common timeframe aggregation boundary.
5. The same rule applies to MACD, Signal, OSC, moving averages, Bollinger,
   Price Box, and other candle-derived indicators.
6. OHLCV belongs to the timeframe candle SoT. Indicators consume only the
   fields required by their formula; the current indicator set is primarily
   close-based, while VOLUME remains projected from the same candle objects.
7. A forming candle, when the Routine projection explicitly permits it, is one
   shared forming timeframe candle snapshot for every indicator in that
   evaluation. Indicators may not hold independent forming-candle states.
8. Historical Validation evaluates the same candles that its chart/replay
   displays. The indicator cache must not reconstruct a different price source.

Acquisition-path boundary
-------------------------

Production and Validation are not required to use the same broker request
mechanism. They are required to represent the same target-timeframe candle
semantics.

- Production minute-timeframe path:
  canonical one-minute candles -> aggregate_minute_candles(timeframe)
  -> Routine candle projection -> common indicator engine.

- Validation minute-timeframe path:
  read-only Broker target-timeframe rows -> detached Validation candles
  -> Replay/Batch/Visualization -> common indicator formulas.
A difference in acquisition path does not authorize a difference in complete
target-timeframe OHLCV. If complete buckets diverge, treat that as a parity
defect to investigate rather than defining separate indicator semantics.

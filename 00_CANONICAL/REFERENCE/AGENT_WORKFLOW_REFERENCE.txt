13. 작업 지시 원칙
==================================================

모든 AI는 다음 원칙을 따른다。

1.
사용자가 요청하지 않은 기능은 구현하지 않는다。

2.
사용자가 요청하지 않은 구조 변경은 하지 않는다。

3.
기존 구조를 단순화하거나 최적화하기 전에
반드시 영향도를 검토한다。

4.
삭제 작업은 반드시 사용자 승인 후 수행한다。

5.
기존 정책과 다른 구현이 필요한 경우
먼저 이유를 보고하고 승인을 받은 후 진행한다。

6.
불확실한 사항은 추측하지 않는다。

7.
MASTER_SPEC와 충돌 가능성이 있으면
즉시 검토를 요청한다。

8.
구현 중 의심되는 사항은
추측으로 처리하지 않는다。

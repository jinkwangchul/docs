13. 작업 지시 원칙
==================================================

모든 AI는 다음 원칙을 따른다。

1.
사용자가 요청하지 않은 기능은 구현하지 않는다。

2.
사용자가 요청하지 않은 구조 변경은 하지 않는다。

3.
기존 구조를 단순화하거나 최적화하기 전에
반드시 영향도를 검토한다。

4.
삭제 작업은 반드시 사용자 승인 후 수행한다。

5.
기존 정책과 다른 구현이 필요한 경우
먼저 이유를 보고하고 승인을 받은 후 진행한다。

6.
불확실한 사항은 추측하지 않는다。

7.
MASTER_SPEC와 충돌 가능성이 있으면
즉시 검토를 요청한다。

8.
구현 중 의심되는 사항은
추측으로 처리하지 않는다。

17. GitHub 재조회 기준
==================================================

GitHub는 모든 작업마다 반복 조회하지 않는다.
재조회는 다음 시점으로만 제한한다 (운영 매뉴얼 §6.3 준수).

재조회 시점
- 새 AI 세션 시작
- Git commit 또는 GitHub Push 완료 이후
- 운영 문서 변경 (README / AI_PROJECT_OPERATION_MANUAL_RELEASE / AI_SESSION_START_PROTOCOL / MASTER_SPEC / CHANGELOG)
- MASTER_SPEC 변경
- 사용자가 GitHub 확인을 요청한 경우
- ChatGPT가 구조 충돌 가능성을 판단한 경우

금지
- 구현 진행 중 반복 GitHub 조회 금지
- 세션 시작 시 확인한 GitHub 상태를 기준으로 작업 진행

1. CONFIRMED CHANGES
======================================================================

- Verified runtime Master Stock Library evidence is now the per-stock NXT
  eligibility authority used by ATS session admission.
- Only explicit `nxt_available=true` authorizes an ATS window.
- False, null, absent, invalid, or unverified evidence fails closed.
- Continuous-operation session projection no longer treats an unavailable NXT
  window as a valid current/future re-entry horizon.
- Routine order permission, manual ATS selection, ATS liquidation,
  close/liquidation availability, and time-end retirement now consume the same
  per-stock eligibility boundary.
- Non-eligible/unknown manual ATS targets use `NXT_NOT_AVAILABLE`.
- Mock/reference projection receives NXT eligibility as read-only parity
  evidence without gaining Production writer authority.

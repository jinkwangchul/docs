Contract recorded:
- Data does not determine metric layout. Approved fixed rectangles determine
  where data is rendered.
- Auto-trade setting stock table metric cells use header-owned labels and
  title-free cell values.
- Main monitoring stock rows keep labels inside the row because the main tree
  has no metric headers.
- Main stock metric slots are fixed:
  holding 232 px, price 226 px, profit/loss 232 px, unfilled order 120 px,
  buy limit 146 px, consumed amount 214 px.
- Main stock metric separators use 5 px gaps and a fixed 9 px separator glyph
  width.
- Main metric internal component rectangles are fixed for label, parentheses,
  left value, slash, right value, and closing parenthesis.
- Buy-limit display, hit-test, and editor value rectangles are aligned.
- Buy-limit editing hides only the current value while keeping label and
  parentheses visible.
- Consumed amount is displayed only when a valid stock buy limit is configured.
- Consumed amount and its preceding separator are hidden when the stock buy
  limit is unconfigured.
- Main routine monitoring tree reserves the vertical scrollbar AlwaysOn and
  does not use a horizontal scrollbar.
- Main window default size is 2137 x 720 for the confirmed layout.

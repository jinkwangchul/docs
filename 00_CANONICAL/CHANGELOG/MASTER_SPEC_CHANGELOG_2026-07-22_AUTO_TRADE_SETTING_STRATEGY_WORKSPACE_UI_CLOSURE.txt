Contracts added or clarified:
- The auto-trade setting window uses a strategy workspace layout with:
  - left Routine Definition -> Routine Instance tree
  - right Selection Summary
  - right Stock List
- The tree is a two-level routine structure, not a stock-node tree.
- Parent definition selection is view-scoped:
  - all child-instance stocks are shown
  - instance_id stays empty
  - no first-child instance inference
- Child instance selection is instance-scoped:
  - only the child instance stocks are shown
  - selected instance_id is retained
- Selection Summary mirrors parent or child selection scope.
- Current count labels remain:
  - 종목
  - 실행
  - 정지
  - 검토
- Counts use the existing current-operation source and do not create a new cache
  or alternate semantics.
- Default-operation remains instance-scoped and is not assigned to parent rows.
- The final visible tree does not treat default-operation stamp buttons as a
  required left-tree display feature.
- The routine tree name display rule remains the new confirmed rule:
  - 1 to 7 characters: original name
  - 8 or more characters: first 6 characters plus ellipsis
- Name QLabel background is transparent and selected row background remains
  continuous.
- The red/yellow/green signal light remains meaningful as a past-performance
  signal and is not removed, hidden, weakened, or replaced.

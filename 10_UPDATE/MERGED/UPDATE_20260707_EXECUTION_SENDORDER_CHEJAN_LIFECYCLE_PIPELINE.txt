1. Execution Queue Commit Pipeline
2. Canonical SendOrder Pipeline
3. SendOrder Recorder Pipeline
4. Chejan Entry Pipeline
5. Chejan Event Pipeline
6. Lifecycle Preview Pipeline

Queue Commit, SendOrder, Chejan, Lifecycle 전환을 각각 분리된 계층으로 다룬다.

Canonical SendOrder Path는 이번 6개 commit에서 Queue Commit 이후 SendOrder, Recorder, Chejan, Lifecycle까지 이어지는 전체 흐름 후보로 정리된다.


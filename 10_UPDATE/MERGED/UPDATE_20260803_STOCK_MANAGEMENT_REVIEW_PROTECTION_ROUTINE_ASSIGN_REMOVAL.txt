3. Protected Review State Contract

- A stock collected into review management is protected until the operator completes an explicit review-management procedure.
- Protected review state blocks:
  - routine assignment
  - routine unassignment
  - registered-stock unregister
  - stock delete
  - general state changes that bypass review management
- The shared review-state predicate remains the Source of Truth.
- Writers must not be reached when the policy Gate blocks an operation.
- Review-management entry and official review-management return/removal flows remain allowed.

4. Emergency Release Gate Contract

- Emergency release is not a simple flag clear.
- Emergency release must pass the existing operation data integrity checks before resolving review state.
- Operation data inconsistency, including holding quantity 0 with average price present, blocks emergency release.
- A blocked release must not store review_status=RESOLVED.
- The review return Gate is not relaxed.

5. Routine Assignment Window Removal

- The separate RoutineAssignWindow GUI is removed from production.
- The bottom stock-management 루틴등록 button that opened the separate window is removed.
- Legacy open functions and imports for RoutineAssignWindow are removed.
- Stock-management right-click routine assignment remains the supported visible path:

  right-click stock row -> 루틴등록 -> select routine instance -> existing direct backend

- Existing routine assignment Gate, Writer, blocked report, Toast, and refresh contracts remain.

MASTER_SPEC v4.0 정본

PART 27. rules.json 구조와 신호엔진 검증 1차본 (27.11 ~ 27.20)

27.11 rules.json 로딩 절차

루틴 초기화 시 rules.json을 먼저 로드한다. 로드 실패 시 신호엔진은
오류를 기록하고 신호 생성을 수행하지 않는다.

------------------------------------------------------------------------

27.12 기본값 처리

누락 가능한 선택 항목은 기본값을 적용한다. 필수 항목은 기본값으로
대체하지 않는다.

------------------------------------------------------------------------

27.13 조건그룹 저장 규칙

A/B/C 조건그룹은 독립 구조로 저장한다. 각 그룹은 별도의 설정 영역을
가진다.

------------------------------------------------------------------------

27.14 BUY 설정 저장

BUY 관련 필터, 평단관리, 매수방식, 완료정책은 BUY 영역에 저장한다.

------------------------------------------------------------------------

27.15 SELL 설정 저장

SELL 관련 조건그룹과 조합 규칙은 SELL 영역에 저장한다.

------------------------------------------------------------------------

27.16 NOT 규칙 저장

NOT은 독립 제외 규칙으로 저장한다.

AND NOT, OR NOT 구조를 저장하지 않는다.

------------------------------------------------------------------------

27.17 신호엔진 검증

로드 완료 후 설정 구조, 필수 키, 데이터 형식을 검증한다.

------------------------------------------------------------------------

27.18 오류 로그 정책

설정 오류는 로그에 기록한다.

오류 발생 시 임의 설정으로 계속 진행하지 않는다.

------------------------------------------------------------------------

27.19 구현 금지

-   미검증 JSON 사용
-   필수 키 자동 생성
-   구조 자동 변경
-   사용자 승인 없는 포맷 변경

------------------------------------------------------------------------

27.20 최종 원칙

rules.json은 루틴 정책의 공식 저장소이다.

신호엔진은 검증된 설정만 사용하여 BUY/SELL을 판단한다.

END OF PART 27.11~27.20

MASTER_SPEC 누락보강 60
주제 : 히스토리 기반 매도설정 UI 최종 확정사항 종합 및 구현 기준

출처 : 작업진행상황대화히스토리_7~8 비교 반영

1. 목적
매도설정 UI 설계 과정에서 확정된 핵심 사항을 종합하여,
향후 구현과 유지보수의 기준 문서로 활용한다.

2. 최종 구조
- 그룹박스 기반 레이아웃 유지
- 수행 1~5 단계 구조 유지
- 단계별 독립성과 전체 흐름 동시 확보

3. 공통 UI 기준
- 제목은 좌측 정렬
- 설정 입력은 반칸 들여쓰기
- 동일 종류의 입력 컨트롤은 동일 높이와 정렬 적용
- 긴 정책 문구의 가독성을 우선 확보

4. 공통 기능 기준
- 비교조건 콤보는 공통 규칙 사용
- 반복 수행과 반복이탈조건은 역할을 분리
- 완료정책은 반복 종료 이후 수행
- 용어는 프로젝트 전체에서 동일하게 유지

5. 구현 기준
- 공통 Row 생성 규칙을 사용한다.
- 화면별 개별 레이아웃 구현을 최소화한다.
- 동일 기능은 동일한 UI 패턴을 따른다.
- 신규 기능은 기존 수행 영역 내부에서 확장한다.

6. 검증 기준
□ 시나리오 흐름 유지
□ UI 일관성 유지
□ 저장/복원 일치
□ 정책 충돌 없음
□ 실제 화면 검증 완료

7. 유지보수 기준
- 구조보다 정책 변경을 우선 검토한다.
- 변경 시 히스토리와 MASTER_SPEC를 함께 갱신한다.
- 폐기·보류·채택 이유를 기록으로 남긴다.

8. 결론
매도설정 UI는 반복 검토를 통해 현재 구조로 확정되었으며,
향후 구현은 본 문서와 관련 누락보강 문서를 기준으로 유지한다.

MASTER_SPEC 누락보강 41
주제 : 히스토리 기반 용어 변경 및 UI 표준화 결정사항

출처 : 작업진행상황대화히스토리_8 비교 반영

1. 목적
프로토타입 단계에서 확정된 용어 변경과 UI 표준화 사항을 MASTER_SPEC에 반영한다.

2. 용어 변경
- '수행' 표기는 단계 중심 표현으로 변경 검토되어
  '1차 / 2차 / 3차' 체계 사용을 기준으로 관리한다.
- '이전수행취소' 명칭은 '매도리셋'으로 변경한다.
- '주문일괄취소' 명칭은 '일괄취소'로 단순화한다.
- 가격 기준 용어는 '주문가'로 통일한다.

3. UI 표준화
다음 항목은 전체 설정창에서 동일 기준을 적용한다.
- 입력 컨트롤 높이
- 폰트
- 포인트 크기
- 정렬
- 반칸 들여쓰기
- 상단 헤더 스타일

4. 기능 연계
후속매도 시간조건을 사용하는 경우
반복이탈조건의 제한시간은 자동으로 비활성화한다.

반복이탈조건 사용 시
→ 보유잔량 시장가 매도

반복이탈조건 미사용 시
→ 다음 신호로 이월

5. 반영 원칙
위 항목은 매도설정 UI의 실제 검토 과정에서 확정된 내용으로,
향후 동일 기능 구현 시 우선 기준으로 사용한다.

MASTER_SPEC 누락보강 55
주제 : 히스토리 기반 UI 문구 잘림 방지 및 폭 조정 기준

출처 : 작업진행상황대화히스토리_8 비교 반영

1. 목적
설정창에서 긴 정책 문구가 잘리거나 레이아웃이 무너지는 문제를 방지하기 위한
공통 배치 기준을 정의한다.

2. 기본 원칙
- 창 폭보다 설정 문구의 가독성을 우선한다.
- 필요한 경우 창 폭을 조정하되 과도한 확장은 지양한다.
- 한 항목의 폭 확보를 위해 다른 항목을 임의로 축소하지 않는다.

3. 폭 조정 기준
- 콤보박스는 표시 문구가 잘리지 않는 최소 폭을 확보한다.
- 입력칸은 숫자 자릿수를 고려하여 폭을 결정한다.
- 긴 설정문은 입력 영역을 우선 확보한다.

4. 창 크기 조정
- 전체 창 확장은 마지막 수단으로 사용한다.
- 먼저 여백과 불필요한 공간을 줄인다.
- 조정 후 실제 화면에서 확인한다.

5. 레이아웃 원칙
- 제목 영역은 최소화한다.
- 설정 입력 영역은 최대한 확보한다.
- 좌우 균형보다 실제 읽기 편한 배치를 우선한다.

6. 검증 절차
① 문구 잘림 확인
② 콤보 표시 확인
③ 입력칸 표시 확인
④ 창 크기 재조정 여부 결정

7. 검증 항목
□ 문구 잘림 없음
□ 콤보 전체 표시
□ 숫자 입력 표시
□ 그룹박스 밀림 없음
□ 화면 가독성 유지

8. 반영 원칙
본 기준은 반복적인 UI 수정 과정에서 확정된 실무 기준이며,
향후 모든 루틴 설정창의 폭 조정 원칙으로 적용한다.

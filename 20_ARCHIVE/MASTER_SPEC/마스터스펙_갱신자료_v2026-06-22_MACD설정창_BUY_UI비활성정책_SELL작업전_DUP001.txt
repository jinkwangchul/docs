============================================================
2. MACD 설정창 UI 운영 원칙
============================================================

2-1. 설정창의 역할
MACD매매루틴 설정창은 루틴의 매수/매도 조건 및 보조정책을 시각적으로 설정·검토하기 위한 UI이다.
현재 저장 기능은 비활성 상태이며, 실주문 연결 또는 rules.json 저장 구현 범위가 아니다.

2-2. UI 수정 범위 제한
설정창 UI 작업은 화면 배치, 용어 표시, 콤보박스 폭, 체크박스 기반 활성/비활성 표시, 설정 항목 구성 조정에 한정한다.
다음 작업은 금지한다.
- 실주문 연결
- 주문취소 실제 구현
- rules.json 저장 기능 활성화
- 엔진 로직 변경
- 신규 신호 개념 추가
- 기존 확정 용어 임의 변경

2-3. 사용자 확인 원칙
UI 수정은 화면 확인 후 진행한다.
작업 순서:
1) 현재 화면 또는 파일 확인
2) 수정 대상 특정
3) 수정 범위 확정
4) 파일 생성
5) 사용자 실행 확인

============================================================
3. BUY 구성 최종 구조
============================================================

BUY 구성은 다음 6개 영역으로 구성한다.

1. 적용필터
2. 매수방식
3. 평단관리
4. 미체결정책
5. 완료정책
6. 완료정책 세부설정

각 영역은 QGroupBox 기반으로 표시하며, 전체 창은 3열 구조를 유지한다.
창 폭은 항목 증가와 콤보박스 잘림 방지를 위해 충분히 넓게 설정한다.

============================================================
4. 공통 비활성 표시 정책
============================================================

4-1. 기본 원칙
체크박스가 있는 조건/행은 체크 해제 시 해당 조건의 설정 항목을 비활성 표시한다.
목적은 사용 중 조건과 미사용 조건을 즉시 구분하는 것이다.

4-2. 체크박스는 항상 유지
체크박스 자체는 다시 켤 수 있어야 하므로 비활성 처리하지 않는다.
비활성 처리 대상은 체크박스를 제외한 해당 행의 라벨, 입력칸, 콤보박스, 논리연산 콤보이다.

4-3. 적용 방식
체크 ON:
- 행 전체 설정 항목 활성
- 일반 색상

체크 OFF:
- 행 전체 설정 항목 비활성
- Qt disabled 상태의 회색 표시
- 사용자가 현재 미사용 조건임을 즉시 인식 가능

4-4. 예외
평단관리의 상단 기본 정책인 회차기준/예산기준/능동매수에는 이 비활성 정책을 적용하지 않는다.
평단관리에서는 조건별 동작 3행에만 적용한다.

============================================================
5. 적용필터 갱신사항
============================================================

5-1. 최종 구성
적용필터는 다음 3행으로 구성한다.
- RSI기간
- MACD선/시그널선
- 배열

5-2. 삭제 확정 항목
삭제된 항목:
- 20 이평 / 3 봉전대비 / 하락 / 0.2%

삭제 사유:
- 중복성 높음
- 화면 가독성 저하
- 공간 낭비
- 시그널선 콤보박스 잘림 문제 개선

5-3. MACD선/시그널선 행
구성:
- [MACD선/시그널선]
- [-/+]
- [1.0]
- [이하/이상]
- [AND/OR/NOT]

콤보박스 폭:
- MACD선/시그널선 문구가 잘리지 않도록 충분히 확보.
- -/+ 콤보도 지나치게 좁지 않게 설정.
- 값 입력칸도 1.0 표시가 답답하지 않도록 확대.

5-4. 비활성 정책
각 필터 행은 체크박스 기준으로 행 전체 활성/비활성 처리한다.

============================================================
6. 매수방식 갱신사항
============================================================

6-1. 구성
매수방식에는 다음 항목이 포함된다.
- 단일호가
- 상향 다중호가
- 다중지점
  - 시간 조건
  - 주문가/평단 조건
  - 마지막회차 능동매수
  - 설정가에 평단이 조건

6-2. 기존 로직 보존
다음 로직은 유지한다.
- 단일호가와 상향 다중호가의 상호배타
- 시간 조건과 평단 조건의 상호배타
- 단일호가 여부에 따른 시장가 선택 가능 여부
- 마지막회차 능동매수 활성 조건

6-3. 비활성 정책
체크 해제된 하위 조건은 관련 라벨, 입력칸, 콤보박스를 비활성 처리한다.
단, 기존 상호배타 로직과 충돌하지 않도록 기존 동작을 보존한다.

============================================================
7. 평단관리 갱신사항
============================================================

7-1. 상단 기본 정책
평단관리 상단에는 다음 정책이 존재한다.
- 회차기준
- 예산기준
- 능동매수

이 세 항목은 평단관리의 기본 정책이므로 체크 해제 시 행 전체 비활성 정책을 적용하지 않는다.
기존 동작 유지.

7-2. 조건별 동작
조건별 동작은 3행으로 구성한다.
예시:
- 20 이평 / 5 봉전 / 상향 / 0.15% / 이하 / 회차기준
- 20 이평 / 5 봉전 / 상하 / 0.15% / 이내 / 예산기준
- 20 이평 / 5 봉전 / 하향 / 0.15% / 이하 / 능동매수

7-3. 조건별 동작 비활성 정책
조건별 동작 3행은 체크박스 기준으로 행 전체 활성/비활성 처리한다.
체크 해제 시 입력칸, 라벨, 방향 콤보, 비교 콤보, 정책 콤보가 모두 비활성 처리된다.

============================================================
8. 미체결정책 갱신사항
============================================================

8-1. 구성
미체결정책은 다음 행으로 구성한다.
- 매수지점 [매회/일괄] [시간값] [초/분/봉] 이후 주문취소 [AND/OR]
- 주문가에 현재가 [상향/하향/상하] [값]% [이상/이하/이내/이탈] 일괄 주문취소 [AND/OR]
- 현재가에 평단가 [상향/하향/상하] [값]% [이상/이하/이내/이탈] 일괄 주문취소 [AND/OR]
- 평단가에 주문가 [상향/하향/상하] [값]% [이상/이하/이내/이탈] 일괄 주문취소 [AND/OR]

8-2. 용어 정책
“괴리율”이라는 단어는 폐기한다.
비교 표현은 다음 4개를 사용한다.
- 이상
- 이하
- 이내
- 이탈

8-3. 방향-비교 콤보 규칙
방향이 상향/하향일 때:
- 비교 콤보에는 이상/이하만 노출

방향이 상하일 때:
- 비교 콤보에는 이내/이탈만 노출

이 규칙은 미체결정책, 완료정책, 완료정책 세부설정 등 유사 가격 비교 UI에 공통 적용 가능하다.

8-4. 비활성 정책
미체결정책의 모든 행은 체크박스 기준으로 행 전체 활성/비활성 처리한다.

============================================================
9. 완료정책 갱신사항
============================================================

9-1. 기본 구성
완료정책은 다음 항목으로 구성한다.
- 현상태로 완료판정
- 마지막 주문 취소 이후 [n] [초/분/봉] 동안 수행
- 잔량매수
- 잔량매수 하위 가격관계 조건 3행
- 예산충족률
- 능동매수

9-2. 현상태로 완료판정
“현상태로 완료판정”은 완료정책의 핵심 기본 항목이다.
완료 조건 중 상단에 유지한다.

9-3. 마지막 주문 취소 이후
마지막 주문 취소 이후 항목은 수행 기간을 지정한다.
이 항목이 활성일 때 하위 잔량매수/능동매수 정책을 사용할 수 있다.

9-4. 잔량매수
잔량매수는 마지막 주문 취소 이후 수행되는 하위 정책이다.
잔량매수 체크 해제 시 잔량매수 하위 3행과 예산충족률 관련 설정은 비활성 처리한다.

9-5. 잔량매수 하위 3행
형식:
- [주문가/현재가/평단가] 에 [주문가/현재가/평단가] [상향/하향/상하] [0.25]% [이상/이하/이내/이탈] [매수안함/능동매수/잔량매수] [AND/OR/NOT]

기본 예시:
- 주문가에 현재가 상하 0.25% 이내 매수안함 AND

9-6. 예산충족률
예산충족률은 잔량매수 하위 조건과 함께 사용된다.
예산충족률 체크 해제 시 95 / % / 이상 / AND 등의 설정 항목도 같이 비활성 처리한다.

9-7. 능동매수
능동매수는 별도 하위 설정을 갖는다.
체크 해제 시 관련 가격기준, 방향, 값, 비교 조건을 비활성 처리한다.

9-8. 들여쓰기 정책
잔량매수와 능동매수는 너무 깊게 들여쓰지 않는다.
잔량매수/능동매수는 살짝 좌측으로 빼서 배치한다.
잔량매수 하위 3행은 잔량매수보다 반칸 정도만 안쪽으로 배치한다.
과도한 들여쓰기 금지.

============================================================
10. 완료정책 세부설정 갱신사항
============================================================

10-1. 그룹명
그룹명은 “완료정책 세부설정”으로 한다.

10-2. 총 6행 구조
완료정책 세부설정은 총 6행이다.

상단 3행:
- 기존 조건별 동작 3행 유지
- 이평/봉전 기준 조건

하단 3행:
- 가격관계 기반 조건 3행 추가

10-3. 기존 조건별 동작 3행
예시:
- 20 이평 5 봉전 상향 0.15% 이하 매수안함 AND
- 20 이평 5 봉전 상하 0.15% 이내 능동매수 AND
- 20 이평 5 봉전 하향 0.15% 이하 잔량매수 AND

10-4. 가격관계 기반 3행
형식:
- [주문가/현재가/평단가] 에 [주문가/현재가/평단가] [상향/하향/상하] [0.25]% [이상/이하/이내/이탈] [매수안함/능동매수/잔량매수] [AND/OR/NOT]

10-5. 중요 오해 방지
기존 조건별 동작 3행은 삭제하지 않는다.
사용자가 기존 내용 보존을 명확히 지시했다.
따라서 최종 구조는 기존 3행 + 추가 3행 = 총 6행이다.

10-6. 비활성 정책
완료정책 세부설정 6행 모두 체크박스 기준으로 행 전체 활성/비활성 처리한다.

============================================================
11. 콤보박스 표시 정책
============================================================

11-1. 메뉴 잘림 방지
콤보박스는 표시 문구가 잘리지 않도록 충분한 폭을 확보한다.
특히 다음 항목은 잘림 방지 대상이다.
- 시그널선
- 주문가
- 현재가
- 평단가
- 회차기준
- 예산기준
- 능동매수
- 잔량매수
- 매수안함
- 이상/이하/이내/이탈

11-2. 전체 창 폭
우측 완료정책 세부설정의 6행이 들어가므로 창 폭은 충분히 넓게 유지한다.
단, 가로 스크롤은 사용하지 않는 방향이 좋다.

11-3. 3열 비율
매수설정 영역은 큰 틀에서 1:1:1 비율을 유지하되, 실제 내용량에 따라 약간의 폭 조정은 가능하다.
중요한 것은 우측 영역의 콤보박스 잘림을 막는 것이다.

============================================================
12. SELL 구성에 적용할 예정 원칙
============================================================

SELL 구성은 다음 창에서 작업한다.

예상 작업 순서:
1. SELL 적용필터
2. SELL 매도방식
3. SELL 분할매도
4. SELL 미체결정책
5. SELL 완료정책
6. SELL 완료정책 세부설정

SELL 작업 원칙:
- BUY와 동일 패턴을 참고한다.
- 그러나 SELL 구조가 BUY와 완전히 같다고 단정하지 않는다.
- SELL 고유 항목을 먼저 확인한다.
- 확인 후 적용필터부터 단계별로 수정한다.
- 임의 삭제 금지.
- 명시된 항목만 수정.

SELL에 적용할 비활성 정책:
- 체크 해제된 조건/행은 행 전체 비활성
- 체크박스 자체는 활성 유지
- 기존 상호배타 로직 보존
- 기존 용어 보존

권장 삽입 위치:

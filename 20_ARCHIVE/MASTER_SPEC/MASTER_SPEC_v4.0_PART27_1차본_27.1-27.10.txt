MASTER_SPEC v4.0 정본

PART 27. rules.json 구조와 신호엔진 검증 1차본 (27.1 ~ 27.10)

27.1 문서 목적

본 문서는 MACD 루틴의 rules.json 구조와 신호엔진 검증 기준을 정의한다.

------------------------------------------------------------------------

27.2 적용 범위

-   rules.json
-   routine.json
-   신호엔진
-   설정 저장
-   설정 검증

------------------------------------------------------------------------

27.3 rules.json 역할

rules.json은 루틴의 조건과 정책을 저장하는 공식 설정 파일이다.

------------------------------------------------------------------------

27.4 routine.json 역할

routine.json은 루틴의 기본 정보와 메타데이터를 관리한다.

------------------------------------------------------------------------

27.5 신호엔진 역할

신호엔진은 rules.json을 해석하여 BUY/SELL 여부를 판단한다.

------------------------------------------------------------------------

27.6 설정 검증

설정 저장 전 필수 항목과 형식을 검증한다.

------------------------------------------------------------------------

27.7 데이터 무결성

필수 키 누락이나 잘못된 형식은 저장하지 않는다.

------------------------------------------------------------------------

27.8 테스트 기준

-   rules.json 로드
-   저장
-   검증
-   신호 생성
-   오류 처리

------------------------------------------------------------------------

27.9 구현 금지

-   미검증 설정 저장
-   임의 키 생성
-   사용자 승인 없는 구조 변경

------------------------------------------------------------------------

27.10 최종 원칙

rules.json은 신호엔진의 공식 입력 데이터이며 구조 변경은 프로젝트 기준
문서를 따른다.

END OF PART 27.1~27.10

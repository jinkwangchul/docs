MASTER_SPEC 누락보강 82
주제 : 히스토리 기반 루틴 등록·PLAN 생성·주문 실행의 전체 흐름

출처 : 작업진행상황대화히스토리_3~8 비교 반영

1. 목적
루틴 등록부터 PLAN 생성, 주문 실행, 종료까지의 전체 처리 흐름을
하나의 표준 절차로 정의한다.

2. 기본 원칙
- 루틴은 전략을 정의한다.
- PLAN은 전략을 실행 가능한 형태로 관리한다.
- 주문 엔진은 PLAN만 실행한다.

3. 전체 처리 순서
① 루틴 등록
② 루틴 선택 및 활성화
③ 신호 검출
④ BUY/SELL PLAN 생성
⑤ 주문 요청 생성
⑥ 주문 실행
⑦ 체결 감시
⑧ 상태 갱신
⑨ 완료·미완성·실패 판정
⑩ PLAN 종료 및 기록

4. 역할 분리
루틴
- 신호 생성
- 정책 정의
- 종료 조건 정의

PLAN
- 주문 대상 관리
- 상태 관리
- 생명주기 관리

주문 엔진
- 주문 전송
- 체결 확인
- 상태 반영

5. 구현 원칙
- 단계 순서를 임의 변경하지 않는다.
- 각 계층은 자신의 책임만 수행한다.
- 계층 간 직접 의존을 최소화한다.

6. 검증 항목
□ 루틴 등록
□ PLAN 생성
□ 주문 실행
□ 상태 전이
□ 종료
□ 로그
□ 복구

7. 반영 원칙
본 기준은 히스토리에서 확정된 루틴-PLAN-주문엔진 전체 흐름이며,
향후 모든 자동매매 루틴의 공통 처리 절차로 적용한다.

MASTER_SPEC 누락보강 81
주제 : 히스토리 기반 PLAN 확장성 및 신규 루틴 적용 원칙

출처 : 작업진행상황대화히스토리_3~8 비교 반영

1. 목적
PLAN 기반 구조를 유지하면서 새로운 자동매매 루틴을 추가할 수 있도록
확장 원칙을 정의한다.

2. 기본 원칙
- 신규 루틴은 기존 PLAN 구조를 재사용한다.
- 주문 엔진은 루틴 종류에 의존하지 않는다.
- 전략만 교체하고 실행 계층은 유지한다.

3. 루틴 추가 절차
① 루틴 등록
② 신호 정의
③ PLAN 생성 정책 정의
④ 종료 정책 정의
⑤ 공통 인터페이스 연결
⑥ 검증

4. 공통 유지 항목
- PLAN 생명주기
- 상태 머신
- 이벤트 처리
- 로그 형식
- 복구 절차

5. 변경 가능 항목
- 진입 조건
- 청산 조건
- 필터
- 재시도 정책
- 유효 조건

6. 구현 원칙
- 기존 루틴에 영향을 주지 않는다.
- 공통 인터페이스를 변경하지 않는다.
- 공통 엔진 수정은 최소화한다.

7. 검증 항목
□ 기존 루틴 영향 없음
□ 신규 루틴 정상 동작
□ PLAN 상태 일치
□ 로그 일치
□ 복구 일치

8. 반영 원칙
본 기준은 히스토리에서 확정된 PLAN 기반 확장 철학이며,
향후 모든 신규 자동매매 루틴 개발의 기본 기준으로 적용한다.

MASTER_SPEC v4.0 정본

PART 21. MACD 루틴 기본 철학과 신호 구조 1차본 (21.21 ~ 21.30)

21.21 신호 생성 순서

루틴은 다음 순서로 신호를 생성한다.

1.  데이터 검증
2.  기준봉 결정
3.  주신호 평가
4.  보조필터 평가
5.  조건그룹 평가
6.  최종 BUY/SELL 여부 결정

------------------------------------------------------------------------

21.22 조건 평가 원칙

모든 조건은 독립적으로 평가한 후 최종 결합한다.

조건 평가 과정에서 순환 참조를 허용하지 않는다.

------------------------------------------------------------------------

21.23 신호 일관성

동일 데이터에 대해 동일 설정이면 항상 동일 결과를 반환해야 한다.

무작위 요소를 포함하지 않는다.

------------------------------------------------------------------------

21.24 데이터 부족

봉 데이터 부족, 지표 계산 불가, 필수 입력 누락 시 BUY 또는 SELL을
생성하지 않는다.

signal=None으로 처리한다.

------------------------------------------------------------------------

21.25 예외 처리

예외가 발생해도 임의의 BUY 또는 SELL을 생성하지 않는다.

오류는 로그에 기록하고 비신호로 종료한다.

------------------------------------------------------------------------

21.26 성능 원칙

루틴은 반복 계산을 최소화한다.

동일 계산 결과는 가능한 범위에서 재사용한다.

------------------------------------------------------------------------

21.27 확장 원칙

새로운 필터와 조건은 기존 구조를 변경하지 않고 확장 가능한 형태로
추가한다.

------------------------------------------------------------------------

21.28 문서 우선 원칙

구현보다 MASTER_SPEC을 우선한다.

문서와 코드가 충돌하면 원인을 분석한 후 수정한다.

------------------------------------------------------------------------

21.29 테스트 기준

다음 항목을 반드시 검증한다.

-   BUY 생성
-   SELL 생성
-   비신호 처리
-   Signal Queue 저장
-   기준봉 변경
-   예외 처리

------------------------------------------------------------------------

21.30 PART21 결론

PART21은 MACD 루틴의 최상위 철학을 정의한다.

이후 PART22부터는 BUY 구조와 평단관리, PART23부터는 매수방식,
PART24부터는 완료정책, PART25부터는 SELL 구조를 상세 규정한다.

END OF PART 21.21~21.30

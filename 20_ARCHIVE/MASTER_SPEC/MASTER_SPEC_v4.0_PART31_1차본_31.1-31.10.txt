MASTER_SPEC v4.0 정본

PART 31. AI 구현절차와 사용자 승인 원칙 1차본 (31.1 ~ 31.10)

31.1 문서 목적

본 문서는 AI를 활용한 프로젝트 구현 절차와 사용자 승인 원칙을 정의한다.

------------------------------------------------------------------------

31.2 적용 범위

-   코드 생성
-   문서 생성
-   구조 변경
-   UI 변경
-   정책 변경

------------------------------------------------------------------------

31.3 구현 시작 조건

구현 전 다음을 확인한다.

-   MASTER_SPEC
-   최신 확정 정책
-   기존 코드
-   관련 문서

------------------------------------------------------------------------

31.4 사용자 승인

정책 변경, 구조 변경, 삭제 작업은 사용자 승인 후 수행한다.

------------------------------------------------------------------------

31.5 신규 개념

확정되지 않은 신규 개념은 구현하지 않는다.

------------------------------------------------------------------------

31.6 기존 코드 검토

기존 구현을 확인한 후 필요한 범위만 수정한다.

------------------------------------------------------------------------

31.7 문서 우선

문서와 구현이 충돌하면 원인을 분석하여 문서를 기준으로 정리한다.

------------------------------------------------------------------------

31.8 테스트

구현 후 단위 테스트와 통합 테스트를 수행한다.

------------------------------------------------------------------------

31.9 구현 금지

-   승인 없는 구조 변경
-   신규 정책 임의 생성
-   무관한 코드 수정
-   문서 없는 구현

------------------------------------------------------------------------

31.10 최종 원칙

AI는 제안을 수행하고 프로젝트 기준은 MASTER_SPEC과 사용자 최종 승인에
따른다.

END OF PART 31.1~31.10

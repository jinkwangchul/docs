MASTER_SPEC 갱신자료

Rule Mapper Preview / Merge Candidate 구조 확정

작성일: 2026-07-02

1. 목적

본 갱신은 지표추종 루틴 설정 UI와 실행 Rule 사이에 Preview/검증 계층을
추가하면서 프로젝트 구조가 변경된 내용을 MASTER_SPEC에 반영하기 위한
문서이다.

핵심 원칙은 다음과 같다.

-   UI 상태와 실행 Rule을 분리한다.
-   UI 변경이 즉시 실행 Rule을 변경하지 않는다.
-   실행 Rule 생성 전 Preview와 Diff 검증 단계를 둔다.
-   운영자 검토 이후에만 실제 Rule 생성 단계로 진행한다.

2. 아키텍처 변경

기존

UI → rules.json

변경 후

UI → indicator_follow_ui_state → Rule Mapper → Rule Preview → Rule Diff
→ 운영자 검토 → (향후 승인) → Engine Rule 생성

현재 구현 범위는 Preview/Diff까지이며 실제 Rule 저장 및 엔진 연결은
구현하지 않는다.

3. Rule Mapper

신규 구성요소

routine_rule_mapper.py

주요 함수

-   build_engine_rules_preview_from_ui_state()
-   compare_engine_rules_preview()

역할

-   UI State를 Preview 후보로 변환
-   기존 Rule과 Preview 차이 비교
-   저장하지 않음
-   실행하지 않음

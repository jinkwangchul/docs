MASTER_SPEC 누락보강 20
주제 : 엔진 연결 준비사항 및 구현 체크리스트

1. 목적
UI 구조 확정 이후 엔진 연결 시 필요한 준비사항과 검증 절차를 표준화한다.

2. 연결 순서
① UI 구조 확정
② 데이터 구조 확정
③ 저장(JSON) 구조 확정
④ JSON 로드 검증
⑤ UI-데이터 매핑
⑥ 데이터-엔진 매핑
⑦ 엔진 단위 테스트
⑧ 통합 테스트
⑨ 실주문 연계

3. 책임 분리
UI
- 설정 입력
- 상태 표시

루틴 엔진
- 신호 및 정책 판단

메인 엔진
- 주문
- 체결
- 자금
- 상태관리

4. 구현 체크리스트
□ 위젯명 변경 없음
□ 공통 함수 재사용
□ 상태제어 정상
□ JSON 저장 확인
□ JSON 로드 확인
□ 엔진 전달 확인

5. 검증 체크리스트
□ UI와 저장값 일치
□ 저장값과 엔진 입력 일치
□ 엔진 결과와 UI 표시 일치
□ BUY/SELL 공통 정책 유지
□ 예외 처리 확인

6. 금지사항
- UI에서 주문 실행
- 엔진에서 QWidget 접근
- UI와 엔진 직접 참조
- 저장 구조와 화면 구조 혼합

7. 장애 대응
- 최신 정상본 기준 복원
- 변경 범위 기록
- 원인 분석 후 재적용
- 임시 우회코드 누적 금지

8. 향후 문서화
- UI↔JSON 매핑표
- JSON↔엔진 매핑표
- 상태전이도
- 테스트 시나리오

9. 완료 기준
엔진 연결 완료는 기능 구현이 아니라
입력→저장→로드→엔진→결과가 모두 일관되게 동작하는 상태를 의미한다.

10. 장기 운영
모든 신규 루틴과 기능은 본 체크리스트를 통과한 뒤 프로젝트에 반영한다.

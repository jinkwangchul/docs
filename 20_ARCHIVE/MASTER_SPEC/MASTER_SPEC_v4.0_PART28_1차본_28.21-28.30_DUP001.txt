MASTER_SPEC v4.0 정본

PART 28. MACD 설정창 UI 구조 1차본 (28.21 ~ 28.30)

28.21 레이아웃 원칙

설정창은 좌우 균형과 가독성을 우선한다. 가로 스크롤 없이 주요 설정을
확인할 수 있어야 한다.

------------------------------------------------------------------------

28.22 그룹 독립성

공통설정, BUY, SELL, 검증 영역은 독립적으로 관리한다. 한 영역의 설정
변경이 다른 영역의 UI 배치를 변경해서는 안 된다.

------------------------------------------------------------------------

28.23 체크박스 정책

체크박스는 기능 활성 여부를 결정한다. 체크 해제 시 관련 입력 항목 전체를
비활성화한다.

------------------------------------------------------------------------

28.24 입력값 검증

숫자 입력, 콤보 선택, 조건식은 저장 전에 형식을 검증한다.

------------------------------------------------------------------------

28.25 표시 정책

비활성 항목은 회색 계열로 표시하여 활성 상태와 명확히 구분한다.

------------------------------------------------------------------------

28.26 저장 정책

저장은 검증 성공 후 수행한다. 검증 실패 시 기존 설정을 유지한다.

------------------------------------------------------------------------

28.27 복원 정책

설정 불러오기 시 구조와 버전을 확인한 후 화면에 반영한다.

------------------------------------------------------------------------

28.28 테스트 기준

-   레이아웃 유지
-   활성/비활성 전환
-   저장/불러오기
-   입력 검증
-   표시 상태

------------------------------------------------------------------------

28.29 구현 금지

-   UI 편의를 이유로 정책 변경
-   검증 없이 저장
-   활성 상태와 실제 정책 불일치

------------------------------------------------------------------------

28.30 최종 원칙

설정창은 프로젝트 정책을 정확하게 표현하는 인터페이스이다. UI 구현은
MASTER_SPEC의 정책을 그대로 반영해야 한다.

END OF PART 28.21~28.30

MASTER_SPEC v4.0 정본

PART 21. MACD 루틴 기본 철학과 신호 구조 1차본 (21.11 ~ 21.20)

21.11 Signal Queue 저장 규칙

Signal Queue는 루틴이 생성한 판단 결과를 메인 프로그램으로 전달하기 위한
공식 전달 계층이다.

저장 가능한 공식 주문 신호는 다음 두 가지뿐이다.

-   BUY
-   SELL

다음 항목은 Signal Queue에 저장해서는 안 된다.

-   signal=None
-   HOLD
-   WAIT
-   SKIP
-   ERROR
-   CANCEL
-   검사 결과
-   내부 상태값

Signal Queue는 주문 후보 저장소이며 내부 상태 저장소가 아니다.

------------------------------------------------------------------------

21.12 BUY 신호의 의미

BUY는 단순 주문 명령이 아니라 매수 판단 완료를 의미한다.

BUY 발생 시 루틴은 다음 정보를 메인 프로그램에 제공한다.

-   BUY 발생 시각
-   기준봉
-   기준가격
-   조건그룹
-   통과 필터
-   평단관리 방식
-   매수방식
-   완료정책
-   미체결정책

BUY 자체가 주문 실행을 의미하지 않는다.

------------------------------------------------------------------------

21.13 SELL 신호의 의미

SELL은 보유 포지션 종료 판단이다.

SELL 역시 주문 실행 명령이 아니다.

SELL 발생 시 다음 정보를 제공한다.

-   발생 시각
-   발생 조건
-   조건그룹
-   통과 필터
-   기준봉
-   기준가격

------------------------------------------------------------------------

21.14 기준봉 정책

지원 기준봉

-   0봉
-   1봉

기본값은 1봉이다.

보유 중 기준봉 변경은 허용하지 않는다.

------------------------------------------------------------------------

21.15 MACD 기준 지표

기본 지표

-   MACD Line
-   Signal Line
-   Oscillator

Oscillator는 기본 전환 판단에 사용한다.

------------------------------------------------------------------------

21.16 보조필터 적용 원칙

보조필터는 주신호를 보완한다.

보조필터 자체를 독립 신호로 사용하지 않는다.

지원 대상

-   RSI
-   이동평균
-   가격비교
-   가격박스
-   MACD Line
-   Signal Line

------------------------------------------------------------------------

21.17 루틴과 자금관리의 관계

루틴은 자금을 승인하지 않는다.

예산 부족은 자금관리 계층이 판단한다.

------------------------------------------------------------------------

21.18 루틴과 주문관리의 관계

루틴은 판단만 수행한다.

주문 생성, 체결, 정정, 취소는 주문관리 계층이 담당한다.

------------------------------------------------------------------------

21.19 구현 금지사항

-   루틴 내부 SendOrder 호출
-   루틴 내부 계좌 변경
-   루틴 내부 자금 승인
-   루틴 내부 검토관리 이동
-   HOLD 공식 신호 재도입
-   Signal Queue에 비신호 저장
-   테스트 편의를 위한 정책 변경
-   사용자 승인 없는 구조 변경

------------------------------------------------------------------------

21.20 최종 원칙

루틴은 판단한다.

메인은 실행한다.

BUY와 SELL만 공식 주문 신호이다.

비신호는 signal=None으로 처리한다.

루틴은 주문을 실행하지 않는다.

루틴은 계좌를 변경하지 않는다.

루틴은 자금을 승인하지 않는다.

END OF PART 21.11~21.20

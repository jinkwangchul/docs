Confirmed Auto-Trade Setting Window Role

- The auto-trade setting window is the strategy management workspace.
- It is responsible for routine definition review, routine instance management,
  stock composition, and historical/performance-oriented strategy inspection.
- The main monitoring window remains the current operation and immediate
  control surface.

Routine Tree Structure Contract

- The left routine tree is a two-level structure:
  - parent row: Routine Definition
  - child row: Routine Instance
- Stock rows are not inserted into the left routine tree.
- Parent definition selection is view-oriented:
  - show all child instances' stocks
  - do not implicitly select the first child instance
  - keep instance_id empty for the selected parent row metadata
- Child instance selection is target-oriented:
  - show only stocks assigned to that instance
  - keep the selected instance_id in row metadata

Routine Tree Name Display Contract

- Parent and child routine tree names use the same display rule.
- The display rule is:
  - 1 to 7 characters: show the original name unchanged
  - 8 or more characters: show the first 6 characters plus U+2026 ellipsis
- Examples:
  - 지표추종매매 -> 지표추종매매
  - 지표추종매매B -> 지표추종매매B
  - 지표추종매매BC -> 지표추종매매…
  - 1234567 -> 1234567
  - 12345678 -> 123456…
  - ABCDEFGHI -> ABCDEF…
- The fixed name QLabel width is calculated from the actual applied font
  metrics. The width must fit both:
  - seven full-width display characters
  - six display characters plus ellipsis
- The width calculation uses the maximum of horizontalAdvance and boundingRect
  width for the approved sample strings, plus internal safety padding.

Routine Tree Selection And Visual Contract

- The routine tree keeps centered name text inside the fixed name cell.
- The routine tree keeps the status columns unchanged:
  - 종목
  - 실행
  - 정지
  - 검토
- The profit/performance signal light is a meaningful status signal, not a
  decorative tree marker.
- The signal light uses the existing red/yellow/green visual language and must
  not be removed, hidden, weakened, or replaced by another symbol without a new
  approved contract.
- The name QLabel background is transparent.
- The selected row background must continue through the name area without a
  separate white or boxed background interrupting selection visibility.

MASTER_SPEC 누락보강 58
주제 : 히스토리 기반 매도설정 UI 시안 비교 및 최종 선택 근거

출처 : 작업진행상황대화히스토리_7~8 비교 반영

1. 목적
매도설정 UI 설계 과정에서 검토된 여러 시안을 비교하고,
최종 구조를 선택한 근거를 기록한다.

2. 비교 대상
- 단순 설정 나열형
- 카드형 시안
- 그룹박스 기반 시나리오형

3. 평가 기준
- 시선 흐름
- 설정 가독성
- 문구 잘림 여부
- 확장성
- 구현 난이도
- 기존 UI와의 일관성

4. 검토 결과
가. 설정 나열형
- 구현은 단순하나 흐름 파악이 어려움.

나. 카드형
- 시나리오 구분은 우수했으나 화면이 산만해지고
  긴 설정 문구 처리에 불리함.

다. 그룹박스 기반 시나리오형
- 기존 구조를 유지하면서 단계별 흐름 표현 가능.
- 긴 문구 대응과 확장성이 우수.
- 최종안으로 채택.

5. 최종 선택 이유
- 프로젝트 전체 UI와 일관성 유지
- 단계별 이해가 쉬움
- 향후 기능 추가 시 수행 블록 내부 확장 가능
- 불필요한 시각 요소 최소화

6. 향후 원칙
- 동일한 비교 기준으로 새로운 UI를 검토한다.
- 시제품은 실제 화면 검증 후 채택 여부를 결정한다.
- 채택·보류·폐기 사유를 함께 기록한다.

7. 반영 원칙
본 문서는 매도설정 UI 시안 검토의 공식 기록이며,
향후 UI 구조 변경 시 판단 기준으로 활용한다.

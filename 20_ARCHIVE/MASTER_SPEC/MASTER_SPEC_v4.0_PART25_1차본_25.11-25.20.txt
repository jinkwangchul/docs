MASTER_SPEC v4.0 정본

PART 25. MACD SELL 구조와 A/B/C 조건그룹 1차본 (25.11 ~ 25.20)

25.11 SELL 발생 순서

SELL 판단은 다음 순서로 수행한다.

1.  데이터 검증
2.  기준봉 확인
3.  A 그룹 평가
4.  B 그룹 평가
5.  C 그룹 평가
6.  조건 조합
7.  최종 SELL 판단

------------------------------------------------------------------------

25.12 기준봉

SELL은 사용자 설정 기준봉(0봉 또는 1봉)을 기준으로 평가한다.

------------------------------------------------------------------------

25.13 A 그룹 평가

A 그룹은 기본 SELL 조건을 담당한다.

각 조건은 독립적으로 평가한다.

------------------------------------------------------------------------

25.14 B 그룹 평가

B 그룹은 가격행동과 가격박스 관련 조건을 평가한다.

------------------------------------------------------------------------

25.15 C 그룹 평가

C 그룹은 MACD Line, Signal Line, 배열 및 추가 확인 조건을 평가한다.

------------------------------------------------------------------------

25.16 그룹 독립성

A/B/C 그룹은 서로의 내부 계산을 변경하지 않는다.

각 그룹의 결과만 최종 조합에 사용한다.

------------------------------------------------------------------------

25.17 SELL 신호 생성

최종 조합 규칙을 만족한 경우에만 SELL 신호를 생성한다.

------------------------------------------------------------------------

25.18 Signal Queue 연계

SELL 생성 후 Signal Queue에는 SELL만 저장한다.

비신호는 저장하지 않는다.

------------------------------------------------------------------------

25.19 구현 금지

-   조건그룹 순환 참조
-   그룹 간 내부값 변경
-   HOLD 생성
-   SELL 생성 후 루틴 내부 주문 실행

------------------------------------------------------------------------

25.20 최종 원칙

SELL은 조건그룹 기반의 판단 결과이며, 실제 주문 실행은 메인 프로그램이
담당한다.

END OF PART 25.11~25.20

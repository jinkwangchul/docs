MASTER_SPEC 누락보강 37
주제 : 테스트 정책 및 검증 절차

1. 목적
프로젝트의 모든 기능은 구현 완료가 아니라 검증 완료를 기준으로 확정한다.

2. 테스트 단계
① UI 단위 테스트
② 저장/복원 테스트
③ 루틴 엔진 테스트
④ 메인 엔진 테스트
⑤ 통합 테스트
⑥ 실운영 모의 테스트

3. UI 검증
- 레이아웃
- 활성/비활성
- 입력 제한
- 상태 표시
- 공통 스타일

4. 데이터 검증
- Model 생성
- JSON 저장
- JSON 복원
- 기본값 적용
- 버전 호환

5. 엔진 검증
- BUY/SELL/CANCEL 판단
- 조건 평가
- 정책 계산
- 예외 처리

6. 통합 검증
- UI→Model→JSON→Engine 흐름
- Engine 결과→UI 반영
- 상태 동기화
- 이벤트 처리

7. 예외 검증
- API 오류
- 데이터 누락
- 부분체결
- 미체결
- 재시작
- 긴급정지

8. 완료 기준
□ 기능 정상
□ 예외 처리 정상
□ 상태 일치
□ 로그 확인
□ 문서 반영 완료

9. 기록 원칙
- 테스트 목적
- 수행 결과
- 발견 문제
- 수정 내용
- 재검증 결과

10. 향후 보강
- 자동 테스트
- 회귀 테스트
- 시나리오 테스트
- 성능 테스트

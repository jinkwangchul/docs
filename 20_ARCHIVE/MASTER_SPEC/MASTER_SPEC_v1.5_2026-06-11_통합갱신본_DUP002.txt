[적색상태]
==================================================

적색은 자동 검토관리 이동이 아니다.

의미:

- 내부 데이터 불일치
- 키움 서버 정보와 내부 정보 불일치
- 데이터 신뢰 불가

조치:

- 자동매매 정지
- 운영자 판단
- 안정성검사 수행

[상태 정책]
==================================================

시작 OFF

→ 상태 비활성
→ 방식 비활성

시작 ON + 감시/대기

→ 방식 비활성
→ 청산 비활성

시작 ON + 매수/매도

→ 방식 활성
→ 청산 활성

[현황 색상]
==================================================

녹색
→ 정상 운영 가능

주황
→ 정상이나 다음 절차 진행 대상 없음

회색
→ 정지/비활성

빨강
→ 데이터 신뢰 불가

선택행 색상은 상태색이 아니다.

MASTER_SPEC v4.0 정본

PART 28. MACD 설정창 UI 구조 1차본 (28.11 ~ 28.20)

28.11 설정 저장

모든 설정은 검증 완료 후 저장한다.

------------------------------------------------------------------------

28.12 설정 불러오기

저장된 설정은 구조 검증 후 화면에 반영한다.

------------------------------------------------------------------------

28.13 기본값

필수 항목은 기본값을 제공할 수 있으나 사용자 설정을 우선한다.

------------------------------------------------------------------------

28.14 비활성 정책

체크 해제 시 해당 설정 행 전체를 비활성화한다.

------------------------------------------------------------------------

28.15 BUY 영역 연계

BUY 영역의 설정은 BUY 정책에만 영향을 준다.

------------------------------------------------------------------------

28.16 SELL 영역 연계

SELL 영역은 A/B/C 조건그룹 정책을 따른다.

------------------------------------------------------------------------

28.17 공통설정 연계

공통설정은 BUY와 SELL 모두에 적용될 수 있다.

------------------------------------------------------------------------

28.18 오류 처리

잘못된 설정은 저장하지 않으며 사용자에게 검증 결과를 제공한다.

------------------------------------------------------------------------

28.19 구현 금지

-   사용자 승인 없는 UI 구조 변경
-   정책과 UI 혼합
-   비활성 정책 무시

------------------------------------------------------------------------

28.20 최종 원칙

설정창은 정책을 정확히 표현해야 하며 구현 편의를 위해 정책을 변경해서는
안 된다.

END OF PART 28.11~28.20

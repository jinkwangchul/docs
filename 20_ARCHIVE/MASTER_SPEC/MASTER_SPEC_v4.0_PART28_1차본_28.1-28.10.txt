MASTER_SPEC v4.0 정본

PART 28. MACD 설정창 UI 구조 1차본 (28.1 ~ 28.10)

28.1 문서 목적

본 문서는 MACD 루틴 설정창의 공식 UI 구조를 정의한다.

------------------------------------------------------------------------

28.2 적용 범위

-   루틴 설정창
-   BUY 설정
-   SELL 설정
-   공통 설정
-   저장 구조

------------------------------------------------------------------------

28.3 기본 원칙

설정창은 설명 화면이 아니라 설정 컨트롤 패널이다.

------------------------------------------------------------------------

28.4 화면 구성

공통설정, BUY, SELL, 검증 영역으로 구성한다.

------------------------------------------------------------------------

28.5 공통설정

신호검출기준, 중복신호처리, 거래시간, 오류정책 등을 포함한다.

------------------------------------------------------------------------

28.6 BUY 구성

적용필터, 매수방식, 평단관리, 완료정책, 미체결정책으로 구성한다.

------------------------------------------------------------------------

28.7 SELL 구성

A/B/C 조건그룹과 조합 규칙을 사용한다.

------------------------------------------------------------------------

28.8 UI 활성 정책

체크 해제 시 해당 행 전체를 비활성 처리한다.

------------------------------------------------------------------------

28.9 테스트 기준

-   활성/비활성
-   저장
-   불러오기
-   설정 반영

------------------------------------------------------------------------

28.10 최종 원칙

UI는 정책을 표현하는 수단이며 정책 자체를 변경하지 않는다.

END OF PART 28.1~28.10

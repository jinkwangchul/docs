MASTER_SPEC 누락보강 105
주제 : 운영정책 통합 기준 (검토관리·긴급정지·재시작·시간정책·안정성검사)

출처 : 작업진행상황대화히스토리 3~8 비교 반영

목적
프로젝트 운영 과정에서 공통적으로 적용되는 운영 정책을 하나의 기준 문서로 통합한다.

1. 운영 기본 원칙
- 자동 처리보다 데이터 무결성을 우선한다.
- 운영 상태는 항상 실제 주문 상태와 일치해야 한다.
- 예외 상황은 검토 가능한 형태로 기록한다.

2. 검토관리
- 자동 처리 불가능한 예외를 관리한다.
- 상태 불일치, 복구 실패, 미해결 주문 등을 대상으로 한다.
- 운영자가 확인 후 복귀 또는 정리한다.

3. 긴급정지
- 모든 자동매매를 즉시 중단한다.
- 신규 주문을 차단한다.
- 현재 상태를 보존한다.
- 해제 전 안정성검사를 수행한다.

4. 프로그램 재시작
① 상태 저장 확인
② 재시작
③ 상태 복원
④ 안정성검사
⑤ 검토관리 대상 확인
⑥ 운영 재개

5. 시간정책
- 장전, 정규장, 동시호가, 장후 정책을 구분한다.
- 루틴은 시간 정책을 준수한다.
- 운영 상태는 시간 변경 시 즉시 재판정한다.

6. 안정성검사
- 주문 상태 일치
- 보유 상태 일치
- PLAN 상태 일치
- 로그 일치
- 복구 가능 여부 확인

7. 구현 원칙
- 운영 정책은 루틴과 독립적으로 적용한다.
- 긴급정지와 재시작은 동일한 무결성 기준을 사용한다.
- 운영 정책 변경 시 관련 문서와 구현을 함께 갱신한다.

반영 원칙
본 문서는 기존 누락보강 141~150 수준의 운영 정책을 통합한 기준 문서이다.

1. Registered Stock Status Counts

- `종목` is the total number of currently registered stocks in the current display scope.
- `운영` or `정지` is one normal trading-target group. The label follows the current global operation state.
- `운영` and `정지` are display labels for the same normal registered-stock group; they are not separate count groups.
- Normal trading-target count excludes `제외` and `검토` stocks.
- `제외` is a stock that remains registered but is excluded from the current auto-trade session.
- `검토` is a REVIEW_REQUIRED stock.
- The count equation is:

  종목 = 운영/정지 + 제외 + 검토

2. Status Views

- The default registered-stock-status view is the normal `운영/정지` view.
- The `운영/정지` view shows only normal registered stocks.
- The `운영/정지` view does not show excluded stocks or REVIEW_REQUIRED stocks.
- The `제외` view shows only currently excluded registered stocks.
- The `검토` view shows only REVIEW_REQUIRED stocks.
- Switching views does not mutate registration state.

3. Exclusion And Exclusion Release

- A normal `운영/정지` stock can be changed to `제외` by double-click or by the context-menu `제외지정` action.
- An excluded stock can be changed back to the normal `운영/정지` group by double-click or by the context-menu `제외해제` action.
- Both UI paths reuse the existing backend state-change path.
- The UI does not create a separate writer, storage file, or UI-only state.
- Exclusion is not registration removal.
- `제외지정` preserves registration information.
- After a state change, the current view and the top counts refresh from canonical state.

4. REVIEW_REQUIRED Protection

- REVIEW_REQUIRED stocks are managed through review management.
- REVIEW_REQUIRED stocks are shown in the `검토` view.
- `제외지정` and `제외해제` do not clear, bypass, or resolve REVIEW_REQUIRED.
- Review-management release and review handling remain governed by the existing review-management contract.

5. Registered Stock Status Table UI

- The row-number area is center aligned.
- Header, row-number, corner, and grid handling for this table are opt-in to the registered-stock-status table.

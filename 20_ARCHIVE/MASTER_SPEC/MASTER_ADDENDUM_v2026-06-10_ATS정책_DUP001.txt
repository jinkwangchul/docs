[ATS 최종 개념]

ATS는 독립 운영모드가 아니다.

수동운영
└ 정규장 거래시간
   + 선택된 ATS 거래시간

구조로 취급한다.

[상태판정]

정규장 시간
→ 매수/매도

장전 ATS 시간
→ 매수/매도

장후 ATS 시간
→ 조기마감/청산 정책 검사

장후 ATS 시간
+ 조기마감 존재
→ 감시/대기

장후 ATS 시간
+ 청산정책 존재
→ 감시/대기

장후 ATS 시간
+ 차단정책 없음
→ 매수/매도

[ATS 구분]

수동+ATS (보라)
→ 전역설정 사용

수동+ATS (주황)
→ 개별설정 사용

[절대규칙]

패치 먼저 작성 금지

1. 증상 확인
2. 이미지 확인
3. 코드 확인
4. 정책 확인
5. 충돌 분석
6. 수정범위 확정
7. 패치 작성

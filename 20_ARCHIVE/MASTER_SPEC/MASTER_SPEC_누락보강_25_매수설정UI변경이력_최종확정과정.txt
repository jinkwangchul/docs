주제 : 매수설정 UI 변경 이력 및 최종 확정 과정

1. 목적
매수설정 UI가 현재 프로토타입 구조로 정리되기까지의 변경 과정과
최종 확정된 설계 원칙을 기록한다.

2. 초기 구조
- 설정 항목 중심의 나열 방식
- 중복 설정이 많고 실행 흐름이 직관적이지 않았음

3. 주요 변경 과정
- 불필요한 설명 영역 제거
- 매수/매도 공통 구조 검토
- 체크박스 기반 활성 정책 적용
- 입력 컨트롤 통일
- 그룹별 재배치

4. 신호검출조건
- 루틴 진입의 최상위 영역으로 고정
- 입력 컨트롤 스타일을 전체 기준으로 사용

5. 매수방식
- 단일매수와 다중매수 구조 정리
- 주문 방식과 반복 정책을 분리
- 실행 순서 기준으로 재배치

6. 평단관리
- 회차기준
- 예산기준
- 능동매수
- 조건별동작
역할을 명확히 분리하고 중복을 제거

7. 미체결 및 완료정책
- 매수 완료와 미완성을 구분
- 후속 정책과 연계
- 비교조건 공통 규칙 적용

8. UI 확정 사항
- 제목 좌측 정렬
- 하위 설정 반칸 들여쓰기
- 입력 높이 및 폭 통일
- 숫자 입력 우측 정렬
- 콤보박스 잘림 방지

9. 프로토타입 상태
- 구조는 확정 단계
- 로직 연결은 후속 구현
- 세부 디자인은 향후 보완 가능

10. 향후 과제
- JSON 저장 구조 연결
- 엔진 매핑
- 상태전이 검증
- 실주문 연계 전 통합 테스트

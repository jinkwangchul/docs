MASTER_SPEC 누락보강 16
주제 : 매도설정 수행 1~5 상세 정책 및 연계 규칙

1. 목적
매도설정의 수행 1~5를 독립 기능이 아닌 하나의 연속 실행 흐름으로 정의하고,
각 수행 단계의 역할과 상호 연계 규칙을 명확히 한다.

2. 전체 실행 흐름
신호검출조건
↓
수행1 최초 매도방식
↓
수행2 후속매도반복설정
↓
수행3 미체결·가격비교
↓
수행4 반복이탈조건
↓
수행5 매도완료정책

각 단계는 이전 단계의 결과를 기반으로 다음 단계를 수행한다.

3. 수행1 : 최초 매도방식
목적
- 최초 매도 주문 방식 결정

구성
- 단일호가
- 다중호가

세부
- 단일호가 : 주문가 / 시장가
- 다중호가 : 상향·주문가기준·하향 설정

4. 수행2 : 후속매도반복설정
목적
- 최초 주문 이후 반복 수행 방식 정의

구성
- 선택없음
- 다중시간
- 다중비율

원칙
- 반복 정책만 정의하며 주문조건은 변경하지 않는다.

5. 수행3 : 미체결 및 가격비교
목적
- 미체결 대응 및 가격 재판단

구성
- 시간 기준 주문취소
- 가격 비교 기반 주문취소

비교 대상
- 주문가 ↔ 현재가
- 현재가 ↔ 평단가
- 평단가 ↔ 주문가

공통 비교규칙 적용
- 상향/하향 : 이상·이하·이내
- 상하 : 이내·이탈

6. 수행4 : 반복이탈조건
목적
- 반복 수행 종료 조건 정의

구성
- 가격비교
- 반복횟수
- 제한시간

연계
- 수행2에서 시간기준 반복 사용 시
  수행4 제한시간은 자동 비활성

7. 수행5 : 매도완료정책
목적
- 반복 종료 후 최종 처리

표시 규칙
반복이탈조건 미사용
→ 다음신호로 이월

반복이탈조건 사용
→ 보유잔량시장가매도

별도 선택 없이 자동 표시한다.

8. 공통 정책
- 각 수행은 독립 수정 가능
- 실행 순서는 고정
- 동일 정책은 모든 시나리오(A/B/C)에 동일 적용

9. 구현 원칙
- 수행 간 직접 위젯 참조 금지
- 공통 상태제어 함수 사용
- 연계 비활성은 공통 로직으로 처리

10. 향후 보강
- 수행별 엔진 매핑
- 수행별 상태전이
- 수행별 JSON 저장 구조

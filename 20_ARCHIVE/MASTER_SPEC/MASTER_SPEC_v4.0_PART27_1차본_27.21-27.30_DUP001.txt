MASTER_SPEC v4.0 정본

PART 27. rules.json 구조와 신호엔진 검증 1차본 (27.21 ~ 27.30)

27.21 설정 적용 순서

1.  routine.json 확인
2.  rules.json 로드
3.  데이터 검증
4.  기본값 적용
5.  신호엔진 초기화

------------------------------------------------------------------------

27.22 버전 호환

버전 정보가 존재하는 경우 호환성을 먼저 확인한다.

------------------------------------------------------------------------

27.23 필수 항목

필수 항목이 누락되면 해당 루틴은 활성화하지 않는다.

------------------------------------------------------------------------

27.24 선택 항목

선택 항목은 기본 정책을 적용할 수 있다.

------------------------------------------------------------------------

27.25 신호엔진 초기화

모든 검증 완료 후 신호엔진을 초기화한다.

------------------------------------------------------------------------

27.26 검증 실패

검증 실패 시 BUY/SELL 신호를 생성하지 않는다.

------------------------------------------------------------------------

27.27 테스트 기준

-   버전 확인
-   필수 키
-   선택 키
-   초기화
-   검증 실패 처리

------------------------------------------------------------------------

27.28 구현 금지

-   검증 우회
-   자동 구조 변경
-   임의 기본값 추가

------------------------------------------------------------------------

27.29 관련 문서

신호 구조는 PART21~26을 따른다.

------------------------------------------------------------------------

27.30 최종 원칙

신호엔진은 검증된 설정만 사용한다. 설정 무결성은 모든 신호 생성보다
우선한다.

END OF PART 27.21~27.30

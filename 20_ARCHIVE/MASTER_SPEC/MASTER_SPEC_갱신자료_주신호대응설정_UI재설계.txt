UI 정책 변경

주신호대응설정

기존 매수방식/다중지점/세부상황설정 구조는 폐기 대상으로 전환.

새 구조

□ 기본매수방식 - 단일호가 / 다중호가 - 선택없음 / 다중시간 / 다중비율

□ 가격비교매수 - 평단 >= 현재가 - 호가설정 - 다중지점 - 회차기준 -
예산기준 - 능동매수 - 평단 < 현재가 - 호가설정 - 다중지점 - 회차기준 -
예산기준 - 능동매수

설계 원칙

-   평단 이상/이하 정책은 완전 독립.
-   매도 UI와 동일한 레이아웃 철학 유지.
-   공용 생성 로직 재사용.
-   새 UI를 임의로 생성하지 않음.

향후 추가

-   직전가 대비 현재가 조건.
-   가격비교매수 독립 정책 확장.

MASTER_SPEC 누락보강 36
주제 : UI ↔ 데이터 ↔ 엔진 매핑 상세 규칙

1. 목적
UI, 설정 데이터, JSON, 루틴 엔진, 메인 엔진 간 데이터 전달 구조를 표준화한다.

2. 계층 흐름
UI
 ↓
설정 데이터(Model)
 ↓
rules.json
 ↓
루틴 엔진
 ↓
메인 엔진
 ↓
OpenAPI

3. UI 책임
- 사용자 입력
- 입력 검증
- 상태 표시
- 정책 편집

4. 데이터(Model) 책임
- UI와 엔진 사이의 중립 데이터
- 기본값 관리
- 직렬화 대상 유지

5. JSON 책임
- 영속 저장
- 버전 호환
- 설정 복원

6. 루틴 엔진 책임
- BUY/SELL/CANCEL 판단
- 조건 평가
- 실행 정책 생성

7. 메인 엔진 책임
- 주문 실행
- 체결 관리
- 자금 관리
- 운영 상태 관리

8. 매핑 원칙
- UI는 JSON을 직접 수정하지 않는다.
- JSON은 UI 위젯을 알지 않는다.
- 엔진은 UI 객체를 참조하지 않는다.
- 모든 변환은 공통 매핑 계층에서 처리한다.

9. 검증 체크리스트
□ UI→Model
□ Model→JSON
□ JSON→Model
□ Model→Engine
□ Engine 결과→UI

10. 향후 보강
- 매핑 테이블 자동 생성
- 데이터 검증기
- Schema 검증
- 계층별 단위 테스트

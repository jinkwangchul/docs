MASTER_SPEC 누락보강 91
주제 : 히스토리 기반 PLAN 중심 자동매매 프레임워크 릴리스 승인 기준

출처 : 작업진행상황대화히스토리_3~8 비교 반영

1. 목적
PLAN 중심 자동매매 프레임워크를 실제 운영 환경에 적용하기 전에
반드시 확인해야 하는 최종 승인 기준을 정의한다.

2. 기본 원칙
- 기능 구현 완료와 운영 가능 판정은 구분한다.
- 모든 핵심 시나리오가 검증된 경우에만 릴리스를 승인한다.
- 설계 철학과 구현 결과가 일치해야 한다.

3. 필수 검증 항목
□ 루틴 정상 동작
□ PLAN 생성 및 종료
□ 주문 실행
□ 상태 머신
□ 이벤트 처리
□ 로그 기록
□ 복구 처리
□ 검토관리 연계

4. 운영 검증
- 정상 시나리오
- 부분 체결
- 재시도
- CANCEL
- 프로그램 재시작
- 예외 복구

5. 승인 조건
- 치명적 구조 오류 없음
- 상태 불일치 없음
- 로그와 내부 상태 일치
- 기존 루틴과 호환성 유지
- 공통 인터페이스 유지

6. 승인 보류 조건
- 상태 전이 오류
- 복구 실패
- 중복 PLAN 생성
- 로그 누락
- 구조 변경으로 인한 호환성 문제

7. 반영 원칙
본 기준은 히스토리에서 확정된 PLAN 중심 프레임워크의 릴리스 승인 기준이며,
향후 정식 배포 전 최종 확인 문서로 적용한다.

[검토관리]
- 검토종목은 자동매매설정창 표시 금지
- 검토관리창 전용 관리
- 임시 복귀 버튼 유지
- 검토관리 컬럼 순서:
  코드 / 종목 / 위치 / 상태 / 사유 / 검출 / 보유 / 미수 / 미도 / 발생시간

[적색상태]
- 내부 데이터 불일치
- 키움 서버 정보와 내부 정보 불일치
- 데이터 신뢰 불가 상태
- 자동 검토관리 이동 금지
- 운영자 판단 후 안정성검사 수행

[재시작 정책]
프로그램 재시작 = 긴급정지 해제 = 매매시작 초기복구

보유/미수/미도 존재
→ 검토관리

없음
→ 종료상태
→ 시작 OFF

[표시 정책]
시작 OFF
→ 상태 비활성
→ 방식 비활성

시작 ON + 감시/대기
→ 방식 비활성
→ 청산 비활성

시작 ON + 매수/매도
→ 방식 활성
→ 청산 활성

[관제창]
- 검토종목 제거
- 검토관리종목 버튼으로 분리
- 검토관리 건수 표시

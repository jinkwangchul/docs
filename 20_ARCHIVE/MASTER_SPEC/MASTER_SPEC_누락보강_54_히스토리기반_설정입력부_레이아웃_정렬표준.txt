MASTER_SPEC 누락보강 54
주제 : 히스토리 기반 설정 입력부 레이아웃·들여쓰기·정렬 표준

출처 : 작업진행상황대화히스토리_8 비교 반영

1. 목적
설정 입력부의 시각적 일관성과 가독성을 확보하기 위한 공통 UI 배치 기준을 정의한다.

2. 기본 원칙
- 제목과 입력부를 명확히 구분한다.
- 제목은 최대한 좌측 정렬한다.
- 실제 설정 입력은 제목보다 반칸 들여쓴다.

3. 정렬 기준
- 제목은 동일 시작 위치를 유지한다.
- 입력 컨트롤은 동일 기준선에 맞춘다.
- 콤보박스와 입력칸 높이를 통일한다.

4. 간격 기준
- 각 행의 줄간격을 동일하게 유지한다.
- 체크박스와 콤보박스 사이에는 충분한 여백을 둔다.
- 설정 블록 간 간격은 행 간격보다 크게 유지한다.

5. 입력부 구성
- '제목 | 설정입력' 형식을 기본으로 한다.
- 긴 설정 문장은 입력 영역 폭을 우선 확보한다.
- 제목보다 설정 내용의 가독성을 우선한다.

6. 구현 원칙
- 모든 설정창에 동일한 레이아웃 규칙을 적용한다.
- 화면마다 임의의 들여쓰기나 정렬 방식을 사용하지 않는다.
- 공통 Row Builder 또는 공통 생성 규칙을 따른다.

7. 검증 항목
□ 제목 정렬
□ 들여쓰기 일관성
□ 줄간격
□ 컨트롤 높이
□ 문구 잘림 여부
□ 전체 가독성

8. 반영 원칙
본 기준은 실제 UI 반복 수정 과정에서 확정된 레이아웃 표준이며,
향후 모든 루틴 설정 화면의 공통 기준으로 유지한다.

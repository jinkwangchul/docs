MASTER_SPEC 누락보강 53
주제 : 히스토리 기반 비교조건 콤보 통합 규칙

출처 : 작업진행상황대화히스토리_8 비교 반영

1. 목적
방향 선택과 비교조건 선택의 동작을 프로젝트 전체에서 동일하게 적용하기 위한
공통 규칙을 정의한다.

2. 적용 대상
- 미체결정책
- 완료정책
- 조건별동작
- 능동매수
- 동일 비교 구조를 사용하는 모든 설정

3. 방향 콤보
- 상향
- 하향
- 상하

4. 비교조건 콤보
- 이상
- 이하
- 이탈
- -

5. 연동 규칙
상향 선택
→ 이상, 이하만 표시

하향 선택
→ 이상, 이하만 표시

상하 선택
→ 이탈, - 만 표시

방향 변경 시 비교조건은 즉시 갱신한다.

6. 구현 원칙
- 공통 함수로 제어한다.
- 화면마다 별도 구현하지 않는다.
- 모든 비교 UI는 동일한 동작을 따른다.

7. 검증 항목
□ 상향 전환
□ 하향 전환
□ 상하 전환
□ 비교조건 자동 변경
□ 저장/복원 후 동일 동작

8. 반영 원칙
본 규칙은 UI 검토 과정에서 확정된 공통 정책이며,
향후 모든 비교조건 입력부의 공식 기준으로 유지한다.

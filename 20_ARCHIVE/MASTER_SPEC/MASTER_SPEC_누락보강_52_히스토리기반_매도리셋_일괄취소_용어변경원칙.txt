MASTER_SPEC 누락보강 52
주제 : 히스토리 기반 매도리셋·일괄취소 용어 변경 배경 및 적용 원칙

출처 : 작업진행상황대화히스토리_8 비교 반영

1. 목적
매도 관련 정책에서 사용되는 용어를 실제 기능과 일치하도록 통일하고,
사용자가 의미를 직관적으로 이해할 수 있도록 표준화한다.

2. 변경 배경
초기 용어인 '이전수행취소', '주문일괄취소'는 실제 동작을 충분히
설명하지 못하고 UI 가독성을 떨어뜨리는 문제가 확인되었다.

3. 최종 용어
- 이전수행취소 → 매도리셋
- 주문일괄취소 → 일괄취소

4. 적용 원칙
- UI, JSON, 문서에서 동일 용어를 사용한다.
- 동일 기능에 서로 다른 명칭을 사용하지 않는다.
- 축약하더라도 의미가 유지되어야 한다.

5. 기능 의미
매도리셋
- 현재 진행 중인 매도 시나리오를 초기 상태로 되돌리는 정책.

일괄취소
- 현재 활성화된 관련 주문을 한 번에 취소하는 정책.

6. 구현 기준
- 화면 표기는 변경된 용어를 사용한다.
- 내부 코드 식별자는 필요 시 기존 이름을 유지할 수 있으나,
  외부 표시 용어와 혼용하지 않는다.

7. 검증 항목
□ UI 표기 일치
□ 문서 표기 일치
□ JSON 표기 일치
□ 기능 의미 일치

8. 반영 원칙
본 용어 변경은 실제 UI 설계 과정에서 확정된 결정사항이며,
향후 프로젝트 전체의 공식 용어로 유지한다.

완료 확인된 분리/정리:

- gui_windows.py 잔여 정리.
- 검토관리창 단일화.
- Runtime 공통함수 분리.
- state.json 저장 함수 통일.
- BaseStock 서비스 분리.
- ATS 관련 함수 분리.
- 현황 표시등 함수 분리.
- 자동매매설정창 기능 다수 분리.
- RoutineAssignWindow 분리.
- CenteredCheckBoxDelegate 분리.

구조개선 종료 판정 이유:
- 프로그램 실행 정상.
- 메인창 정상.
- 자동매매설정창 정상.
- 검토관리창 정상.
- 매매루틴지정창 정상.

남은 구조개선 후보는 존재하지만 현 단계에서 필수는 아니다.

============================================================
4. 재시작/긴급정지 최신 정책
============================================================

재시작 = 긴급정지 해제 = 매매시작 초기복구.

판정:
- 보유 있음 → 검토관리.
- 미수 있음 → 검토관리.
- 미도 있음 → 검토관리.
- 이월 있음 → 검토관리.
- 문제 없음 → 종료상태 + 시작 OFF.

자동복귀 금지.
이전 실행 상태 복원 금지.
주황 상태 복원 금지.

============================================================
5. 이월 최신 정책
============================================================

이월은 자동운영 연속 허용이 아니다.
이월은 보유를 청산하지 않고 넘기는 선택일 뿐이다.

확정:
- 조기마감 이월 → 청산 실행 금지.
- 자동마감 이월 → 청산 실행 금지.
- 청산 시간대와 겹쳐도 이월이 우선.
- 종료시점 이월 → 검토관리.
- 재시작시 이월 → 검토관리.
- 다음 시작점에서 운영자 확인 전 자동복귀 금지.

============================================================
6. 조기마감/자동마감 최신 정책
============================================================

조기마감/자동마감은 운영 종료 절차이다.
청산은 보유 제거 절차이다.
두 용어를 혼용하지 않는다.

조기마감 + 보유 있음 + 이월:
- 상태: 조기마감.
- 방식: 이월.
- 청산: 이월.
- 보유 유지.
- 현황 녹색.
- 자동청산 실행 금지.

대상 없음:
- 보유 0.
- 미도 0.
- 청산 대상 0.
- 정상이나 다음 절차 없음 → 주황.

============================================================
7. 현황 색상 최신 정책
============================================================

녹색: 정상 운영 가능.
주황: 정상이나 다음 절차 진행 대상 없음.
회색: 정지/비활성.
빨강: 데이터 신뢰 불가.

조기마감/자동마감 상태라는 이유만으로 주황 처리하지 않는다.
보유 또는 미도가 있으면 처리 대상이 있으므로 주황이 아니다.

============================================================
8. 정렬 유지 최신 정책
============================================================

해결된 문제:
- 헤더 정렬 후 운영방식 변경 시 종목 위치가 튀는 문제.
- 운영방식 변경 후 정렬, 다시 변경 시 정렬 전 자리로 돌아가는 문제.
- 선택 복원 과정에서 스크롤이 튀는 문제.

적용 원칙:
- 헤더 클릭 시점에만 정렬 수행.
- 정렬 결과 화면순서 저장.
- reload 중 sortItems 재실행 금지.
- loader는 _stock_visual_order를 읽기만 함.
- selectionModel().select()로 선택 복원.

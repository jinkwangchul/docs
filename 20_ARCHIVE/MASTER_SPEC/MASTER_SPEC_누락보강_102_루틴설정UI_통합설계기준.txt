MASTER_SPEC 누락보강 102
주제 : 루틴 설정 UI 통합 설계 기준

출처 : 작업진행상황대화히스토리 3~8 비교 반영

목적
루틴 설정창에서 확정된 모든 UI 정책을 하나의 문서로 통합하여
향후 모든 루틴 UI 구현의 기준으로 사용한다.

1. 기본설정
- 신호검출기준
- 거래시간
- 데이터 누락 정책
- 신호 재검증
- 오류 발생 처리
- 공통 활성/비활성 규칙

2. 적용필터
- RSI
- MACD
- 이동평균선
- 가격 비교
- 방향/비교 연산자 연동
- AND / OR / NOT 구성

3. 매수방식
- 단일호가
- 다중호가
- 다중시간
- 다중비율
- 능동매수
- 중복 방지 규칙

4. 평단관리
- 회차 기준
- 예산 기준
- 능동매수 기준
- 완료정책 연계

5. 미체결정책
- 시간 기준
- 가격 비교
- 주문취소
- 일괄취소
- 연산자 규칙

6. 완료정책
- 현상태 완료
- 마지막 주문 이후 완료
- 잔량매수
- 능동매수
- 조건별동작
- 예산 충족률

7. 매도설정
- 수행 단계 구조
- 반복 정책
- 반복이탈조건
- 완료정책
- 시나리오 중심 UI

8. 공통 UI 규칙
- Row Builder 공통 사용
- Show/Hide 정책
- 활성/비활성 정책
- 반칸 들여쓰기
- 공통 정렬
- 입력폭 표준화
- 문구 잘림 방지

9. 구현 원칙
- 모든 루틴 설정창은 동일한 UI 철학을 따른다.
- 공통 기능은 재사용한다.
- 화면별 예외 구현을 최소화한다.
- UI 변경 시 문서와 구현을 함께 갱신한다.

반영 원칙
본 문서는 기존 누락보강 111~120 수준의 루틴 설정 UI 정책을
통합 정리한 기준 문서이다.


MASTER_SPEC v4.0 - SYSTEM MASTER CONSOLIDATION v2 (FREEZE VERSION)

============================================================
0. PURPOSE
============================================================
This document is the FINAL CONSOLIDATION of PART21~PART25 (2차보강).
It defines a frozen system architecture for MACD trading engine design.

============================================================
1. CORE ARCHITECTURE PRINCIPLE
============================================================
ROUTINE = JUDGMENT ENGINE
MAIN    = EXECUTION ENGINE

This separation is absolute and non-negotiable.

============================================================
2. SIGNAL SYSTEM
============================================================
Allowed signals ONLY:
- BUY   : entry decision
- SELL  : exit decision
- None  : no signal state

STRICT RULE:
- HOLD is permanently forbidden
- No additional signal types allowed

Signal Queue:
- stores BUY / SELL only
- never stores internal states or debug values

============================================================
3. ROUTINE RULES (ALL PARTS)
============================================================
Responsibilities:
- data analysis
- condition evaluation
- signal generation

FORBIDDEN:
- order execution
- budget control
- account operations
- position management

Output:
- deterministic result required
- same input => same output
- error => None

============================================================
4. MAIN SYSTEM RULES
============================================================
Main system responsibilities:
- order execution
- budget allocation
- position management
- account state control
- final decision enforcement

Main is the ONLY execution authority.

============================================================
5. BUY STRUCTURE
============================================================
BUY is NOT an execution signal.

Rules:
- BUY = decision only
- execution depends on MAIN validation
- no direct order creation in routine

Averaging:
- handled only by MAIN
- never affects BUY logic

============================================================
6. SELL STRUCTURE
============================================================
SELL is NOT immediate liquidation.

Rules:
- SELL = exit decision only
- A/B/C condition groups required
- independent evaluation groups

Groups:
A = MACD core logic
B = price structure
C = confirmation indicators

SELL requires combined evaluation result.

============================================================
7. COMPLETION / CLOSE POLICY
============================================================
- completion = evaluation result
- not execution trigger

Main decides final closure state

============================================================
8. AVERAGING / ORDER STRATEGY
============================================================
- strategy is separate from signal logic
- single / multi / active buy strategies allowed
- no strategy can modify BUY logic

============================================================
9. ERROR HANDLING
============================================================
On any inconsistency:
- do NOT guess signal
- return None
- log error for MAIN handling

============================================================
10. GLOBAL RULES (FREEZE)
============================================================
- no HOLD allowed
- no new signal types
- no runtime rule mutation
- full deterministic evaluation required
- execution strictly in MAIN only

============================================================
END OF SYSTEM CONSOLIDATION v2 (FREEZE)

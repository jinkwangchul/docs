MASTER_SPEC 누락보강 05
주제 : 상태제어 및 비활성 정책

1. 목적
- 설정 사용 여부를 사용자가 즉시 식별할 수 있도록 상태를 일관되게 표시한다.
- UI 상태와 내부 상태가 서로 다르게 보이지 않도록 한다.

2. 기본 원칙
- 체크박스는 항상 활성 상태를 유지한다.
- 체크 해제 시 체크박스를 제외한 관련 컨트롤만 비활성 처리한다.
- 비활성은 Qt 기본 Disabled 상태를 사용한다.

3. 적용 대상
- 적용필터
- 매수방식
- 평단관리(조건 행)
- 미체결정책
- 완료정책
- 완료정책 세부설정
- 매도설정 시나리오

4. 상호배타 정책
- 상호배타 조건은 선택된 항목만 활성.
- 선택되지 않은 항목은 자동 비활성.
- 기존 상호배타 로직을 임의 변경하지 않는다.

5. 연계 비활성
- 상위 조건이 비활성이면 하위 설정도 함께 비활성.
- 수행2의 시간조건 사용 시 수행4 제한시간 비활성.
- 반복이탈조건 미사용 시 완료정책은 '다음신호로 이월' 표시.
- 반복이탈조건 사용 시 '보유잔량시장가매도' 표시.

6. 비교조건 표시 규칙
상향/하향 :
- 이상
- 이하
- 이내

상하 :
- 이내
- 이탈

방향 변경 시 표시 가능한 항목만 노출한다.

7. 상태 동기화
- UI 표시 상태와 내부 Enable 상태를 항상 동기화한다.
- 화면만 변경되고 내부 상태가 남는 현상을 금지한다.

8. 구현 원칙
- 상태 변경은 공통 함수로 처리한다.
- 동일 기능의 상태제어를 중복 구현하지 않는다.
- 삭제된 위젯 참조를 남기지 않는다.

9. 검증 항목
- 체크박스 동작
- 상호배타 동작
- 연계 비활성
- 콤보 표시 전환
- 런타임 AttributeError 여부

10. 향후 보강
- UI 상태와 rules.json 저장 상태 매핑
- 엔진 활성/비활성 연계
- 상태전이 다이어그램 작성

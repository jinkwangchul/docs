MASTER_SPEC 누락보강 57
주제 : 히스토리 기반 매도설정 UI 발전 과정 및 구조 변경 이력

출처 : 작업진행상황대화히스토리_7~8 비교 반영

1. 목적
매도설정 UI가 여러 차례의 검토를 거쳐 현재 구조로 발전한 과정을 기록하여
향후 동일한 시행착오를 방지한다.

2. 발전 단계
1단계 : 설정 항목 나열 방식
- 기능은 표현되었으나 흐름 파악이 어려움.

2단계 : 카드형 시안
- 시나리오 구분은 명확했으나 화면이 산만하고 설정 문구가 잘림.

3단계 : 그룹박스 기반 시나리오 방식
- 기존 그룹 구조를 유지하면서 수행 1~5 흐름을 적용.
- 현재 방향으로 확정.

3. 주요 변경 이력
- 카드형 UI 검토 후 보류
- 흰색 배경 제거
- 수행 번호 체계 도입
- 제목 좌측 정렬
- 설정 입력 반칸 들여쓰기
- 줄간격 및 컨트롤 높이 통일
- 긴 문구 표시를 위한 폭 조정

4. 확정된 설계 철학
- 설정보다 시나리오 흐름을 우선한다.
- 한 화면에서 전체 흐름을 이해할 수 있어야 한다.
- 동일한 UI 규칙을 모든 수행 영역에 적용한다.

5. 향후 변경 원칙
- 기존 수행 구조를 유지한 상태에서 확장한다.
- 구조 변경보다 항목 확장을 우선한다.
- 변경 시 이전 결정 이유를 함께 검토한다.

6. 반영 원칙
본 문서는 매도설정 UI의 발전 과정을 기록한 기준 문서이며,
향후 구조 변경 시 참조 문서로 사용한다.

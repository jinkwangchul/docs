6. 적색상태 정책
==================================================
적색 = 데이터 신뢰 불가

예:
- 서버/내부 불일치
- 잔고 불일치
- 데이터 이상

자동 검토관리 이동 금지.
운영자 판단 후 안정성검사.

==================================================
7. ATS 최종 정책
==================================================
ATS는 독립 운영모드가 아니다.

수동운영
+ 선택된 ATS 거래시간

정규장 → 매수/매도
장전 ATS → 매수/매도
장후 ATS → 조기마감/청산 정책 검사

장후 ATS + 조기마감 존재 → 감시/대기
장후 ATS + 청산정책 존재 → 감시/대기
차단정책 없음 → 매수/매도

표시:
전역 ATS = 보라
개별 ATS = 주황

==================================================
8. 표시 정책
==================================================
시작 OFF
→ 상태 비활성
→ 방식 비활성

시작 ON + 감시/대기
→ 방식 비활성
→ 청산 비활성

시작 ON + 매수/매도
→ 방식 활성
→ 청산 활성

색상:
녹색 = 정상
주황 = 정상이나 후속 절차 없음
회색 = 비활성
빨강 = 데이터 신뢰 불가

선택행 색상은 상태색이 아니다.

==================================================

이미 지정된 종목:
하단 연결종목에서 관리.

동일 루틴 중복 지정 금지.

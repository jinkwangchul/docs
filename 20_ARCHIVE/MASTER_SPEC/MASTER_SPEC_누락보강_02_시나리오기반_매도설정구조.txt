MASTER_SPEC 누락보강 02
주제 : 시나리오 기반 매도설정 구조

1. 설계 목적
- 매도설정을 단순 옵션 나열이 아닌 시나리오 단위로 구성한다.
- 각 시나리오는 독립적으로 수정·확장 가능해야 한다.

2. 시나리오 구성
- 설정 A
- 설정 B
- 설정 C
- 향후 확장 가능

3. 공통 구조
① 신호검출조건
② 수행 1 : 최초 매도방식
③ 수행 2 : 후속매도반복설정
④ 수행 3 : 미체결/가격비교
⑤ 수행 4 : 반복이탈조건
⑥ 수행 5 : 매도완료정책

4. 수행 1
- 단일호가
- 다중호가
- 주문가 기준 사용

5. 수행 2
- 선택없음
- 다중시간
- 다중비율

6. 수행 3
- 시간기준 미체결 취소
- 가격비교 취소
- 수행2와 연계

7. 수행 4
- 가격비교
- 반복횟수
- 제한시간
- 수행2의 시간기준 사용 시 제한시간 비활성

8. 수행 5
- 반복이탈조건 미사용 : 다음신호로 이월
- 반복이탈조건 사용 : 보유잔량시장가매도
- 별도 콤보 선택 없이 자동 표시

9. UI 규칙
- 소제목 좌측 정렬
- 설정 입력은 반칸 들여쓰기
- 줄간격 통일
- 입력 컨트롤 높이 통일
- 콤보 잘림 금지

10. 설계 철학
- 수행 순서가 곧 실행 흐름이다.
- 사용자가 시나리오를 위에서 아래로 읽을 수 있어야 한다.
- 설정과 실행 흐름이 동일한 UI를 유지한다.

# 작업재개참조 - 운영시간정책 재정의 v1

## 현재 결정

환경설정은 시간표만 관리한다.

종목별로 정규장/추가시장/수동운영/시간운영/조기마감 사용 여부를 결정한다.

## 핵심 구조

```text
환경설정
└─ 운영시간표
   ├ 정규장 시작/종료
   ├ 시간운영 전역 매수 시작/종료
   └ 추가시장1~3 시작/종료

종목설정
├─ 수동운영
├─ 시간운영
├─ 추가시장 사용 여부
├─ 감시/매도 정책
└─ 조기마감 정책
```

## 코드 방향

`gui_windows.py`에 시간정책을 직접 넣지 않는다.

신규 파일:

```text
time_policy.py
```

을 만들어 시간판정을 분리한다.

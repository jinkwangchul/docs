## 2. 현재 작업 완료 판정

운영환경설정 창 UI 정렬 작업은 실사용 가능 수준까지 완료.

현재 단계에서는 1~2px 단위 미세조정보다 저장/불러오기 검증이 더 중요하다.

UI 작업은 일단 중단하고, 다음 작업은 기능 검증으로 넘어간다.

## 3. 운영환경설정 UI 완료 내용

### 3.1 1번 운영시간 설정

완료:
- 제목 폰트 크기 정상화
- 제목과 정규장 라인 정렬
- 정규장 시작/종료 시간 열 정렬
- 정규장과 ATS 영역 사이 구분선 추가
- ATS 라벨 위치 조정
- 추가시간 이름 입력칸 배치
- 추가시간 저장 버튼 배치
- ATS 시작/종료 열을 정규장 시작/종료 열과 동일 위치로 정렬
- 거래시간 추가 문구 삭제

현재 구조:

1. 운영시간 설정
- 정규장
- 시작 시간
- 종료 시간

ATS
- 추가시간1 이름 + 저장 + 시작 + 종료
- 추가시간2 이름 + 저장 + 시작 + 종료
- 추가시간3 이름 + 저장 + 시작 + 종료

판정:
완료.

### 3.3 3번 수동운영 기본설정

완료:

- 정규장 / 추가시간 / 청산정책 적용 체크박스 배치
- 청산정책 적용 앞에 "/" 추가
- 청산정책 적용 체크박스 위치를 아래 자동마감/조기마감 이월 열과 맞춤

판정:
완료.

### 3.4 4번 자동마감 설정

완료:

- 시장가
- 현재가
- 익절/손절
- 익절 입력칸
- 손절 입력칸
- 이월

배치 완료.

익절/손절 입력칸은 익절/손절 옵션 소속으로 보이도록 붙여 배치한다.

판정:
완료.

### 3.5 5번 조기마감 설정

완료:

- 루틴매도
- 시장가
- 현재가
- 익절/손절
- 익절 입력칸
- 손절 입력칸
- 이월

판정:
완료.

---

### 3.6 6번 청산설정

완료:
- 정규장 종료 N분전
- 시장가
- 현재가
- 이월

정렬 기준:
- 6번 시장가 체크박스는 5번 현재가 체크박스 열과 일치
- 6번 현재가 체크박스는 5번 익절/손절 체크박스 열과 일치
- 6번 이월 체크박스는 6번 시장가와 현재가 사이 거리와 같은 간격으로 오른쪽 배치
- 6번 이월은 4/5번 이월과 억지 정렬하지 않음

판정:
완료.

## 4. 다음 작업 우선순위

### 1순위: 운영환경설정 저장/불러오기 검증

확인 대상:
- 정규장 시작/종료 저장
- ATS 추가시간 이름 저장
- ATS 추가시간 시작/종료 저장
- 2번 시간운영 기본설정 저장
- 3번 수동운영 기본설정 체크박스 저장
- 4번 자동마감 설정 저장
- 5번 조기마감 설정 저장
- 6번 청산설정 저장
- 저장 후 창 재오픈 시 동일하게 복원되는지 확인

검증 방식:
1. 운영환경설정 창 열기
2. 값을 변경
3. 저장
4. 프로그램 종료
5. 재실행
6. 운영환경설정 다시 열기
7. 값이 유지되는지 확인

---

### 2순위: 시간정책 재판정 누락 검증

남은 핵심 버그:
시작 직후 시간정책 재판정 1회 누락

의미:
프로그램 시작 직후 현재 시간이 운영시간인지 다시 계산해야 하는데, 이 재판정이 1회 누락될 가능성이 있음.

검증 기준:
- 프로그램 재시작
- 현재시간 기준 상태 재계산
- 감시/대기, 매수/매도, 감시/매도 상태가 즉시 맞게 표시되는지 확인

---

### 3순위: 재시작/긴급정지 복구 정책 적용

확정 정책:
프로그램 재시작과 긴급정지 후 복구는 같은 레벨의 재판정 프로세스로 취급한다.

재시작 또는 복구 시:
- 기존 상태 그대로 자동복구 금지
- 현재 조건 재계산
- 잔량/미수/미도 존재 시 검토종목 이동
- 정상일 때만 현재 시간정책에 따라 상태 재판정

---

### 4순위: 검토관리 기능 강화

검토관리로 보내야 하는 조건:
- 잔량 존재
- 미체결 매수 존재
- 미체결 매도 존재
- 익일이월
- 청산 실패
- 설정/파일 이상
- 루틴 참조 이상

추가 설계 예정:
- 검토관리 종목 조기마감 옵션
- 현재가 청산
- 시장가 청산
- 지정가 청산
- 익절 N%
- 손절 N%
- 마감 N분전 시장가 청산

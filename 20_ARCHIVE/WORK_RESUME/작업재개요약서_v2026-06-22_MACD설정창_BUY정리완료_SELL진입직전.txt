2. 작업 중 확정된 핵심 원칙
============================================================

2-1. 임의 삭제 금지
- 사용자가 삭제를 명시한 항목 외에는 임의 삭제 금지.
- 구조가 복잡해 보여도 먼저 확인하고 진행.

2-3. 설명 과다 금지

- 단, 참조문서는 세세하게 작성해야 한다.

2-4. 결과물 제공 원칙

- 가능한 개별 .py 파일 단위로 제공.
- 압축파일 생성은 지양.
- 다음 창으로 넘어가기 전에는 작업재개요약서와 마스터스펙 갱신자료를 파일로 제공.

2-5. 화면 확인 우선

3. BUY 구성 완료 내용
============================================================

3-1. 전체 창 크기
- 창 가로폭은 여러 차례 확대됨.
- 현재 기준 self.resize(1960, 780) 수준까지 확장됨.

  - 우측 완료정책 세부설정 6행 수용
  - 콤보박스 메뉴 잘림 방지
  - 가로 스크롤 없이 화면 내부에 수용

3-2. 적용필터 정리
기존 적용필터는 다음 행들을 포함했음:
- RSI기간
- MACD선/시그널선
- 20 이평 봉전대비 행
- 배열

수정 후:
- RSI기간
- MACD선/시그널선
- 배열

삭제 확정:
- “20 이평 | 3 봉전대비 | 하락 | 0.2%” 이평선 비교 행 전체 삭제

삭제 사유:
- 사용자가 빨간선으로 표시하여 이평선 비교 행 전체 삭제 요청
- 중복성 높음
- 공간 낭비
- 시그널선 콤보박스 잘림 개선을 위한 공간 확보

시그널선 개선:
- MACD선/시그널선 콤보 폭 확대
- -/+ 콤보 폭 확대
- 1.0 입력칸 확대
- 이하/이상 콤보 유지

비활성 정책:
- 적용필터의 각 행은 체크박스 기준으로 행 전체 활성/비활성 처리.
- 체크 해제 시 체크박스를 제외한 해당 행의 라벨, 입력칸, 콤보, 논리연산 콤보가 비활성.
- 체크박스는 사용자가 다시 켤 수 있어야 하므로 계속 활성.

현재 화면 판정:
- 적용필터 비활성 정책 정상 작동 확인.

5. 평단관리 완료 내용
============================================================

평단관리 상단 기본 정책:
- 회차기준
- 예산기준
- 능동매수

중요 확정:
- 평단관리 상단의 회차기준/예산기준/능동매수에는 체크 해제 시 행 전체 비활성 정책을 적용하지 않는다.
- 사용자가 명확히 “평단관리는 회차, 예산, 능동에는 적용 X, 조건별 동작만 적용”이라고 정정함.

따라서:
- 회차기준/예산기준/능동매수는 기존 방식 유지.
- 조건별 동작 3행만 체크박스 기준으로 행 전체 활성/비활성.

조건별 동작:
- 20 이평 / 5 봉전 / 상향·상하·하향 / 0.15% / 이하·이내 / 회차기준·예산기준·능동매수

적용 정책:
- 체크 해제 시 해당 조건별 동작 행의 입력칸, 라벨, 콤보 전체 비활성.
- 체크박스는 다시 켤 수 있어야 하므로 활성 유지.

현재 화면 판정:
- 조건별 동작 비활성 정상 작동 확인.
- 상단 기본 정책은 그대로 활성 유지되고 있음.

6. 미체결정책 완료 내용
============================================================

미체결정책 구성:
- 매수지점 [매회/일괄] [20] [초/분/봉] 이후 주문취소 [AND/OR]
- 주문가에 현재가 [상향/하향/상하] [0.25]% [이상/이하/이내/이탈] 일괄 주문취소 [AND/OR]
- 현재가에 평단가 [상향/하향/상하] [0.25]% [이상/이하/이내/이탈] 일괄 주문취소 [AND/OR]
- 평단가에 주문가 [상향/하향/상하] [0.25]% [이상/이하/이내/이탈] 일괄 주문취소 [AND/OR]

용어 확정:
- 괴리율 단어 폐기.
- 비교 표현은 이상/이하/이내/이탈 사용.

콤보 규칙:
- 방향이 상향/하향이면 비교 콤보에는 이상/이하만 보이도록.
- 방향이 상하이면 비교 콤보에는 이내/이탈만 보이도록.
- 이 규칙은 미체결정책뿐 아니라 유사한 모든 비교 콤보에 확장 적용할 수 있음.

비활성 정책:
- 각 행 체크 해제 시 해당 행 전체 비활성.
- 체크박스는 다시 켤 수 있어야 하므로 활성 유지.

현재 화면 판정:
- 미체결정책 비활성 정상 작동 확인.

7. 완료정책 완료 내용
============================================================

완료정책 구성:
- 현상태로 완료판정
- 마지막 주문 취소 이후 [3] [봉] 동안 수행
- 잔량매수
  - 주문가에 현재가 상하 0.25% 이내 매수안함 AND
  - 주문가에 현재가 상하 0.25% 이내 매수안함 AND
  - 주문가에 현재가 상하 0.25% 이내 매수안함 AND
- 예산충족률 95% 이상 AND
- 능동매수 | 주문가에 평단이 상하 0.15% 이내

중요 구조:
- 현상태로 완료판정과 마지막 주문 취소 이후는 상호 배타적 성격.
- 마지막 주문 취소 이후가 활성일 때 잔량매수/능동매수 하위 정책 사용.
- 잔량매수와 능동매수는 기존 로직에 따라 상호 배타적 성격이 적용됨.
- 잔량매수 하위 3행과 예산충족률은 잔량매수가 활성일 때 의미 있음.
- 능동매수 하위 항목은 능동매수가 활성일 때 의미 있음.

비활성 정책:
- 현상태로 완료판정 / 마지막 주문 취소 이후 로직은 기존 유지.
- 잔량매수 체크 해제 시 잔량매수 하위 3행 + 예산충족률 비활성.
- 예산충족률 자체 체크 해제 시 95 / % / 이상 / AND 비활성.
- 능동매수 체크 해제 시 능동매수 하위 항목 비활성.
- 각 상세행 체크 해제 시 해당 행 전체 비활성.

들여쓰기:
- 잔량매수와 능동매수는 살짝 좌측으로 빼서 배치.
- 잔량매수 하위 3행은 잔량매수보다 반칸만 들여쓰기.
- 너무 깊은 들여쓰기는 금지.
- 평단관리처럼 직관적인 계층감 유지.

현재 화면 판정:
- 완료정책 비활성 정상 작동 확인.
- 사용자가 “잘 되고 있어”라고 확인.

8. 완료정책 세부설정 완료 내용
============================================================

현재 그룹명:
- 완료정책 세부설정

구성:
상단 3행:
- 20 이평 5 봉전 상향 0.15% 이하 매수안함 AND
- 20 이평 5 봉전 상하 0.15% 이내 능동매수 AND
- 20 이평 5 봉전 하향 0.15% 이하 잔량매수 AND

하단 3행:
- 주문가에 현재가 상하 0.25% 이내 매수안함 AND
- 주문가에 현재가 상하 0.25% 이내 매수안함 AND
- 주문가에 현재가 상하 0.25% 이내 매수안함 AND

총 6행 구조.

중요한 대화 정리:
- 처음에는 기존 조건별 동작을 폐기하는 것으로 오해했으나, 사용자가 기존 내용 보존을 명확히 지시.
- 최종 확정은 기존 조건별 동작 3행 유지 + 가격관계 기반 3행 추가.
- 따라서 총 6행 구조가 맞음.

비활성 정책:
- 각 행 체크박스 기준으로 행 전체 활성/비활성.
- 체크 해제된 행은 회색 처리.
- 체크박스는 다시 켤 수 있도록 활성 유지.

콤보 잘림:
- 주문가/현재가/평단가 콤보가 잘리는 문제가 있었음.
- 전체 창 크기 확대 및 콤보 폭 조정으로 개선.

현재 화면 판정:
- 완료정책 세부설정 비활성 정상 작동 확인.

- BUY에서 정립된 패턴을 참고하되 SELL 고유 항목은 보존.
- 임의로 삭제하거나 이름 변경하지 말 것.

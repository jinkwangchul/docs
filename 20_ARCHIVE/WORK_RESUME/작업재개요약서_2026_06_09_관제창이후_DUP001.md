# 중요결정사항

## 검토관리 정책

검토종목은 관제창 일반목록에서 관리하지 않는다.

전용 검토관리창에서만 관리한다.

## 검토관리 컬럼

코드
종목
위치
상태
사유
검출
보유

## 적색 상태

의미:
- 내부 데이터 오류
- 서버 데이터 불일치
- 데이터 신뢰 불가

처리:
- 자동 이동 금지
- 적색 표시 유지
- 안정성검사 시 검토관리 분류

## 상태 색상

녹색
- 정상 운영 가능

주황
- 정상
- 다음 절차 없음

회색
- 정지/비활성

빨강
- 데이터 불일치
- 서버 비교 오류
- 운영 중단 필요

## 관제창

검토종목 표시 제거

검토관리종목 버튼으로 관리

# 작업재개요약서_추가갱신_STEP23_profit_rate_sell_signal_logic_완료

기준 시점:
- STEP22 sell.signals.macd_sell 구조 검증 완료 이후
- STEP23 profit_rate_sell + sell.signal_logic 검증 완료 직후

------------------------------------------------------------
1. 현재 상태 요약
------------------------------------------------------------

프로젝트는 계속 진행 가능하다.

HOLD 오염 복구 이후 BUY / SELL / signal=None 구조는 유지되고 있다.
STEP23에서 SELL 계층의 미구현 항목 중 profit_rate_sell과 sell.signal_logic OR/AND 결합이 구현·검증되었다.

------------------------------------------------------------
2. STEP23 완료 항목
------------------------------------------------------------

완료:
- sell.signals.profit_rate_sell 실제 평가
- 평단 대비 수익률 기준 적용
- sell.signal_logic OR 결합
- sell.signal_logic AND 결합
- context 기반 평단/현재가/보유수량 전달
- 보유 없음 상태에서 profit_rate_sell 평가 제외
- profit_rate_sell 미충족 시 signal=None 유지

검증 완료 테스트:
- test_sell_profit_rate_signal_logic_step23.py

검증 결과:
- OR profit only: SELL 성공
- AND both pass: SELL 성공
- AND profit fail: signal=None
- no holding: signal=None
- 최종 [OK] 통과

------------------------------------------------------------
3. STEP23 확정 구조
------------------------------------------------------------

함수 구조:
- evaluate_macd_routine(candles, config=None, context=None)

역할 분리:
- config: rules.json 기반 루틴 설정값
- context: 현재 종목 상태값

context 사용 값:
- avg_price 또는 평단
- current_price 또는 현재가
- holding_qty 또는 보유수량

profit_rate_sell 판정:
- 평단 대비 현재가 수익률 >= target_profit_rate

평가 제외:
- 보유 수량 없음
- 평단 없음 또는 0 이하
- 현재가 없음 또는 0 이하
- enabled=false

------------------------------------------------------------
4. 유지된 원칙
------------------------------------------------------------

유지:
- HOLD 재도입 없음
- BUY / SELL / signal=None 원칙 유지
- CANCEL 개념 변경 없음
- 실주문 연결 없음
- UI 변경 없음
- execution_enabled=False 유지 대상

중요:
- config에 평단/현재가를 넣지 않는다.
- 평단/현재가는 설정값이 아니라 상태값이므로 context로 전달한다.

작업재개요약서

대상: MACD 매매루틴 설정창 - 매도설정 UI

이번 작업에서 확정된 사항

1.  매도설정 상단

-   신호검출조건 기본식: A OR B OR C.
-   매도방식지정 영역 추가.
-   설정 A/B/C 선택 방식.
-   최소 1개 선택 유지.
-   기본값: 설정 A 선택.
-   현재 OR 방식만 사용. AND/NOT 미사용.

2.  설정 A/B/C 구조

-   각 설정은 독립적으로 동일한 구조.
-   1.  주신호대응 매도설정
-   2.  매도중상황변화대응
-   3.  후속매도반복설정
-   4.  반복이탈조건
-   5.  매도완료정책

3.  후속매도반복설정

-   소제목 기반 구조 적용.
-   단일호가 기준 주문가.
-   다중호가 기준 ‘주문가 1’.

4.  반복이탈조건

-   가격비교
-   반복횟수
-   제한시간
-   OR 개념으로 접근.
-   연산자 없음.
-   후속매도 시간조건 사용 시 제한시간 비활성.

5.  매도완료정책

-   반복이탈조건 선택 없음 → ‘다음신호로 이월’
-   반복이탈조건 선택 있음 → ‘보유잔량시장가매도’
-   체크박스는 표시용.

6.  UI

-   소제목 접기표시 적용.
-   반칸 들여쓰기.
-   입력컨트롤 통일.
-   콤보 잘림 다수 수정.
-   상단 폭 조정.
-   창 크기 조정.
-   상단 헤더에 신호검출조건/매도방식지정 표시.

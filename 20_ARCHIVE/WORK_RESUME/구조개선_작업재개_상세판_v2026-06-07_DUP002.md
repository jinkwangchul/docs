
# 구조개선_작업재개_상세판_v2026-06-07

# 1. 프로젝트 현황

프로젝트:
키움 자동매매 구조개선

현재 단계:
구조개선 마무리 단계

상태:
실전 검증 기반 UI/정책 정리 진행 중

--------------------------------------------------
# 2. 현재 확정된 상태 체계
--------------------------------------------------

실사용 상태

1. 감시/대기
2. 매수/매도
3. 자동마감
4. 긴급정지
5. 검토종목

검토종목은 정상 운영 상태가 아님.

--------------------------------------------------
# 3. 운영방식
--------------------------------------------------

운영방식은 2종류

1. 시간운영
2. 수동운영

--------------------------------------------------
# 4. 시간운영
--------------------------------------------------

감시시작 이후

감시/대기
→ 지정시간 도달
→ 매수/매도
→ 종료시간 도달
→ 자동마감

자동 전환

최근 검증 완료

- 프로그램 실행중 자동변경 확인
- 재시작 없이 자동변경 확인
- 화면 전체 깜빡임 제거 방향 채택

--------------------------------------------------
# 5. 수동운영
--------------------------------------------------

수동운영은

사용자가 직접 시간 입력

현재 논의 결과

추가시간설정은
수동운영 전용

시간운영 적용 안함

--------------------------------------------------
# 6. 추가시간설정
--------------------------------------------------

현재 확정

정규장 이전

청산정책 사용 가능

정규장 이후

청산정책 사용 불가

추가시간설정은
수동운영 전용 기능

--------------------------------------------------
# 7. 청산정책
--------------------------------------------------

청산 컬럼 존재

활성 시
노란색 강조

비활성 시
회색 처리

색상은 사용자가 선호한
형광 노랑 계열 채택

--------------------------------------------------
# 8. 시작 컬럼
--------------------------------------------------

최근 추가

역할

매매시작 여부 표시

상태컬럼과 역할 분리

상태컬럼은 상태 표시

시작컬럼은
자동판정 참여 여부 표시

--------------------------------------------------

현재 방향

긴급정지

# 작업재개요약서_v2026-06-07

## 현재 구조 확정사항

### 상태 체계
- 감시/대기
- 매수/매도
- 자동마감
- 검토종목(검토관리 전용)
- 긴급정지

### 운영방식
- 시간운영
- 수동운영

### 시간운영
- 감시시작 후 자동 시간판정 수행
- 지정시간 진입 시 매수/매도 자동 전환
- 종료시간 이후 자동마감 전환
- 주기적 자동 재판정 동작 확인 완료

### 수동운영
- 수동 시간 설정 가능
- 추가시간설정은 수동운영 전용
- 정규장 이전: 청산정책 사용 가능
- 정규장 이후: 청산정책 사용 불가

## 검토종목 정책

### 최종 확정
- 검토종목은 자동매매설정 목록에서 제거
- 검토관리 창에서만 관리
- 임시 '돌려보내기' 버튼 제공
- 돌려보내기 = MONITORING 복귀

## UI 확정사항

### 시작 컬럼
- 매매시작 여부 표시
- 신호등 역할 전담

### 상태 컬럼
- 상태만 표시
- 상태 앞 점 제거

### 청산 컬럼
- 활성 시 노란색 강조
- 비활성 시 회색

## 최근 확인 완료

- 시간정책 자동변경 동작 확인
- 감시/대기 자동 전환 확인
- 자동마감 전환 확인
- 청산정책 활성/비활성 확인
- 시작 컬럼 표시 구조 도입

2. 현재 가장 최근 UI 형태
============================================================

상단 탭:
- 구성
- 고급
- 검증

구성 탭:
- 매수설정 영역
- SELL 구성 영역

매수설정 헤더:
매수설정 | 메인신호 : OCR [-] [1] [이하] [상승] 전환 [0] 봉

현재 헤더 구현 요소:
- 매수설정 | : QLabel
- 메인신호 : OCR : QLabel
- 부호: QComboBox
- 기준값: QLineEdit
- 비교: QComboBox
- 방향: QComboBox
- 전환: QLabel
- 봉값: QLineEdit
- 봉: QLabel

세부항목:
- 적용필터
- 매수방식
- 평단관리
- 미체결정책
- 완료조건
- 완료정책

각 세부항목에는 실제 QCheckBox가 들어가야 한다.
현재 문자열 “☑” 방식은 폐기.
비활성 체크박스도 폐기.
더미라도 활성 QCheckBox로 둔다.

============================================================
3. 현재 멈춘 지점
============================================================

마지막 화면에서 입력값 위젯 폰트를 8pt/7pt/9pt 등으로 시험했다.
사용자는 8pt를 다시 요청했고, 이후 7pt가 너무 작아졌으며 9pt도 다시 시도하려 했다.
현재 최종 미확정.

다음 창에서는 현재 실제 파일 기준으로 화면을 본 뒤 다음 중 하나로 결정해야 한다.

후보:
- 입력 위젯 8pt 유지
- 입력 위젯 9pt 적용
- 입력 위젯 폰트보다 높이/폭 조정
- 고정문구와 입력값 간 폰트 차이 재조정

주의:
QComboBox/QLineEdit은 QLabel과 같은 pt라도 다르게 보인다.
단순 pt 비교로 판단하지 말고 실제 화면 기준으로 판단해야 한다.

STEP42-1:
현재 파일 기준 컴파일/실행 확인.

STEP42-2:

가능한 순서:
1. 입력값 폰트 8pt/9pt 중 하나 확정
2. 입력칸 높이 조정 여부 결정
3. 입력칸 폭 조정 여부 결정
4. 고정문구 폰트 조정 여부 결정

STEP42-3:
적용필터 내부 항목을 실제 컨트롤 형태로 세분화.
현재는 한 줄 체크박스 텍스트지만, 나중에는 다음처럼 나눌 가능성이 있다.

예:
[체크박스] RSI [45] [이하] [AND]
[체크박스] MACD [0] [이하] [NOT]
[체크박스] 20이평 조건 [NOT]
[체크박스] 이평배열 [OR]

단, 다음 창에서 바로 전체 구현하지 말고 “적용필터” 하나부터 잡는 것이 좋다.

STEP42-4:
적용필터 UI 모양이 잡히면 매수방식으로 이동.
그 다음 평단관리, 미체결정책, 완료조건, 완료정책 순서로 진행.

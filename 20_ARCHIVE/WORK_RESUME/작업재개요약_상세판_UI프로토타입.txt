작업재개요약서 (상세판)

1. 작업 목적

이번 작업은 지표추종매매 설정창(UI 프로토타입)의 구조를 실사용 가능한
수준으로 정리하는 것을 목표로 진행하였다. 기능 추가보다 레이아웃 안정화,
상태제어 복구, 구조 정리를 우선하였다.

2. 핵심 변경 사항

-   탭 기반 구조 제거 후 단일 화면 구성 유지.
-   기본설정 / 매수설정 / 매도설정을 하나의 화면에서 처리하는 구조 확정.
-   매수설정을 3열 구조로 재배치.

매수설정 최종 배치

1열 - 기본매수설정 - 반복매수설정

2열 - 상황변화대응 - 추가기능설정 - 순환설정

3열 - 이탈조건 - 회차마감

3. 이번 작업에서 해결한 문제

-   반복매수설정을 기본매수설정에서 분리.
-   순환설정을 독립 영역으로 이동.
-   불필요한 상위 제목(순환/마감설정 등) 제거.
-   여러 차례 발생한 RuntimeError(wrapped C/C++ object has been deleted)
    원인 분석.
-   순환설정과 이탈조건 활성/비활성 연결 복구.
-   순환설정 ‘다중시간’, ‘미체결’ 선택 시 이탈조건 제한시간 비활성 정상
    동작 확인.
-   설정창 생성 및 MainWindow 생성 확인.
-   py_compile 통과.

4. 분석 과정

여러 차례 레이아웃 수정 과정에서 wrapper, QFrame, height 고정, stretch
등의 영향 여부를 검토하였다. 최종적으로 단순 spacing 문제가 아니라 생성
구조와 상태제어 참조 방식이 원인임을 확인하였다. 동적 self 참조 대신
생성 시점의 로컬 참조를 사용하도록 수정하여 안정성을 높였다.

5. 현재 상태

-   UI 프로토타입은 마감 가능한 수준.
-   추가 레이아웃 수정은 얻는 것보다 위험이 큼.
-   구조 개선은 로직 연결 전 단계에서 진행하기로 결정.

4. 최근 해결된 주요 오류
============================================================

1. now_text NameError
- 원인: 분리 후 함수 정의 누락.
- 해결: 공통 runtime 함수로 정리.

2. clear_auto_close_runtime_metadata NameError
- 원인: import 누락.
- 해결: 필요한 파일에 import 추가.

3. short_close_method_text NameError
- 원인: gui_auto_trade_close.py import 누락.
- 해결: gui_auto_trade_policy에서 import.

4. 조기마감 이월인데 청산 실행
- 원인: 조기마감 옵션 이월과 청산정책 경로가 분리되어 있었음.
- 해결: 조기/자동마감 옵션의 이월이 청산정책보다 우선하도록 수정.

5. 조기마감 이월인데 청산 컬럼이 시장가/현재가 표시
- 원인: 표시 함수가 환경설정 청산정책을 보여줌.
- 해결: 조기/자동마감 이월이면 청산 컬럼도 이월 표시.

6. 정렬 후 운영방식 변경 시 종목이 튐
- 원인: reload 중 sortItems 재실행 및 _stock_visual_order 덮어쓰기.
- 해결: 헤더 클릭 시점에만 화면순서 저장, loader는 읽기만 수행.

7. 선택 복원 중 스크롤 튐
- 원인: selectRow()가 현재 행으로 스크롤 이동.
- 해결: selectionModel().select() 사용 및 스크롤 마지막 재적용.

============================================================
5. 최신 확정 정책
============================================================

재시작:
- 프로그램 재시작 = 긴급정지 해제 = 매매시작 초기복구.
- 보유/미수/미도/이월 존재 → 검토관리.
- 문제 없음 → 종료상태 + 시작 OFF.

검토관리:
- 자동매매설정창 표시 금지.
- 검토관리창 전용 관리.
- 자동복귀 금지.
- 복귀는 운영자 판단 후 수행.

조기마감/자동마감:
- 운영 종료 절차.
- 청산과 혼용 금지.
- 이월이면 청산 실행 금지.
- 이월 후 다음 시작점에서는 검토관리.

청산:
- 보유 제거 절차.
- 미수는 청산 대상이 아니며 검토관리 대상.
- 미도는 처리 대상이며 재시작 시 검토관리 대상.

현황색:
- 녹색: 정상 운영 가능.
- 주황: 정상이나 다음 절차 대상 없음.
- 회색: 비활성.
- 빨강: 데이터 신뢰 불가.

ATS:
- 독립 운영모드 아님.
- 수동운영 + ATS 시간 확장.

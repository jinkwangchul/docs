4. routine_display_name / routine.json 확인
------------------------------------------------------------

실제 routine.json 내용 확인:
- name: MACD매매루틴
- enabled: true
- entry_file: routine.py
- runtime.execution_enabled: false

실제 gui_routine_registry.py 확인:
- routine_display_name(path)는 routine.json 패키지 record.name을 우선 사용한다.

판정:
- 루틴 폴더명이 ZIP 해제 환경에서 #U 형태로 보이더라도 routine.json name 기준으로 GUI 표시명은 MACD매매루틴이 될 가능성이 높다.
- STEP31에서 routine_name == "MACD매매루틴" 비교를 사용하는 것은 현재 구조상 타당하다.

주의:
- 리눅스 컨테이너에서 ZIP을 해제하면 폴더명이 MACD#Ub9e4... 형태로 보인다.
- 그러나 routine.json 내부 name은 정상적으로 MACD매매루틴이다.
- 사용자 Windows 프로젝트에서는 실제 폴더명이 한글일 가능성이 높다.
- STEP29의 기본 경로 routines/MACD매매루틴/rules.json은 사용자 실제 프로젝트에서는 맞을 가능성이 높지만, ZIP 해제 환경처럼 폴더명이 깨진 경우에는 경로 인자 방식 실행이 필요하다.

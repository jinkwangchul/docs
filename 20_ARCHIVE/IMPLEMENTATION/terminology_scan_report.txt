용어 전수조사 및 1차 정리 보고서
========================================================================

확정 용어
- 종목 등록: 중앙 종목관리(stocks)에 종목을 추가
- 종목 삭제: 중앙 종목관리(stocks)에서 제거/archive 이동
- 루틴 지정: 종목과 매매루틴을 연결
- 루틴 해제: 종목과 매매루틴 연결을 제거
- 검토관리 이동/복귀: 상태관리 영역

금지/퇴출 후보
- 등록해제: 종목 삭제/루틴 해제/자동매매 해제가 섞일 수 있으므로 신규 UI 문구에서 사용 금지

1차 패치 대상
- gui_stock_register_window.py: 종목관리 창의 등록해제 표현 → 종목 삭제 표현
- gui_force_unregister_dialog.py: 종목 삭제 확인창의 등록해제 표현 → 삭제 표현
- gui_search_stock_register_dialog.py: changelog 문구 중앙 종목관리 유지 확인

수정 보류
- gui_routine_assign_window.py: 루틴 지정/루틴 해제 의미가 맞으므로 전역 수정 금지
- gui_auto_trade_unregister.py: 자동매매 등록해제 의미일 수 있어 별도 판정 필요
- gui_review_required_window.py / gui_global_review_required_window.py: 검토관리 용어 단계에서 별도 정리

MASTER_SPEC_추가갱신_프로젝트_검증매트릭스_Verification_Matrix_2026-07-03

목적
- 기능, 설계, 테스트, 운영 검증 항목을 하나의 매트릭스로 관리하기 위한 기준 문서이다.

==================================================
검증 영역
==================================================

[아키텍처]
□ 책임 분리
□ 단방향 의존성
□ State Machine 준수

[Runtime]
□ JSON 규격 준수
□ ID 참조 무결성
□ 상태 일관성

[주문 파이프라인]
□ Candidate
□ Approval
□ Policy
□ Preflight
□ Adapter Preview

[실주문 준비]
□ ExecutionController
□ Final Execution Guard
□ Order Lock
□ Request Hash
□ Execution Request

[운영]
□ Review
□ Recovery
□ Audit
□ Runtime 무결성

==================================================
검증 기준
==================================================

각 항목은 다음 5단계를 모두 통과해야 한다.

1. 설계 검토
2. 코드 구현
3. 단위 테스트
4. 회귀 테스트
5. 문서 갱신

==================================================
검증 결과 상태
==================================================

NOT_STARTED
IN_PROGRESS
VERIFIED
BLOCKED
DEFERRED

==================================================
판정 원칙
==================================================

VERIFIED 상태는 다음 조건을 모두 만족해야 한다.

- 구현 완료
- 테스트 통과
- Runtime 영향 확인
- 회귀 테스트 통과
- MASTER_SPEC 반영 완료

==================================================
최종 원칙
==================================================

기능의 구현 완료와 검증 완료는 동일하지 않다.
프로젝트는 검증 완료를 기준으로 다음 단계로 진행한다.

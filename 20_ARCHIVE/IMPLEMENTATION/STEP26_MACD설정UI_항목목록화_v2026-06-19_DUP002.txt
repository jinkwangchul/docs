2. UI에 즉시 올릴 수 있는 확정 항목
------------------------------------------------------------

다음 항목은 STEP23까지 검증된 범위와 직접 연결되므로 UI 항목 후보로 올릴 수 있다.

[공통]
1. 루틴 사용 여부
- rules.enabled
- 기본값: true

2. 신호 전용 모드
- signal_only
- 현재 유지값: true

3. 실제 실행 허용
- execution_enabled
- 현재 유지값: false
- UI에 표시하더라도 잠금/비활성 권장
- 실주문 전환 전까지 사용자가 쉽게 변경하지 못하게 해야 함

[SELL 공통]
4. SELL 사용 여부
- sell.enabled

5. SELL 신호 결합 방식
- sell.signal_logic
- 값: OR / AND
- STEP23 검증 완료

[MACD SELL]
6. MACD SELL 사용 여부
- sell.signals.macd_sell.enabled

7. MACD SELL delay_bar
- sell.signals.macd_sell.delay_bar
- 기준봉/지연봉 설정

8. MACD SELL 조건그룹 표시
- sell.signals.macd_sell.groups
- 단, UI에서 복잡한 조건 편집을 바로 구현할지 여부는 별도 판단 필요

[수익률 SELL]
9. 수익률 SELL 사용 여부

10. 목표 수익률
- sell.signals.profit_rate_sell.target_profit_rate 또는 profit_rate_percent
- 기준: 평단 대비 현재가 수익률
- STEP23 검증 완료

11. 수익률 기준 설명 표시

- UI 문구: 평단 대비 현재가 수익률

------------------------------------------------------------
3. UI에 표시 가능하지만 비활성/잠금 권장 항목
------------------------------------------------------------

다음 항목은 사용자 이해를 위해 표시할 수는 있으나,
아직 구현 또는 확정 전이므로 편집은 막는 것이 안전하다.

1. BUY 구조 확장 영역
- BUY 설정은 현재 기본 구조만 표시
- 지속매수/평단중심/다중매수와 연결되므로 편집 잠금 권장

2. BUY delay_bar
- 기존 구조상 존재 가능
- 다만 향후 BUY 구조 개편 가능성이 있으므로 최소 노출 권장

3. BUY 조건그룹
- 기존 groups 표시 가능
- UI 편집은 보류 권장

4. CANCEL 영역
- 루틴 CANCEL은 향후 별도 개념 정리 필요
- 현재 UI에서는 숨김 또는 "추후 확정" 표시 권장

5. 다중매수/다중호가/다중지점
- UI 항목으로 별도 섹션 예약 가능
- 편집 불가 상태 권장

비신호 설명:
- "조건 미충족은 별도 신호가 아니며 signal=None으로 처리됩니다."
- "HOLD 신호는 사용하지 않습니다."

7. UI 구현 시 주의할 점
------------------------------------------------------------

1. UI는 rules.json을 직접 파괴하면 안 된다.
- 기존 키 유지
- 알 수 없는 키 보존
- 저장 전 백업 또는 미리보기 필요

2. 기본값을 임의로 바꾸지 않는다.
- 특히 execution_enabled=false 유지
- profit_rate_sell.enabled 기본 false 유지

3. BUY 쪽은 임의 확장 금지
- UI에서 사용자가 편집할 수 있게 만들기 전 개념 확정 필요

4. CANCEL은 표시하더라도 설명 수준
- 실제 설정/동작/신호 생성은 아직 금지

5. context 값은 UI 설정값이 아니다.
- 평단
- 현재가
- 보유수량
위 값은 실시간 상태값이므로 rules.json에 저장하지 않는다.

------------------------------------------------------------
8. UI 구현 전 선행 확인 필요 항목
------------------------------------------------------------

UI 구현 전 사용자 확인이 필요한 항목:

1. UI에서 BUY 설정을 최소 표시만 할지, 아예 숨길지
2. SELL 설정을 먼저 구현할지, BUY/SELL 화면 전체 틀을 먼저 만들지
3. profit_rate_sell 기본 enabled 값을 false로 유지할지
4. target_profit_rate 입력 단위를 %로 고정할지
5. OR/AND 선택 UI를 콤보박스로 할지 라디오버튼으로 할지
6. 조건그룹 편집은 이번 단계에서 제외할지
7. 실행 허용 execution_enabled는 잠금 표시할지 완전 숨길지

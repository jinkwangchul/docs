------------------------------------------------------------
1. STEP23 작업 목적
------------------------------------------------------------

STEP23의 목적은 MACD매매루틴 SELL 계층에서 남아 있던 미구현 항목을 구현·검증하는 것이다.

대상:
- sell.signals.profit_rate_sell 실제 평가
- sell.signal_logic OR/AND 실제 결합

제외:
- HOLD 개념 재도입 금지
- CANCEL 개념 구현/변경 없음
- 실주문 연결 없음
- UI 변경 없음
- 평단 기반 지속매수/능동매수 개념 구현 없음

------------------------------------------------------------
2. 확정 기준
------------------------------------------------------------

profit_rate_sell 기준:
- 평단 대비 현재가 수익률 기준
- 현재가 >= 평단 * (1 + target_profit_rate / 100) 이면 profit_rate_sell 만족

평가 제외:
- 보유 수량 없음
- 평단 없음 또는 평단 0 이하
- 현재가 없음 또는 현재가 0 이하
- profit_rate_sell.enabled=false

context 사용 기준:
- config는 rules.json 설정값
- context는 현재 종목 상태값
- 평단, 현재가, 보유수량은 context로 전달

함수 방향:
- evaluate_macd_routine(candles, config=None, context=None)
- 기존 호출을 깨지 않도록 context 기본값은 None

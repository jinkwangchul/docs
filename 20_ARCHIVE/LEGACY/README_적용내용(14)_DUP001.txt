# 메인 관제창 중앙 stocks 기준 표시 패치 v2

적용 파일:
- gui_main_table_loader.py

수정 내용:
1. 메인 좌측 루틴 종목수
   - 중앙 stocks/config.json 기준
   - 루틴 미지정 종목 제외
   - 검토관리/검토종목 상태 제외
   - 자동매매설정창 하단 목록 기준과 맞춤

2. 메인 우측 실행 중 자동매매 종목표
   - 루틴 미지정 종목 표시 제외
   - 실제 루틴 지정 종목만 표시

기대 결과:
- 메인 좌측 MACD 종목수와 자동매매설정창 MACD 종목수가 일치해야 합니다.
- 우측 실행 종목표에서 '미지정' 종목은 사라져야 합니다.

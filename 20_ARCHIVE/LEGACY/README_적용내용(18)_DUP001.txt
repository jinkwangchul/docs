# 선택 종목 삭제 중앙 stocks 기준 패치

적용 파일:
- gui_stock_register_window.py

수정 내용:
1. 선택 종목 삭제가 더 이상 기초종목.txt를 찾지 않습니다.
2. 중앙 stocks/종목폴더를 archive로 이동합니다.
3. 삭제 전 config.json의 루틴 연결을 비웁니다.
4. 기존 종목 데이터를 완전 삭제하지 않고 archived_stocks/ 로 보존합니다.
5. 처리불가 종목은 기존처럼 리포트에 남깁니다.

주의:
- 이 패치는 종목 폴더를 완전 삭제하지 않습니다.
- archive 이동 방식이므로 필요 시 복구 가능합니다.

확인:
1. 파일 교체
2. python gui_main.py 실행
3. 종목등록설정창에서 미등록/안전 종목 1개 선택
4. 선택 종목 삭제 실행
5. 중앙 종목관리 목록에서 사라지는지 확인
6. archived_stocks/ 아래로 이동됐는지 확인

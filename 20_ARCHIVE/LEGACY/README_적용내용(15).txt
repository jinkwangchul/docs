# 종목등록설정창 중앙 종목관리 1차 정리 패치

적용 파일:
- gui_stock_register_window.py

수정 내용:
1. 창 제목 표시
   - "기초종목.txt 등록 종목 관리" -> "중앙 종목 관리"

2. 종목 runtime 조회
   - 이 파일 안의 `stock_runtime_dirs_for_stock()`가 더 이상 루틴폴더를 직접 스캔하지 않습니다.
   - `gui_stock_data.assigned_runtime_dirs_for_stock()`로 위임합니다.
   - 중앙 stocks/ 구조가 있으면 stocks/종목폴더 기준으로 동작합니다.

3. 문구 정리
   - 화면/리포트/체인지로그의 "기초종목.txt" 표현을 "중앙 종목관리" 중심으로 일부 정리했습니다.

주의:
- 종목 완전 삭제/보존 정책은 아직 확정하지 않았으므로,
  delete_selected_stock()의 실제 삭제 흐름은 다음 단계에서 별도로 다뤄야 합니다.
- 이번 패치는 종목 폴더 삭제/이동을 수행하지 않습니다.

확인:
1. 파일 교체
2. python gui_main.py 실행
3. 종목등록설정창 제목 확인
4. 등록 루틴/운영상태 표시 확인
5. 루틴 해제/지정 후 표시 갱신 확인

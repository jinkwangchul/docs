# 루틴 정책 초안 v10 - Position Policy 가격제한/추가진입 트리거 분리

핵심:
- 가격제한 정책과 추가진입 트리거 정책을 분리한다.
- 가격제한 비활성은 BUY 신호 발생 시 가격조건 없이 기계적으로 BUY 검토한다는 뜻이다.
- 비활성 정책은 통과로 간주한다.
- 실제 BUY 회차는 신호 수가 아니라 실제 BUY 대상으로 채택된 횟수다.

1. 가격제한 정책

비활성:
- BUY 신호마다 가격제한 없이 BUY 검토

최초 BUY 상한:
- 현재가 <= 최초 실제 BUY 현재가

최초 BUY 하한:
- 현재가 >= 최초 실제 BUY 현재가

최초 BUY 양방향 범위:
- 최초 BUY 기준 상승 +n%, 하락 -n% 범위 안에서만 허용

사용자 지정 범위:
- 상승 제한과 하락 제한을 사용자가 별도 입력

2. 추가진입 트리거 정책

비활성:
- 직전 BUY 기준 변동률 검사 없음

직전 BUY 하락률:
- 현재가 <= 직전 실제 BUY 현재가 × (1 - n%)

직전 BUY 상승률:
- 현재가 >= 직전 실제 BUY 현재가 × (1 + n%)

직전 BUY 양방향:
- 현재가가 직전 BUY 대비 +n% 이상 또는 -n% 이하 도달 시 허용

3. 조합 원칙

가격제한 정책 AND 추가진입 트리거 정책.

단, 비활성 정책은 통과로 간주한다.

예:
- 가격제한 비활성 + 트리거 비활성 = BUY 신호마다 기계적 BUY
- 최초 BUY 상한 + 직전 BUY -10% = 평단관리형 추가매수
- 최초 BUY 하한 + 직전 BUY +10% = 상승추종형 추가매수
- 최초 BUY 범위 + 직전 BUY 양방향 = 범위 내 변동성 대응형 추가매수

4. 회차

BUY 신호 수와 실제 진입 회차는 다르다.
스킵은 회차 증가 없음.
부분체결은 정상 회차로 인정한다.

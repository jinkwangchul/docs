# 루틴 정책 초안 v9 - Position Policy 추가진입 알고리즘 정정

핵심 정정:
- BUY 신호 번호와 실제 진입 회차는 다르다.
- 회차별 % 테이블을 두는 구조가 아니다.
- 고정 비율 하나를 사용한다.
- 비교대상은 최초 실제 BUY 현재가와 직전 실제 BUY 현재가다.
- 예산 증가 규칙(X2/X3 등)과 가격조건은 별개다.

1. 기본 예시

최초진입예산 = 100만원
금액기준 X3 적용

진입예산 계획:
1회차 = 100만원
2회차 = 300만원
3회차 = 900만원
4회차 = 2700만원

최초 실제 BUY 현재가 = 10,000원
고정비율 = 직전 실제 BUY 현재가 대비 -10% 이하

1회차:
10,000원
100만원 / 10,000원 = 100주

다음 BUY 신호:
현재가 9,500원
직전 실제 BUY 현재가 10,000원의 -10% 이하가 아님
→ 스킵
→ 실제 2회차는 아직 발생하지 않음

다음 BUY 신호:
현재가 8,500원
직전 실제 BUY 현재가 10,000원의 -10% 이하 충족
→ 실질 2회차 BUY
→ 300만원 / 8,500원 = 352주, 소수점 절사

결과:
1회차 100주 × 10,000원
2회차 352주 × 8,500원

평단:
(100 × 10,000 + 352 × 8,500) / 452 = 약 8,831.86원

2. 추가 BUY 허용 조건

현재가 <= 최초 실제 BUY 현재가
AND
현재가 <= 직전 실제 BUY 현재가 × (1 - 고정비율)

3. 중요한 분리

BUY 신호 수:
- 참고정보
- 회차 증가와 직접 연결하지 않음

실제 진입 회차:
- 가격조건 통과
- 메인 게이트 승인
- 실제 BUY 대상으로 채택
- 부분체결도 정상 회차로 인정

4. 스킵

조건 미충족 BUY는 스킵한다.
스킵된 BUY는 실제 진입 회차를 증가시키지 않는다.
다음 BUY 신호가 다시 같은 다음 회차 조건을 평가한다.

5. 평단

평단은 결과 확인 및 별도 필터/검증용이다.
추가진입 가격조건의 기본 기준은 평단이 아니라 최초/직전 실제 BUY 현재가다.

6. 메인/루틴 관계

루틴:
- 다음 진입금액 산정
- 가격조건 평가
- BUY 제안

메인:
- 예산/시간/상태/검토관리 확인
- 최종 승인/거부
- 실제 주문 수행

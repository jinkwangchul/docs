# 운영정책_테스트체크리스트_v2026-06-13

작성 기준일: 2026-06-13
작성 목적: 다음 새 대화창에서 키움 자동매매 프로젝트를 즉시 이어가기 위한 최신 기준 문서
주의: 본 문서는 기존 v1.1~v2.0 문서의 누적 정책과 2026-06-13까지의 최신 확정사항을 반영한 신규 상세본이다.


============================================================
1. 테스트 목적
============================================================

이 체크리스트는 기능이 열리는지 확인하는 문서가 아니다.
목적은 예외 상황에서 시스템이 정책대로 안전하게 동작하는지 확인하는 것이다.

중점 확인:
- 자동복귀가 발생하지 않는가.
- 검토관리로 격리되어야 할 종목이 누락되지 않는가.
- 이월 종목이 자동으로 정상 운영에 복귀하지 않는가.
- 마감과 청산 개념이 섞이지 않는가.
- 데이터 불일치가 빨강으로 표시되는가.
- 빨강이 자동 검토관리 이동으로 오해되지 않는가.

============================================================
2. 재시작 테스트
============================================================

[RS-01] 보유/미수/미도 없음
조건:
- trade_enabled 여부와 무관하게 보유 0.
- 미수 0.
- 미도 0.
- 이월 메타 없음.
동작:
- 프로그램 종료 후 재시작.
예상:
- 종료상태.
- 시작 OFF.
- 검토관리 이동 없음.
- 자동 매수/매도 복귀 없음.

[RS-02] 보유 있음
조건:
- 보유 > 0.
- 미수 0.
- 미도 0.
동작:
- 프로그램 종료 후 재시작.
예상:
- 검토관리 이동.
- 자동복귀 금지.
- 자동매매설정창에서 제거.
- 검토관리창에서 보유 표시.

[RS-03] 미수 있음
조건:
- 보유 0.
- 미수 > 0.
- 미도 0.
예상:
- 검토관리 이동.
- 청산 대상으로 넘기지 않음.

[RS-04] 미도 있음
조건:
- 보유 0 또는 보유 있음.
- 미도 > 0.
예상:
- 검토관리 이동.
- 자동복귀 금지.

[RS-05] 이월 흔적 있음
조건:
- 조기마감/자동마감 이월 메타 존재.
- 보유 존재 여부 확인.
예상:
- 검토관리 이동.
- 다음 시작점 자동복귀 금지.

============================================================
3. 긴급정지 테스트
============================================================

[EM-01] 긴급정지 실행
조건:
- 정상 운영 종목 존재.
동작:
- 긴급정지 실행.
예상:
- 신규 매수 중지.
- 자동 매도 금지.
- 상태 긴급정지 또는 정지 상태.
- 로그 기록.

[EM-02] 긴급정지 해제 + 잔여 없음
조건:
- 보유 0, 미수 0, 미도 0.
동작:
- 긴급정지 해제.
예상:
- 재시작과 동일 판정.
- 종료상태 + 시작 OFF.
- 자동 RUNNING 복귀 금지.

[EM-03] 긴급정지 해제 + 보유 있음
조건:
- 보유 > 0.
동작:
- 긴급정지 해제.
예상:
- 검토관리 이동.

[EM-04] 긴급정지 해제 + 미수/미도 있음
예상:
- 검토관리 이동.

============================================================
4. 검토관리 테스트
============================================================

[RV-01] 검토관리 표시
조건:
- REVIEW_REQUIRED 종목 존재.
예상:
- 자동매매설정창에서 미표시.
- 검토관리창에 표시.
- 코드/종목/위치/상태/사유/검출/보유/미수/미도/발생시간 확인.

[RV-02] 복귀
조건:
- 검토관리 종목 선택.
동작:
- 복귀.
예상:
- 자동복귀가 아니라 운영자 명령으로 복귀.
- 복귀 후 현재 조건 재판정.
- 보유/미수/미도/이월이 남아 있으면 재격리 또는 복귀 차단 필요.

[RV-03] 임시복귀
동작:
- 임시복귀 버튼 또는 유사 기능 사용.
예상:
- 원래 정책과 충돌하지 않는지 확인.
- 자동 정상운영 복귀로 오해되지 않아야 함.

[RV-04] 미지정
예상:
- 루틴 연결/기초종목 상태가 정책대로 정리되는지 확인.

[RV-05] 삭제
예상:
- 보유/미수/미도 존재 시 삭제 경고 또는 차단 확인.

============================================================
5. 조기마감 테스트
============================================================

[EC-01] 조기마감 + 시장가
조건:
- 보유 있음.
동작:
- 조기마감 시장가.
예상:
- 상태 조기마감.
- 청산 시장가.
- 처리 대상 있음 → 현황 녹색.

[EC-02] 조기마감 + 현재가
예상:
- 현재가 정책대로 처리.
- 미체결/잔여 발생 시 정책 확인.

[EC-03] 조기마감 + 지정가
예상:
- 지정가 주문/표시 정책 확인.

[EC-04] 조기마감 + 익절/손절
예상:
- 기준 수익률 판정.
- 조건 미충족 시 다음 상태 확인.

[EC-05] 조기마감 + 이월 + 보유 있음
예상:
- 상태 조기마감.
- 방식 이월.
- 청산 이월.
- 보유 유지.
- 현황 녹색.
- 자동청산 금지.

[EC-06] 조기마감 + 이월 + 청산시간대 겹침
예상:
- 이월 우선.
- 시장가/현재가 청산 실행 금지.

[EC-07] 조기마감 + 대상 없음
조건:
- 보유 0.
- 미도 0.
예상:
- 상태 감시/대기 또는 마감 대상 없음 표시 정책.
- 현황 주황.

6. 자동마감 테스트
============================================================

[AC-01] 자동마감 + 시장가
[AC-02] 자동마감 + 현재가
[AC-03] 자동마감 + 지정가
[AC-04] 자동마감 + 익절/손절
[AC-05] 자동마감 + 이월
[AC-06] 자동마감 + 이월 + 청산시간대 겹침
[AC-07] 자동마감 + 대상 없음

각 예상은 조기마감과 동일 철학을 따른다.
단, 자동마감은 장기 테스트가 필요하며 완료 판정하지 않는다.

============================================================
7. 청산 테스트
============================================================

[CL-01] 5분/시장가
[CL-02] 10분/시장가
[CL-03] 5분/현재가
[CL-04] 10분/현재가
[CL-05] 지정가
[CL-06] 이월

공통 확인:
- 이월이면 청산 active False.
- 보유 없으면 청산 비활성.
- 시작 OFF면 청산 비활성.
- 미수는 청산 대상으로 넘기지 않음.
- 미도는 처리 대상 또는 검토관리 조건으로 판정.

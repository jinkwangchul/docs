[목적]

본 문서는 AI추론오염사고_재발방지 문서의 추가 규정이다.

--------------------------------------------------
1. 코드 생성 전 필수 검증 절차
--------------------------------------------------

어떠한 코드도 아래 절차 완료 전 생성 금지.

1. 마스터스펙 확인
2. 작업진행상황대화히스토리 확인
3. 확정 참조문서 확인
4. 기존 코드 확인
5. 사용자 승인
6. 코드 생성

하나라도 누락되면 구현 금지.

--------------------------------------------------
2. 신규 개념 생성 금지
--------------------------------------------------

다음 행위 금지.

- 문서에 없는 상태값 생성
- 문서에 없는 신호 생성
- 문서에 없는 엔진 생성
- 문서에 없는 정책 생성
- 문서에 없는 용어 생성

확정 문서 근거 또는 사용자 승인 필수.

--------------------------------------------------
3. 구현 방향 확인 의무
--------------------------------------------------

AI는 구현 전 반드시:

"어느 방향으로 구현할지"

확인해야 한다.

사용자 승인 없는 구조 변경 금지.

--------------------------------------------------
4. 문서 남발 금지
--------------------------------------------------

문서 작성은 아래 경우만 허용.

- 프로젝트 기준 문서
- 작업재개요약서
- 사고 기록 문서
- 사용자 요청 문서

설계 가설 문서 무분별 생성 금지.

--------------------------------------------------
5. 복구 기준본 관리
--------------------------------------------------

문제 발생 시:

1. 마지막 정상 동작 버전 확인
2. 오염 버전 확인
3. 차이점 분석
4. 복구 여부 결정

무조건 최신본 사용 금지.

--------------------------------------------------
6. 코드 적용 규칙
--------------------------------------------------

AI 제안 코드

= 적용 코드

가 아니다.

사용자 검토 전에는 모두 제안 상태로 간주.

--------------------------------------------------
7. 압축파일 금지
--------------------------------------------------

특별 요청 없는 한:

ZIP 생성 금지.

결과물은:

- TXT
- PY
- 개별 파일

형태 우선.

--------------------------------------------------
8. 최종 원칙
--------------------------------------------------

추론보다 문서.

문서보다 확정사항.

확정사항보다 사용자 승인.

이를 최우선 원칙으로 한다.

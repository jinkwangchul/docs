# 상태전이표 최종확정본 v5

## 목적
본 문서는 최신 구조개선 정책 기준의 상태체계와 상태전이 규칙을 정리한다.
구버전 문서의 일시정지, 정지, 전체대기, 다단계 긴급정지 개념은 본 문서 기준으로 폐기한다.

---

# 1. 최종 상태 목록

- 감시/대기
- 매수/매도
- 감시/매도
- 조기마감
- 긴급정지
- 검토종목

---

# 2. 상태별 정의

## 감시/대기

감시는 수행하지만 매수/매도 주문은 하지 않는 상태.

진입 예:

- 시작시간 이전
- 거래불가시간
- 감시/매도 후 보유수량 0
- 조기마감 후 전량 정리 완료

이탈:

- 운영시간 시작 + 정상상태 → 매수/매도

---

## 매수/매도

정상 자동매매 상태.
매수와 매도 모두 가능하다.

진입 예:

- 운영시간 중
- 무결성 정상
- 검토종목 아님
- 긴급정지 아님

이탈:

- 운영시간 종료 → 감시/매도
- 조기마감 실행 → 조기마감
- 계좌 단위 문제 → 긴급정지
- 종목 단위 문제 → 검토종목

---

## 감시/매도

신규매수는 금지하고 매도만 허용하는 상태.
기본 매도 판단은 루틴의 매도정책을 따른다.

진입 예:

- 시간운영 종료
- 종료 후 정책이 감시/매도인 경우

동작:

- 매수신호 폐기
- 매도신호는 메인엔진 판정 후 실행 가능
- +N% 익절, -N% 손절 등 루틴 매도조건 허용

이탈:

- 보유수량 0 → 감시/대기
- 조기마감 실행 → 조기마감
- 계좌 단위 문제 → 긴급정지
- 종목 단위 문제 → 검토종목

---

## 조기마감

운영자가 강제로 정리 절차를 시작한 상태 또는 표시상태.
조기마감은 기본적으로 루틴을 유지하되 시간조건을 제거하고 즉시 평가한다.

진입 예:

- 상태 컬럼 우클릭 → 조기마감 실행

기본 동작:

- 신규매수 금지
- 루틴 유지
- 시간조건 제거
- 즉시 매도조건 평가

선택 정책:

- 현재가 청산
- 시장가 청산
- 지정가 청산
- 익절 N%
- 손절 N%
- 익일이월

이탈:

- 전량 정리 완료 → 감시/대기
- 익일이월 → 검토종목
- 청산실패 → 검토종목
- 잔량발생 → 검토종목
- 계좌 단위 문제 → 긴급정지

---

## 긴급정지

계좌 단위 문제, 시스템 이상, API 이상, 운영자 강제중단 시 사용하는 비상 상태.

진입 예:

- 예수금 조회 실패
- 잔고 조회 실패
- 계좌 전체 조회 실패
- API 이상
- 운영자 긴급정지

동작:

- 신규매수 금지
- 신규매도 금지
- 자동판단 중지
- 자동청산 중지
- 감시와 조회는 가능하면 유지

이탈:

- 해제 요청
- 무결성 검사
- 현재조건 재판정

자동복귀:

- 금지

---

## 검토종목

자동매매 신뢰성이 훼손된 종목의 격리 상태.

진입 예:

- 수량불일치
- 주문불일치
- 잔고불일치
- 청산실패
- 잔량발생
- 익일이월
- 무결성실패
- 파일구조이상
- 설정파일이상

동작:

- 자동매매 제외
- 상태조회 허용
- 로그조회 허용
- 미체결 취소 허용
- 수동 무결성 검사 허용
- 필요 시 수동 매도 허용

이탈:

- 수동 무결성 검사 통과
- 현재조건 재판정
- 운영자 복귀 승인

자동복귀:

- 금지

---

# 3. 핵심 전이 규칙

## 정상 운영

감시/대기
→ 운영시간 시작
→ 매수/매도

매수/매도
→ 운영시간 종료
→ 감시/매도

감시/매도
→ 보유수량 0
→ 감시/대기

---

## 조기마감

매수/매도 또는 감시/매도
→ 조기마감 실행
→ 조기마감

조기마감
→ 전량 정리 성공
→ 감시/대기

조기마감
→ 익일이월
→ 검토종목

조기마감
→ 청산실패 또는 잔량발생
→ 검토종목

---

## 긴급정지

모든 상태
→ 계좌 단위 문제
→ 긴급정지

긴급정지
→ 무결성 검사 통과
→ 현재조건 재판정

긴급정지
→ 무결성 검사 실패
→ 문제 범위에 따라 긴급정지 유지 또는 검토종목 이동

---

## 검토종목

모든 상태
→ 종목 단위 문제
→ 검토종목

검토종목
→ 수동 무결성 검사 통과
→ 현재조건 재판정

검토종목
→ 수동 무결성 검사 실패
→ 검토종목 유지

---

# 4. 익일이월 규칙

익일이월은 정상 운영 복귀 대상이 아니다.

장마감 또는 조기마감
→ 익일이월 발생
→ 검토종목 이동

복귀 흐름:

검토종목
→ 수동 무결성 검사
→ 현재조건 재판정
→ 운영자 복귀 승인

# 6. 코드 반영 주의

기존 코드에 남은 STOPPED, PAUSED, SELL_ONLY 등은 즉시 삭제하지 않는다.
먼저 최신 상태표시명으로 매핑한 뒤 영향 범위를 확인하고 단계적으로 정리한다.

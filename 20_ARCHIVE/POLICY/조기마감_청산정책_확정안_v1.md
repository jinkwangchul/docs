# 조기마감 / 청산정책 확정안 v1

## 1. 목적

본 문서는 자동매매 구조개선 과정에서 확정된 조기마감 정책과 청산정책의 기준을 정리한다.

조기마감은 단순 강제청산이 아니라,
사용자가 현재 시점부터 신규매수를 중단하고 보유종목 정리 절차를 시작하는 운영 명령이다.

---

## 2. 조기마감의 정의

조기마감은 일반 시간운영 종료와 구분한다.

- 일반 시간운영 종료: 감시/매도
- 조기마감 실행: 조기마감

조기마감은 상태 컬럼 우클릭 메뉴에서 실행하는 예외적 운영 명령으로 본다.

---

## 3. 상태 표시

조기마감 실행 후 화면 상태 표시는 다음과 같이 한다.

- 표시 상태명: 조기마감
- 의미: 신규매수 금지 + 보유종목 정리 절차 진행

감시/매도와 조기마감은 모두 매수 금지, 매도 허용 성격을 가지지만 목적이 다르므로 표시명을 분리한다.

---

## 4. 기본 동작

조기마감의 기본 동작은 다음으로 확정한다.

루틴 유지 + 시간조건 제거 + 즉시평가

즉, 루틴의 매도 조건은 유지하되,
루틴 내부의 시간 대기 조건은 제거하고 현재 시점에서 즉시 매도 가능 여부를 평가한다.

예시:

- 기존 루틴: 14:50 이후 매도 판단
- 조기마감 실행: 현재 시각 기준 즉시 매도 판단

---

## 5. 매도조건 처리

루틴 단계에서 다음과 같은 매도조건을 사용할 수 있다.

- +N% 익절 매도
- -N% 손절 매도
- MACD 매도신호
- 기타 루틴 기반 매도신호

조기마감은 이 조건들과 충돌하지 않는다.

조기마감 실행 시:

- 매수신호는 폐기
- 매도조건은 즉시 평가
- 조건 충족 시 메인엔진이 주문 가능 여부를 최종 판정

---

## 6. 루틴과 메인엔진 책임 분리

루틴 역할:

- 매수신호 생성
- 매도신호 생성
- +N% / -N% 조건 평가
- 시간조건 제거 후 즉시 평가 가능

메인엔진 역할:

- 현재 상태 확인
- 긴급정지 여부 확인
- 검토종목 여부 확인
- 미체결 존재 여부 확인
- 주문 실행 가능 여부 최종 판단
- 실제 주문 실행

루틴은 주문을 직접 실행하지 않는다.

---

## 7. 조기마감 옵션

기본값은 루틴 유지 + 시간조건 제거 + 즉시평가로 한다.

추가 옵션은 후속 설정에서 선택 가능하게 둔다.

후보 옵션:

1. 루틴 유지 + 시간조건 제거 + 즉시평가
2. 현재가 청산
3. 시장가 청산
4. 지정가 청산
5. 익절 N% 이상 청산
6. 손절 N% 이하 청산
7. 익일이월

단, 익일이월 선택 시 자동복귀하지 않고 검토종목으로 이동한다.

---

## 8. 익일이월 처리

조기마감 또는 장마감 정책에서 익일이월이 발생하면 다음과 같이 처리한다.

익일이월
→ 검토종목 이동
→ 자동복귀 금지
→ 수동 무결성 검사
→ 현재조건 재판정
→ 운영복귀 여부 결정

---

## 9. 감시/매도와의 차이

감시/매도:

- 일반 시간운영 종료 후 진입
- 신규매수 금지
- 루틴 매도방침 유지
- 일반적인 운영 종료 상태

조기마감:

- 운영자가 명시적으로 실행
- 신규매수 금지
- 루틴 매도방침 유지
- 시간조건 제거
- 즉시 매도조건 평가
- 예외적 조기 정리 상태

---

## 10. UI 정책

좌클릭:

- 수동 컬럼: 수동운영 설정
- 시간 컬럼: 시간운영 설정

우클릭:

- 상태 컬럼: 조기마감, 긴급정지, 무결성 검사, 검토종목 이동 등 운영 명령

조기마감 실행 후 상태 컬럼에는 감시/매도가 아니라 조기마감으로 표시한다.

---

## 11. 현재 확정 상태

확정 상태명:

- 감시/대기
- 매수/매도
- 감시/매도
- 조기마감
- 긴급정지
- 검토종목

폐기 표시명:

- 정지
- 일시정지
- 전체대기

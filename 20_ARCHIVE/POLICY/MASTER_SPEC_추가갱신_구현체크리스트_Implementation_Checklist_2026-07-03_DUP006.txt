MASTER_SPEC_추가갱신_구현체크리스트_Implementation_Checklist_2026-07-03

목적
- 설계 문서를 실제 구현으로 옮길 때 누락을 방지하기 위한 구현 체크리스트이다.
- 각 항목은 완료 여부를 독립적으로 확인할 수 있어야 한다.

==================================================
1. 주문 후보 단계
==================================================
[ ] order_candidate 생성
[ ] order_intent 생성
[ ] order_provenance 생성
[ ] execution_enabled 기본값 false 확인

==================================================
2. Approval 단계
==================================================
[ ] PENDING → APPROVED
[ ] PENDING → BLOCKED
[ ] APPROVED 외 상태 변경 없음

==================================================
3. Policy 단계
==================================================
[ ] APPROVED → EXECUTABLE
[ ] APPROVED → BLOCKED_POLICY
[ ] execution_enabled 변경 없음

==================================================
4. Preflight 단계
==================================================
[ ] EXECUTABLE → REAL_READY
[ ] EXECUTABLE → BLOCKED_REAL
[ ] guard 검증
[ ] 상태 외 부작용 없음

==================================================
5. Adapter Preview
==================================================
[ ] Preview 생성
[ ] queue 변경 없음
[ ] SendOrder 호출 없음

==================================================
6. Execution 준비
==================================================
[ ] hoga 확정
[ ] order_type 확정
[ ] order_intent.unresolved=false
[ ] execution_enabled=true 정책
[ ] operator_confirmed=true 정책

==================================================
7. Final Guard
==================================================
[ ] Final Execution Guard
[ ] Lock 확인
[ ] Request Hash 생성
[ ] ORDER_QUEUED 생성

==================================================
8. 실행 계층
==================================================
[ ] Execution Request 생성
[ ] Kiwoom Boundary 연결
[ ] SendOrder 단일 진입점 확인

==================================================
9. 체결 계층
==================================================
[ ] Chejan 수신
[ ] Fill 생성
[ ] Position 갱신
[ ] Audit Log 기록

==================================================
10. 운영 계층
==================================================
[ ] Review Management
[ ] Recovery
[ ] Close History
[ ] Runtime 검증

==================================================
11. 최종 검증
==================================================
[ ] 중복주문 방지
[ ] 재시작 복구
[ ] 상태 전이 검증
[ ] Audit Log 검증
[ ] 검토관리 검증

최종 원칙
각 체크 항목은 독립적으로 검증 가능해야 하며,
선행 항목이 완료되지 않은 상태에서 다음 단계 구현을 시작하지 않는다.

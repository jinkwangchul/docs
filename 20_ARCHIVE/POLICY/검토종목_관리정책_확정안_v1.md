# 검토종목 관리정책 확정안 v1

## 1. 목적

검토종목은 자동매매 신뢰성이 훼손되었거나 운영자 확인이 필요한 종목을 자동운영에서 분리하여 관리하는 격리 영역이다.

검토종목은 자동복귀하지 않는다.

---

## 2. 기본 원칙

- 검토종목은 자동매매 대상에서 제외한다.
- 검토종목은 운영자 확인 전 자동복귀 금지.
- 검토종목 복귀는 수동 무결성 검사 후 현재조건 재판정으로만 가능.
- 종목 단위 문제는 해당 종목만 검토종목으로 이동한다.
- 계좌 단위 문제는 검토종목이 아니라 긴급정지로 처리한다.

---

## 3. 표시 기준

관제센터 및 관리창에서는 `진입사유`보다 `검토위치`를 우선 표시한다.

이유:

- 운영자가 어디서 문제가 발생했는지 즉시 파악 가능
- 로그성 문장보다 상태관리용 분류에 적합
- 후속 조치 버튼과 연결하기 쉬움

---

## 4. 검토위치 목록

검토위치는 고정값으로 관리한다.

| 검토위치 | 의미 |
|---|---|
| HTS수동개입 | HTS 또는 외부에서 수동 매수/매도/취소 발생 |
| 청산실패 | 청산 주문을 냈으나 정상 완료되지 않음 |
| 잔량발생 | 청산 후 보유수량 또는 미체결 잔량이 남음 |
| 익일이월 | 장마감 후 보유상태가 다음날로 넘어감 |
| 무결성실패 | 수량, 주문, 상태 정보 검사 실패 |
| 계좌불일치 | 프로그램 상태와 계좌 조회 결과 불일치 |
| 미체결이상 | 미체결 매수/매도 상태가 정상 흐름과 맞지 않음 |
| 수량불일치 | 프로그램 보유수량과 실제 보유수량 불일치 |
| 수동등록 | 정상 등록 조건을 통과하지 못해 검토종목으로 등록 |
| 기타 | 위 항목으로 분류하기 어려운 예외 |

---

## 5. 검토종목 필수 기록값

검토종목으로 이동할 때 최소 아래 값을 기록한다.

| 항목 | 설명 |
|---|---|
| 종목코드 | 종목 식별값 |
| 종목명 | 화면 표시명 |
| 검토위치 | 어디서 검토종목으로 들어왔는지 |
| 진입시간 | 검토종목 이동 시각 |
| 현재보유수량 | 이동 당시 보유수량 |
| 미체결매수 | 이동 당시 미체결 매수 수량 |
| 미체결매도 | 이동 당시 미체결 매도 수량 |
| 최근검사결과 | 마지막 무결성 검사 결과 |
| 상세메시지 | 로그용 설명 |

---

## 6. 검토종목 허용 기능

검토종목 상태에서 허용되는 기능은 제한한다.

허용:

- 상태조회
- 로그조회
- 미체결 취소
- 현재가 매도
- 시장가 매도
- 수동 무결성 검사
- 검토종목 해제

금지:

- 자동매수
- 자동매도
- 루틴신호 자동실행
- 자동복귀
- 신규 루틴 자동연결

---

## 7. 복귀 절차

검토종목은 자동복귀하지 않는다.

복귀 흐름:

```text
검토종목
↓
운영자 확인
↓
문제 해결
↓
수동 무결성 검사
↓
통과
↓
현재조건 재판정
↓
감시/대기 또는 매수/매도 또는 감시/매도
```

무결성 검사 실패 시 검토종목 유지.

---

## 8. 익일이월 처리 확정

익일이월은 검토종목으로 이동한다.

```text
장마감
↓
익일이월 선택 또는 잔량 이월
↓
검토종목
```

익일 자동재개 금지.

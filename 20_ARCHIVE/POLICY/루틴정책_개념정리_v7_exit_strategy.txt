# 루틴 정책 초안 v7 - exit_strategy 추가

핵심 추가:
- SELL 이후 실제 포지션 종료 전술을 exit_strategy.json으로 분리한다.
- 최초 유효 SELL은 Cycle 종료 선언이며 Exit Strategy 시작점이다.
- Exit Strategy 진행 중 추가 SELL은 새 SELL Trigger가 아니라 분할매도/추가매도 조건 이벤트로 활용할 수 있다.
- 디폴트는 안정형: 전량청산 목표 + 다중호가매도 + 재SELL + 마지막 시장가.
- 옵션은 자유형: 분할매도, 시간조건, 간격조건, 최초 SELL 기준가 이상/이하, 이평선 기울기, 수익률 조건 조합 허용.

1. SELL 해석
최초 유효 SELL:
- 현재 자동매매 1싸이클 종료 선언
- Exit Strategy 시작

Exit Strategy 중 추가 SELL:
- 새 싸이클 종료신호 아님
- Exit Strategy 내부 조건 이벤트로 사용 가능

Exit Strategy 중 BUY:
- 기본적으로 새 싸이클 시작으로 보지 않음
- 경고/로그 대상

2. 분할매도
분할매도는 사용자입력 방식:
- 분할 횟수 사용자 입력
- 분할 비율 사용자 입력
- 비율 합계 100% 검증
- 마지막 회차는 잔여수량 전량 처리 옵션

회차별 개별 조건은 두지 않는다.
조건은 Exit Strategy 공통조건으로 적용한다.

3. 재SELL
재SELL 조건:
- 주어진 시간 내 N번
- 주어진 시간 간격 N번
- 최초 SELL 기준가 이상/이하
- 추가 SELL 신호
- 이평선 기울기 변화
- 수익률 변화

이 조건들은 조합 가능하다.

4. 마지막 재SELL
마지막 재SELL은 특별 취급한다.
기본값:
- 잔여수량 전량
- 시장가 청산

선택 가능:
- 시장가
- 현재가
- 다중호가

5. 다중호가매도
SELL 디폴트는 다중호가매도다.
하지만 단일매도 옵션은 막지 않는다.

디폴트:
- 현재가 재산정
- 현재가 기준 위/아래 호가 배치
- 잔여수량 기준 재SELL

6. 정책 방향
디폴트는 안정형.
옵션은 자유형.
복잡한 조합은 경고/로그/백테스트 대상으로 남긴다.
서버연동 테스트 전에는 과도하게 막지 않는다.

# 무결성검사 정책확정안 v1

## 목적
본 문서는 자동매매 구조개선에서 사용하는 무결성 검사 체계를 확정한다.
무결성 검사는 자동매매 신뢰성을 유지하고, HTS/계좌 실제 상태와 프로그램 내부 상태의 불일치를 걸러내는 안전장치이다.

---

# 1. 무결성 검사 종류

무결성 검사는 3종류로 구분한다.

1. 자동 무결성 검사
2. 개별 무결성 검사
3. 전체 무결성 검사

---

# 2. 자동 무결성 검사

## 실행 시점

- 종목 등록 시
- 프로그램 재시작 시

## 목적

위험 종목이 정상 운영 상태로 진입하는 것을 차단한다.

## 종목 등록 시 검사 항목

- 보유수량 0 여부
- 미체결 매수 0 여부
- 미체결 매도 0 여부
- 계좌조회 정상 여부

## 판정

정상:

- 일반 등록 가능

이상:

- 검토종목 이동

## UI 원칙

종목등록창에는 별도 무결성 검사 버튼을 두지 않는다.
등록 과정에서 내부 로직으로 자동 수행한다.

---

# 3. 개별 무결성 검사

## 실행 위치

- 검토종목 관리창

## 대상

- 선택된 검토종목

## 목적

검토종목이 정상 운영으로 복귀 가능한지 판정한다.

## 흐름

검토종목 선택
→ 무결성 검사
→ 구조 무결성
→ 종목 무결성
→ 계좌 무결성
→ 통과 시 현재조건 재판정
→ 복귀 가능

실패 시:

- 검토종목 유지
- 실패 단계 기록
- 상세원인 기록

---

# 4. 전체 무결성 검사

## 실행 위치

- 관제센터 도구 메뉴

## 대상

- 전체 종목
- 전체 파일/폴더 구조
- 전체 계좌 상태

## 목적

시스템 건강검진.

## 사용 예

- 프로그램 시작 후 점검
- 대규모 설정 변경 후 점검
- 백업 복원 후 점검
- 운영자가 이상을 의심할 때

---

# 5. 버튼 원칙

버튼은 1개로 유지한다.
내부적으로 3단계를 순서대로 수행한다.

1. 구조 무결성
2. 종목 무결성
3. 계좌 무결성

---

# 6. 1단계: 구조 무결성

## 검사 항목

- 필수 폴더 존재 여부
- 필수 파일 존재 여부
- JSON 파일 파싱 가능 여부
- 루틴 참조 존재 여부
- 종목데이터 경로 정상 여부
- 설정파일 손상 여부

## 실패 예

- state.json 누락
- orders.json 누락
- config.json 누락
- JSON 손상
- 루틴 폴더 삭제
- 종목 폴더명 변경
- 필수 경로 누락

## 실패 처리

- 종목 단위 구조 문제 → 검토종목
- 전체 구조 문제 → 긴급정지 검토

---

# 7. 2단계: 종목 무결성

## 검사 항목

- 프로그램 내부 보유수량 기록
- 프로그램 내부 주문기록
- 종목별 상태값
- 종목별 설정값
- 루틴 연결 정보
- 검토위치 해소 여부

## 실패 예

- 상태값 없음
- 알 수 없는 상태값
- 주문기록 손상
- 루틴 연결 정보 불일치
- 종목 설정 누락

## 실패 처리

- 검토종목 유지 또는 검토종목 이동

---

# 8. 3단계: 계좌 무결성

## 검사 항목

- HTS/계좌 실제 보유수량
- 프로그램 기록 보유수량
- HTS/계좌 실제 미체결 매수
- HTS/계좌 실제 미체결 매도
- 프로그램 기록 미체결
- 잔고조회 가능 여부
- 현재가 조회 가능 여부
- 주문 가능 상태 여부

## 실패 예

- 보유수량 불일치
- 미체결 매수 불일치
- 미체결 매도 불일치
- 잔고조회 실패
- 현재가 조회 실패
- 계좌정보 조회 실패

## 실패 처리

- 종목 단위 문제 → 검토종목
- 계좌 전체 문제 → 긴급정지

---

# 9. HTS 수동개입 처리

HTS 수동개입은 검토위치가 아니라 상세원인으로 기록한다.

예:

검토위치: 수량불일치
상세원인: HTS 수동매도

검토위치: 주문불일치
상세원인: HTS 수동취소

---

# 10. 결과 기록

무결성 검사 결과는 다음 정보를 남긴다.

- 검사일시
- 검사대상
- 검사종류
- 실패단계
- 검토위치
- 상세원인
- 최종판정

## 최종판정 후보

- 통과
- 실패: 구조
- 실패: 종목
- 실패: 계좌
- 긴급정지 필요
- 검토종목 유지
- 복귀 가능

---

# 11. UI 배치

## 종목등록창

- 별도 버튼 없음.
- 등록 시 자동검사.

## 검토종목 관리창

- 개별 무결성 검사 버튼 배치.
- 선택 종목만 검사.

## 관제센터

- 도구 메뉴에 전체 무결성 검사 배치.

---

# 12. 복귀 원칙

무결성 검사 통과는 자동복귀가 아니다.

검토종목:

무결성 검사 통과
→ 현재조건 재판정
→ 운영자 확인
→ 복귀

긴급정지:

해제 요청
→ 무결성 검사
→ 현재조건 재판정
→ 운영 재개 가능

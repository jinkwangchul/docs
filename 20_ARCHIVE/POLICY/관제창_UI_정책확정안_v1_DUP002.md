# 관제창 UI 정책확정안 v1

## 1. 문서 목적

본 문서는 구조개선 2차 정책 확정 이후, 관제창에서 상태를 어떻게 표시할지 정리한 기준 문서이다.

관제창은 내부 개발 상태값을 보여주는 화면이 아니라, 운영자가 현재 종목 상태를 즉시 판단하는 화면이다.

따라서 관제창 UI는 직관성을 최우선으로 한다.

---

## 2. 기본 원칙

### 원칙 1. 직관성 우선

관제창은 운영자가 설명서 없이도 이해할 수 있어야 한다.

예:

- 감시/대기
- 매수/매도
- 감시/매도
- 조기마감
- 긴급정지
- 검토종목

내부 코드값은 표시하지 않는다.

표시 금지 예:

- MONITORING
- RUNNING
- REVIEW_REQUIRED
- EMERGENCY_STOPPED
- SELL_ONLY
- STOPPED

---

### 원칙 2. 텍스트 + 색상 동시 사용

색상만으로 상태를 판단하게 만들지 않는다.

모든 상태는 반드시 텍스트로 표시하고, 색상은 보조 수단으로 사용한다.

예:

| 상태 | 표시 예시 | 색상 성격 |
|---|---|---|
| 감시/대기 | 감시/대기 | 중립 |
| 매수/매도 | 매수/매도 | 정상 |
| 감시/매도 | 감시/매도 | 주의 |
| 조기마감 | 조기마감 | 특별 처리 |
| 긴급정지 | 긴급정지 | 위험 |
| 검토종목 | 검토종목 | 격리 |

실제 색상값은 구현 단계에서 화면 가독성을 보며 조정한다.

---

## 3. 관제창 상태 표시 기준

### 3-1. 기본 상태 표시

관제창 상태 컬럼에는 아래 상태명을 사용한다.

| 정책 상태 | 관제창 표시 |
|---|---|
| 감시/대기 | 감시/대기 |
| 매수/매도 | 매수/매도 |
| 감시/매도 | 감시/매도 |
| 조기마감 | 조기마감 |
| 긴급정지 | 긴급정지 |
| 검토종목 | 검토종목 |

---

### 3-2. 검토종목 표시

검토종목은 가능하면 보조 정보를 괄호로 함께 표시한다.

예:

- 검토종목(익일이월)
- 검토종목(수량불일치)
- 검토종목(주문불일치)
- 검토종목(청산실패)
- 검토종목(잔량발생)
- 검토종목(무결성실패)

단, 컬럼 폭이 부족하면 기본 상태는 `검토종목`으로 표시하고, 상세 내용은 툴팁 또는 검토종목 관리창에서 표시한다.

---

### 3-3. 조기마감 표시

조기마감도 가능하면 보조 정보를 괄호로 표시한다.

예:

- 조기마감(루틴)
- 조기마감(현재가)
- 조기마감(시장가)
- 조기마감(익일이월)

기본 조기마감 정책은 다음과 같다.

```text
루틴 유지
시간조건 제거
즉시평가
```

따라서 기본 표시는 `조기마감(루틴)`을 우선 후보로 둔다.

단, 실제 구현 시 컬럼 폭이 부족하면 `조기마감`만 표시하고 상세는 툴팁 또는 우클릭 메뉴에서 확인한다.

---

## 4. 좌클릭 / 우클릭 원칙

### 4-1. 좌클릭

좌클릭은 일반 설정 진입에 사용한다.

| 클릭 위치 | 동작 |
|---|---|
| 수동 컬럼 | 수동운영 설정창 |
| 시간 컬럼 | 시간운영 설정창 |

---

### 4-2. 우클릭

우클릭은 운영 명령 또는 예외 처리 메뉴에 사용한다.

상태 컬럼 우클릭 후보:

- 조기마감 실행
- 긴급정지
- 검토종목 이동
- 무결성 검사
- 로그 보기

실제 메뉴 구성은 구현 단계에서 화면 흐름을 보며 조정한다.

---

## 5. 검토종목 관리창 연계

관제창에서 검토종목으로 표시된 종목은 검토종목 관리창에서 상세 관리한다.

검토종목 관리창 기본 컬럼 후보:

| 컬럼 | 의미 |
|---|---|
| 종목 | 종목명/코드 |
| 검토위치 | 문제 유형 |
| 상세원인 | 발생 원인 |
| 진입시간 | 검토종목 진입 시각 |
| 현재상태 | 보유/미체결/격리 상태 |
| 최근검사결과 | 최근 무결성 검사 결과 |
| 조치 | 검사/복귀/청산 등 |

검토위치와 상세원인은 분리한다.

예:

```text
검토위치: 수량불일치
상세원인: HTS 수동매도
```

---

## 6. 무결성 검사 버튼 위치

### 자동 무결성 검사

종목 등록 및 프로그램 재시작 시 내부 로직으로 자동 수행한다.

### 개별 무결성 검사

검토종목 관리창에 둔다.

대상:

- 선택된 검토종목

목적:

- 복귀 가능 여부 판정

### 전체 무결성 검사

관제센터 도구 메뉴에 둔다.

대상:

- 전체 종목
- 전체 구조
- 전체 계좌 상태

목적:

- 시스템 건강검진

---

## 7. 구현 단계 재조정 허용 항목

아래 항목은 설계 확정 후에도 구현/필드테스트에서 조정 가능하다.

- 컬럼 폭
- 상태 색상
- 괄호 표시 여부
- 툴팁 표시 방식
- 우클릭 메뉴 순서
- 조기마감 표시명 세부 문구
- 검토종목 상세 표시 방식

단, 아래 원칙은 변경하지 않는다.

- 내부 코드값 표시 금지
- 운영자 언어 사용
- 검토종목/조기마감 직관 표시
- 색상만으로 상태 판단 금지
- 수동/시간 설정은 좌클릭
- 조기마감/긴급정지/검토종목 이동은 우클릭 계열

---

## 8. 현재 판정

관제창 UI 정책은 설계 확정 상태로 본다.

다만 실제 구현 단계에서 화면 폭, 컬럼 잘림, 색상 가독성 문제는 반드시 재검증한다.

현재 문서는 구현 전 기준문서이며, 구현 후에는 `관제창_UI_필드테스트_수정목록` 문서로 보완한다.

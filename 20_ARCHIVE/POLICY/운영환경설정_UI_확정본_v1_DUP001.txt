# 운영환경설정_UI_확정본_v1

## 1. 문서 목적

이 문서는 운영환경설정 창의 최종 UI 배치 기준을 기록한다.

현재 기준 코드:
gui_windows_88_align_manual_liquidation_checkbox.py

이 문서는 다음 창에서 UI 재분석을 반복하지 않기 위한 기준 문서이다.

---

## 2. 전체 원칙

1. 이미지 재생성 방식 금지.
2. 실제 PyQt 코드 수정으로만 반영.
3. 1번, 2번 영역은 현재 확정 상태이므로 불필요한 수정 금지.
4. 3~6번 체크박스는 체크박스 사각형 위치 기준으로 정렬.
5. 텍스트 시작점이 아니라 체크박스 위치가 기준이다.
6. 익절/손절 입력칸은 익절/손절 옵션 소속으로 보이게 가깝게 배치.
7. 이월 위치는 각 행의 의미 기준에 맞춘다.

---

## 3. 1번 운영시간 설정

구성:
- 1. 운영시간 설정
- 정규장
- 시작 시간
- 종료 시간
- 구분선
- ATS
- 추가시간1 이름 입력칸
- 추가시간1 저장 버튼
- 추가시간1 시작/종료
- 추가시간2 이름 입력칸
- 추가시간2 저장 버튼
- 추가시간2 시작/종료
- 추가시간3 이름 입력칸
- 추가시간3 저장 버튼
- 추가시간3 시작/종료

확정 사항:
- "거래시간 추가" 문구는 삭제
- ATS 라벨은 추가시간 영역의 좌측에 배치
- 추가시간 저장 버튼은 이름 입력칸 뒤에 배치
- 저장 버튼은 너무 좁지 않게 약간 여유 있게 배치
- 정규장 시작/종료 열과 ATS 시작/종료 열은 같은 x축 기준

---

## 4. 2번 시간운영 기본설정

구성:
- 시작
- 기본 시작 시간
- 매수종료
- 매수종료 시간
- 매수종료 후
- 정책 선택 콤보박스

확정 사항:
- 현재 배치 유지
- 3~6번 정렬 기준의 참고 위치로만 사용
- 직접 수정하지 않음

---

## 5. 3번 수동운영 기본설정

구성:
- 정규장
- 추가시간1 또는 저장된 ATS 이름
- 추가시간2
- 추가시간3
- /
- 청산정책 적용

확정 사항:
- "사용시간" 문구 삭제
- 청산정책 적용 앞에 "/" 추가
- 청산정책 적용 체크박스는 4/5번 이월 체크박스 열과 맞춤
- 단, 기준은 텍스트가 아니라 체크박스 사각형 위치

---

## 6. 4번 자동마감 설정

구성:
- 루틴매도
- 시장가
- 현재가
- 익절/손절
- + 익절 입력칸
- / - 손절 입력칸
- 이월

확정 사항:
- 이월 체크박스는 후방 열에 배치
- 익절/손절 입력칸은 익절/손절 옵션 옆에 붙여 배치
- 자동마감은 조기마감과 동일 구조

---

## 7. 5번 조기마감 설정

구성:
- 루틴매도
- 시장가
- 현재가
- 익절/손절
- + 익절 입력칸
- / - 손절 입력칸
- 이월

확정 사항:
- 자동마감과 동일 구조
- 5번 현재가 체크박스 열은 6번 시장가 체크박스 열의 기준
- 5번 익절/손절 체크박스 열은 6번 현재가 체크박스 열의 기준

---

## 8. 6번 청산설정

구성:
- 정규장 종료
- N분전
- 시장가
- 현재가
- 이월

확정 사항:
- 6번 시장가 체크박스는 5번 현재가 체크박스와 같은 열
- 6번 현재가 체크박스는 5번 익절/손절 체크박스와 같은 열
- 6번 이월은 6번 시장가와 6번 현재가 사이 거리와 같은 간격으로 오른쪽 배치
- 6번 이월은 4/5번 이월과 억지 정렬하지 않는다

---

## 9. 남은 UI 관련 보류

현재는 실사용 가능 수준.

추후 실제 사용 중에만 아래 항목을 조정한다.

- 1~2px 단위 미세조정
- 입력칸 폭 조정
- 버튼 폭 조정
- 행 높이 조정
- 폰트 크기 미세조정

- 익절/손절 입력값 저장
- 청산설정 저장
- 재실행 후 복원

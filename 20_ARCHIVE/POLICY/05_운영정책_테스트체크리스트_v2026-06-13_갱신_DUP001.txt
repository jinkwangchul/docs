# 운영정책_테스트체크리스트_v2026-06-13_갱신

작성 기준일: 2026-06-13
작성 목적: 다음 새 대화창에서 키움 자동매매 프로젝트를 즉시 이어가기 위한 최신 테스트 기준 문서
작성 방식: 기존 운영정책_테스트체크리스트_v2026-06-13을 기반으로, 조기/자동마감 v2.2, 예산/완충/완충복구, 관제창 자금운영 정책을 반영한다.


============================================================
1. 테스트 목적
============================================================

이 체크리스트는 기능이 열리는지 확인하는 문서가 아니다.
목적은 예외 상황에서 시스템이 정책대로 안전하게 동작하는지 확인하는 것이다.

중점 확인:
- 자동복귀가 발생하지 않는가.
- 검토관리로 격리되어야 할 종목이 누락되지 않는가.
- 이월 종목이 자동으로 정상 운영에 복귀하지 않는가.
- 마감과 청산 개념이 섞이지 않는가.
- 데이터 불일치가 빨강으로 표시되는가.
- 빨강이 자동 검토관리 이동으로 오해되지 않는가.
- 조기/자동마감이 더 이상 단순 매수금지 상태로 처리되지 않는가.
- 마감상태에서 루틴 매수/매도 신호가 정책대로 수용되는가.
- 예산/가용/완충 계산이 총매입금액 + 매수주문대기금액 기준으로 동작하는가.
- 완충복구 정책이 기존 조기마감/청산 정책을 재사용하는가.
- 완충복구 상황에서 이월이 비활성화되는가.
- 관제창에서 예산/완충/시간/정책이 직접 수정 가능한가.


============================================================
2. 재시작 테스트
============================================================

[RS-01] 보유/미수/미도 없음
조건:
- trade_enabled 여부와 무관하게 보유 0.
- 미수 0.
- 미도 0.
- 이월 메타 없음.
동작:
- 프로그램 종료 후 재시작.
예상:
- 종료상태.
- 시작 OFF.
- 검토관리 이동 없음.
- 자동 매수/매도 복귀 없음.

[RS-02] 보유 있음
조건:
- 보유 > 0.
- 미수 0.
- 미도 0.
동작:
- 프로그램 종료 후 재시작.
예상:
- 검토관리 이동.
- 자동복귀 금지.
- 자동매매설정창에서 제거.
- 검토관리창에서 보유 표시.

[RS-03] 미수 있음
조건:
- 보유 0.
- 미수 > 0.
- 미도 0.
예상:
- 검토관리 이동.
- 청산 대상으로 넘기지 않음.

[RS-04] 미도 있음
조건:
- 보유 0 또는 보유 있음.
- 미도 > 0.
예상:
- 검토관리 이동.
- 자동복귀 금지.

[RS-05] 이월 흔적 있음
조건:
- 조기마감/자동마감 이월 메타 존재.
- 보유 존재 여부 확인.
예상:
- 검토관리 이동.
- 다음 시작점 자동복귀 금지.

3. 긴급정지 테스트
============================================================

[EM-01] 긴급정지 실행
조건:
- 정상 운영 종목 존재.
동작:
- 긴급정지 실행.
예상:
- 신규 매수 중지.
- 자동 매도 금지.

- 긴급정지 해제.
예상:
- 재시작과 동일 판정.

[EM-03] 긴급정지 해제 + 보유 있음

[EM-04] 긴급정지 해제 + 미수/미도 있음
예상:
- 검토관리 이동.

4. 검토관리 테스트
============================================================

[RV-01] 검토관리 표시
조건:
- REVIEW_REQUIRED 종목 존재.
예상:
- 자동매매설정창에서 미표시.
- 검토관리창에 표시.
- 코드/종목/위치/상태/사유/검출/보유/미수/미도/발생시간 확인.

[RV-02] 새로고침 판정
조건:
- 검토관리 종목 존재.
동작:
- 새로고침 실행.
예상:
- 현재 보유/미수/미도/평단/서버불일치/이월 흔적을 다시 읽는다.
- 문제 있으면 계속 검토관리 유지.
- 문제 없으면 복귀 가능 상태로 볼 수 있다.

[RV-03] 복귀
조건:
- 검토관리 종목 선택.
동작:
- 복귀.
예상:
- 자동복귀가 아니라 운영자 명령으로 복귀.
- 복귀 후 현재 조건 재판정.
- 보유/미수/미도/이월이 남아 있으면 재격리 또는 복귀 차단 필요.

[RV-04] 미지정
예상:
- 루틴 연결/기초종목 상태가 정책대로 정리되는지 확인.
- 문제 남아 있으면 미지정 차단 필요.

[RV-05] 삭제
예상:
- 보유/미수/미도 존재 시 삭제 경고 또는 차단 확인.

5. 조기마감 테스트 v2.2
============================================================

[EC-01] 조기마감 상태 진입 후 매수신호 허용
조건:
- 종목이 조기마감 상태.
- 아직 매수신호 발생 가능.
동작:
- 루틴 매수신호 발생.
예상:
- 기존처럼 무조건 매수 차단하지 않는다.
- 조기마감은 마감상태이며 루틴 신호 수용 가능.
- 매수 진행 여부는 예산/매수한도/주문정책/운영방식 기준으로 최종 판정.

[EC-02] 조기마감 상태 진입 후 매도신호 발생
조건:
- 조기마감 상태.
- 보유 있음.
동작:
- 루틴 매도신호 발생.
예상:
- 매도 수행.
- 매도 후 해당 종목 운영 종료 또는 감시/대기 상태로 이동.

[EC-03] 조기마감 중 여러 번 매수 발생
조건:
- 조기마감 상태.
- 매수신호가 여러 번 발생.
예상:
- 매수횟수 제한 없음.
- 관제창에 마감상태에서 매수진행 횟수 또는 관련 상태가 표시되어야 함.

[EC-04] 조기마감 + 시장가
조건:
- 보유 있음.
동작:
- 조기마감 시장가.
예상:
- 상태 조기마감.
- 청산 시장가.
- 처리 대상 있음 → 현황 녹색.

[EC-05] 조기마감 + 현재가
예상:
- 현재가 정책대로 처리.
- 미체결/잔여 발생 시 정책 확인.

[EC-06] 조기마감 + 지정가
예상:
- 지정가 주문/표시 정책 확인.

[EC-07] 조기마감 + 익절/손절
예상:
- 기준 수익률 판정.
- 조건 미충족 시 다음 상태 확인.

[EC-08] 조기마감 + 이월 + 보유 있음
예상:
- 상태 조기마감.
- 방식 이월.
- 청산 이월.
- 보유 유지.
- 현황 녹색.
- 자동청산 금지.

[EC-09] 조기마감 + 이월 + 청산시간대 겹침
예상:
- 이월 우선.
- 시장가/현재가 청산 실행 금지.

[EC-10] 조기마감 + 대상 없음
조건:
- 보유 0.
- 미도 0.
예상:
- 상태 감시/대기 또는 마감 대상 없음 표시 정책.
- 현황 주황.

6. 자동마감 테스트 v2.2
============================================================

[AC-01] 자동마감 시간 도달 후 상태 진입
조건:
- 자동마감 설정 있음.
- 설정 시간 도달.
예상:
- 자동마감 상태 진입.
- 자동마감은 조기마감과 동일한 마감상태 철학을 따른다.

[AC-02] 자동마감 상태에서 매수신호 허용
조건:
- 자동마감 상태.
- 루틴 매수신호 발생.
예상:
- 기존처럼 무조건 매수 차단하지 않는다.
- 최종 매수 여부는 예산/매수한도/주문정책/운영방식 기준.

[AC-03] 자동마감 상태에서 매도신호 발생
조건:
- 자동마감 상태.
- 보유 있음.
동작:
- 루틴 매도신호 발생.
예상:
- 매도 수행.
- 이후 종료/감시대기 상태 확인.

[AC-04] 자동마감 + 시장가
[AC-05] 자동마감 + 현재가
[AC-06] 자동마감 + 지정가
[AC-07] 자동마감 + 익절/손절
[AC-08] 자동마감 + 이월
[AC-09] 자동마감 + 이월 + 청산시간대 겹침
[AC-10] 자동마감 + 대상 없음

각 예상은 조기마감과 동일 철학을 따른다.
단, 자동마감은 장기 테스트가 필요하며 완료 판정하지 않는다.

7. 청산 테스트
============================================================

[CL-01] 5분/시장가
[CL-02] 10분/시장가
[CL-03] 5분/현재가
[CL-04] 10분/현재가
[CL-05] 지정가
[CL-06] 이월

공통 확인:
- 이월이면 청산 active False.
- 보유 없으면 청산 비활성.
- 시작 OFF면 청산 비활성.
- 미수는 청산 대상으로 넘기지 않음.
- 미도는 처리 대상 또는 검토관리 조건으로 판정.
- 완충복구로 조기마감에 들어간 경우 조기마감 이월은 비활성.
- 완충복구 이후 이어지는 청산은 기존 청산정책을 사용.

8. 예산/완충 테스트
============================================================

[BG-01] 예산 구조 표시
조건:
- 전체 예산 100,000,000원.
- 가용/완충 8:2.
예상:
- 가용예산 80,000,000원.
- 완충예산 20,000,000원.
- 예산 = 가용 + 완충으로 표시.

[BG-02] 예산 사용금액 계산
조건:
- 보유 총매입금액 30,000,000원.
- 매수주문대기금액 5,000,000원.
예상:
- 예산 사용금액 35,000,000원.

[BG-03] 매도주문 대기금액 처리
조건:
- 매도주문 발송.
- 아직 체결 전.
예상:
- 해당 금액은 아직 회수금으로 보지 않음.
- 보유 또는 사용중 자금으로 유지.

[BG-04] 정상 상태
조건:
- 예산 사용금액이 경고비율 미만.
예상:
- 예산상태 정상.

[BG-05] 경고 상태
조건:
- 사용금액이 설정 경고비율 도달.
예상:
- 예산상태 경고.
- 관제창 표시.
- 로그 기록.
- 텔레그램 등 외부 알림 후보.

[BG-06] 완충진입 상태
조건:
- 사용금액이 가용예산 초과.
예상:
- 예산상태 완충진입.
- 완충 사용금액 표시.
- 정상운영이 아니라 비상복구 상태로 표시.

[BG-07] 가용/완충 비율 직접 수정
동작:
- 관제창에서 비율 클릭.
- 8:2 → 9:1 또는 7:3 변경.
예상:
- 가용/완충 금액 자동 환산.
- 예산상태 재계산.

9. 완충복구 테스트
============================================================

[BF-01] 완충진입만 발생, 신규매수 없음
조건:
- 완충진입 상태.
- 이후 신규매수 없음.
예상:
- 복구대상 추가 선정 없음.
- 경고/알림 유지.

[BF-02] 완충상태 + 신규매수 + 완충 미해소
조건:
- 완충상태.
- 신규 매수 발생.
- 매수 후에도 완충 해소 안 됨.
예상:
- 완충복구 정책 실행.
- 복구대상 선정.
- 대상 종목 조기마감 전환.

[BF-03] 수익률 낮은 종목 우선
조건:
- 복구대상 정책: 수익률 낮은 종목 우선.
- 여러 종목 존재.
예상:
- 이미 조기마감/자동마감/청산이 아닌 종목 중 수익률 가장 낮은 종목 선정.

[BF-04] 이미 마감/청산 종목 제외
조건:
- 수익률이 가장 낮은 종목이 이미 조기마감/자동마감/청산 상태.
예상:
- 해당 종목 제외.
- 다음 후보 선정.

[BF-05] 완충복구 조기마감 이월 비활성
조건:
- 완충복구로 종목이 조기마감 전환.
예상:
- 조기마감 이월 선택 불가.
- 기존 조기마감 정책 중 이월 외 옵션 사용.

[BF-06] 완충복구 후 청산정책 연동
조건:
- 완충복구 대상 선정.
- 조기마감 정책이 청산으로 이어짐.
예상:
- 별도 완충 청산 엔진이 아니라 기존 청산정책 사용.

[BF-07] 완충복구 적용시간 - 시간운영 설정값 사용
조건:
- 시간운영 설정값 사용 체크 ON.
예상:
- 기존 시간운영 설정값에 따라 완충복구 적용시간 결정.

[BF-08] 완충복구 적용시간 - 별도 시간 사용
조건:
- 시간운영 설정값 사용 체크 OFF.
- 별도 시간 설정.
예상:
- 별도 시간에만 완충복구 실행.

[BF-09] 적용시간 밖 완충상태 + 신규매수
조건:
- 완충상태.
- 신규매수 발생.
- 완충복구 적용시간 밖.
예상:
- 신규 복구대상 선정 안 함.
- 알림/상태표시만 강화.
- 기존 마감/청산 흐름 유지.

10. 매수한도 테스트
============================================================

[LIM-01] 전체 매수한도 ON
조건:
- 전체 매수한도 설정.
예상:
- 전체 한도 초과 신규 매수 차단 또는 정책상 제한.

[LIM-02] 루틴 매수한도 ON
조건:
- 루틴 매수한도 설정.
예상:
- 루틴 총매입금액 + 매수예정금액이 한도 초과 시 제한.

[LIM-03] 루틴 매수한도 OFF
조건:
- 루틴 매수한도 미사용.
예상:
- 상위 예산/전체한도/종목한도만 적용.
- 제한 없는 루틴들은 남은 가용자금을 공유.

[LIM-04] 종목 매수한도 ON
조건:
- 종목 매수한도 설정.
예상:
- 해당 종목 총매입금액 + 매수예정금액이 한도 초과 시 제한.

[LIM-05] 루틴 한도 변경 시 종목 한도 유지
조건:
- 루틴 한도 증가 또는 OFF.
- 종목 한도 설정 존재.
예상:
- 종목 한도 자동 증가/해제 금지.
- 종목 한도는 운영자가 직접 변경해야 함.

[LIM-06] 비율/금액 병기
예상:
- 루틴 한도는 비율/금액 병기.
- 비율 클릭 시 비율 수정.
- 금액 클릭 시 금액 수정.
- 환산값 자동 반영.

11. 수익성/추세 테스트
============================================================

[PF-01] 종목 수익성 빨강
조건:
- 현재가 일괄매도 기준 세금/수수료/거래비용 반영 후 손실.
예상:
- 수익성 빨강.

[PF-02] 종목 수익성 노랑
조건:
- 표면 수익은 있으나 비용 반영 시 손익분기 근처 또는 비용 미충족.
예상:
- 수익성 노랑.

[PF-03] 종목 수익성 녹색
조건:
- 비용 반영 후 명확한 순이익.
예상:
- 수익성 녹색.

[PF-04] 루틴 수익성
조건:
- 루틴 내 여러 종목 존재.
예상:
- 수익 종목 개수로 판단하지 않음.
- 루틴 전체 총매입금액/평가금액/비용/손익 기준으로 판정.

[TR-01] 종목 추세 이평선 선택
조건:
- 선택 이평선 5/10/20 중 하나.
예상:
- 선택 이평선 기준으로 추세 표시.

[TR-02] 루틴 추세 없음
예상:
- 루틴 추세는 계산하지 않음.
- 루틴은 수익성/손익/사용금액 중심 표시.

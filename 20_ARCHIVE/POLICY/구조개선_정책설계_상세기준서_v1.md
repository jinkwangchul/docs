
# 구조개선 정책설계 기준서 상세판 v1

## 문서 목적
본 문서는 구조개선 단계에서 확정된 운영정책, 상태체계, 무결성 검사, 검토종목 정책, 긴급정지 정책을 상세 기록하여 새 창에서도 동일한 설계 철학을 유지하기 위한 기준 문서이다.

# 1. 운영 철학

- 안정성 최우선
- 상태확인 없는 자동주문 금지
- 상태확인 없는 자동청산 금지
- 상태확인 없는 자동복귀 금지
- 문제 종목은 격리 후 검증
- 자동매매 신뢰성 훼손 시 검토종목 이동

# 2. 상태 체계

유지 상태

- 감시/대기
- 매수/매도
- 긴급정지
- 검토종목

폐기 상태

- 일시정지
- 중강도 긴급정지

폐기 사유

- 자동매매는 타이밍 기반
- 일시정지 후 복귀는 신호 유실 문제 발생
- 긴급정지와 기능 중복

# 3. 긴급정지

목적

- 시장 급변
- 시스템 이상 의심
- API 이상 의심
- 운영자 강제 중단

동작

- 신규 매수 금지
- 신규 매도 금지
- 자동판단 중지
- 자동청산 중지
- 실시간 감시 유지
- 계좌조회 유지

해제

- 자동복귀 금지
- 종목별 무결성 검사 수행

무결성 통과

- 현재조건 재판정 후 운영 복귀

무결성 실패

- 검토종목 이동

# 4. 검토종목

정의

자동매매 신뢰성이 훼손된 종목 격리구역

자동복귀

- 금지

복귀 방법

- 운영자 문제 해결
- 수동 무결성 검사
- 통과 시 현재조건 재판정

검토종목 이동 조건

- HTS 수동개입
- 수량 불일치
- 청산 실패
- 잔량 발생
- 익일이월
- 계좌정보 불일치
- 조회 실패
- 긴급정지 후 무결성 실패

허용 기능

- 상태조회
- 로그조회
- 미체결 취소
- 현재가 매도
- 시장가 매도
- 수동 무결성 검사

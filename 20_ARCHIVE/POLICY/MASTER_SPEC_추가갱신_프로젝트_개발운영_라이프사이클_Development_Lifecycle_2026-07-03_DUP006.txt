MASTER_SPEC_추가갱신_프로젝트_개발운영_라이프사이클_Development_Lifecycle_2026-07-03

목적
- 프로젝트가 아이디어부터 운영, 유지보수까지 반복되는 전체 개발 생명주기(Development Lifecycle)를 정의한다.

==================================================
1. 전체 생명주기
==================================================
요구사항
→ 설계
→ 구현
→ 단위 테스트
→ 통합 테스트
→ 회귀 테스트
→ Preview 검증
→ 문서 갱신
→ 릴리즈 승인
→ 운영
→ 모니터링
→ 유지보수
→ 개선 요구사항

==================================================
2. 단계별 산출물
==================================================
요구사항
- 요구사항 목록
- 변경 목적

설계
- MASTER_SPEC
- ADR
- Runtime 규격

구현
- 코드
- 테스트 코드

검증
- 테스트 결과
- 회귀 결과
- Preview 결과

운영
- Runtime
- Audit
- Review
- Recovery 기록

==================================================
3. 단계별 진입 조건
==================================================
설계
- 요구사항 명확화

구현
- 설계 승인

테스트
- 구현 완료

릴리즈
- Definition of Done 충족
- Test Strategy 충족
- 문서 갱신 완료

운영
- Recovery 확인
- Runtime 무결성 확인

==================================================
4. 단계별 종료 조건
==================================================
각 단계는 다음 단계의 입력 산출물을 남겨야 한다.
- 설계 → 구현 기준
- 구현 → 테스트 대상
- 테스트 → 릴리즈 근거
- 운영 → 유지보수 근거

==================================================
5. 피드백
==================================================
운영 중 발견된 문제는
운영
→ 분석
→ 설계 검토
→ 구현
으로 되돌아간다.

==================================================
6. 금지
==================================================
- 설계 없이 구현
- 테스트 없이 릴리즈
- 문서 없이 구조 변경
- 운영 중 Runtime 직접 수정

==================================================
최종 원칙
프로젝트는 일회성 개발이 아니라,
'요구사항 → 설계 → 구현 → 검증 → 운영 → 개선'의 반복 사이클로 지속적으로 발전한다.

6. Architecture Decision 기록
- Lifecycle Commit은 Runtime Commit Core(M6)로 직접 쓰지 않고 Adapter를 통해 위임
- Adapter/Builder는 thin layer: IO/검증/락/토큰/저널/GUI/브로커 수행 안 함
- 실제 Runtime Commit 동작은 runtime_commit_real_executor.execute_runtime_commit 에 집중
- RSI 매수 필터는 오직 buy.filters.rsi 공식 설정만 사용, pending UI 후보값은 실행에 영향 없음
- BUY 주조건 통과 후에만 RSI 필터 평가, 불충족 시 signal=None("BUY RSI filter blocked")

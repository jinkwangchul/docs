============================================================
1. 현재 작업의 큰 목적
============================================================
키움 자동매매 프로젝트에서 실제 SendOrder 호출 전/후 실행 체인을 Preview / Review / Commit 구조로 분리했다.
모든 단계는 독립 서비스로 구현되며, write 가능 계층만 명시 path + 수동 confirmation + stale snapshot + backup + atomic write를 사용한다.

현재 실제 Kiwoom SendOrder/dynamicCall/OnReceiveChejanData는 연결하지 않았다.
현재 GUI/Timer/자동 루프도 실제 SendOrder 또는 Chejan 처리와 연결하지 않았다.

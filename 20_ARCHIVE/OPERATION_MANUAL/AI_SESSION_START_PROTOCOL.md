# AI Session Start Protocol

This document is a short startup checklist. It is not an independent operating policy.

Authoritative AI operating rules are defined only in:

```text
00_CANONICAL/REFERENCE/AGENT_WORKFLOW_REFERENCE.txt
```

## Startup Checklist

1. Read `00_CANONICAL/REFERENCE/AGENT_WORKFLOW_REFERENCE.txt`.
2. Read `00_CANONICAL/REFERENCE/00_REFERENCE_INDEX.md`.
3. Identify the Latest Official Canonical.
4. Identify the Latest Work Resume.
5. Confirm the local project Git baseline when code work is requested.
6. Confirm the docs Git baseline when document work is requested.
7. Read only the Canonical sections and source files needed for the current task.

## Boundaries

- Do not perform broad structure audits by default.
- Do not treat historical notes as current instruction.
- Do not modify code, Runtime, Canonical, Changelog, or Work Resume during startup.
- Do not run Git operations during startup unless the user explicitly asks for baseline verification.

## Completion

Startup is complete when the current task scope, required source files, and relevant baseline are known.

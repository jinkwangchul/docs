핵심 내용
- Runtime Layer Phase1은 runtime을 바로 쓰는 계층이 아니라 preview-only runtime 보호 계층이다.
- Lifecycle 이후 Runtime Projection을 만들고, 그 결과를 Persistence Preview, Recovery Preview, Reconciliation Preview로 검토한다.
- 실제 runtime write, position write, balance write는 수행하지 않는다.
- GUI update, SendOrder, Chejan 호출도 수행하지 않는다.

Projection 상세 규격 통합
- Projection 단독 UPDATE의 상세 규격은 Phase1 Canonical에 흡수되었다.
- Projection은 lifecycle/fill/evidence 기반으로 position, balance, runtime state 후보를 계산한다.
- Projection 결과는 실제 파일에 쓰지 않고 다음 preview 계층의 입력 후보로만 전달한다.

Persistence Preview
- Projection 결과를 runtime 저장 대상으로 반영하기 전에 persistence plan candidate를 만든다.
- 저장 대상과 변경 후보를 검토하지만 실제 파일 저장은 하지 않는다.
- 실제 runtime file write는 이후 Runtime Commit Executor 계층에서만 다룬다.

Recovery Preview
- 재시작, 누락, 불완전 상태 등에서 복구 후보를 계산한다.
- recovery candidate와 recoverable 여부를 preview로 정리한다.
- 자동 복구 commit이나 runtime 파일 생성/수정은 수행하지 않는다.

Reconciliation Preview
- projection, persistence, recovery 결과와 기존 runtime 기준 사이의 불일치를 검토한다.
- mismatch list와 reconciliation candidate를 만든다.
- 불일치가 있어도 자동 보정이나 runtime write는 수행하지 않는다.

Preview Safety
- 유지된 safety flags:
  - `runtime_write=False`
  - `position_write=False`
  - `balance_write=False`
  - `gui_update_called=False`
  - `send_order_called=False`
  - `chejan_called=False`
- Runtime Layer Phase1은 preview-only 정책을 유지한다.

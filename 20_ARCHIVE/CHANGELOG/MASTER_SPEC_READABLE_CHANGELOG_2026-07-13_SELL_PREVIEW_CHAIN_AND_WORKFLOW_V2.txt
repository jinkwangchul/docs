이번 Conversation에는 중요한 운영 사례가 있었다.

SELL Common Execution Preview Adapter는 처음에 구현 완료로 보고됐지만 실제 저장소에는 파일이 없었다. 그래서 Git history, worktree, reflog, dangling object, 파일시스템까지 조사했다. 복구 가능한 파일이나 commit은 찾지 못했고, 동일 범위를 재구현했다. 재구현 후 신규 테스트 42개, SELL 테스트 306개, Execution 테스트 1623개, 전체 unittest 4275개가 통과했고 change set 4로 기준점에 반영했다.

이 사례는 Workflow v2에서 파일 실존 검증과 stage/commit 범위 검증이 왜 필요한지를 보여준다.
